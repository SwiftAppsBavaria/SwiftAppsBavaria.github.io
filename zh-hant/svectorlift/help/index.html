sVectorLift 手冊

概覽

sVectorLift 可打開 CorelDRAW 時代的舊向量美工圖案，並將其轉換為 SVG——即當今程式仍能使用的圖形。請在左側選擇一個檔案夾，右側便會以預覽形式顯示其中的美工圖案。所選圖形可輸出到你指定的目標檔案夾。

支援的格式

• CorelDRAW 文件（.cdr），版本 6 至 9
• Corel Binary Meta File（.cmx）——也包括舊的 CDRX 變體
• Windows Metafile（.wmf）
• Computer Graphics Metafile（.cgm）
• QuickDraw 3D 中繼檔（.3dm、.3dmf）——會算圖為影像
• Scalable Vector Graphics （.svg）——直接顯示

許多副檔名為 .cdr 的檔案其實根本不是 CorelDRAW 文件，而是 CMX。常見的轉換器正是在這一點上失敗——而 sVectorLift 兩者都能讀取。

選擇檔案夾

1. 點按「選擇檔案夾 …」（或按 ⌘O）以打開包含美工圖案收藏的檔案夾。其下方會顯示檔案夾樹狀結構。
2. 點按樹狀結構中的某個檔案夾即可載入其中的美工圖案。子檔案夾可透過三角形展開。
3. 下次啟動時會重新打開最近使用的檔案夾 — 連同最近打開的子檔案夾以及所選檔案。透過「檔案 → 最近使用的檔案夾」可直接返回先前的收藏。

也可從 Finder 打開單一檔案（「打開檔案的應用程式」或按兩下）：若該檔案位於收藏中，sVectorLift 會跳至該檔案；若位於收藏之外，則會單獨顯示它，並且僅在切換到概覽時才要求檔案夾存取權限。

透過「篩選（名稱或關鍵字）」欄位，可依名稱或關鍵字過濾美工圖案。

將分隔線拖向格狀檢視即可調整側邊欄的寬度。使用側邊欄頂端的按鈕 — 或按 ⌃⌘S — 可將其完全隱藏，讓美工圖案佔滿整個視窗寬度。

兩個檔案夾按鈕旁邊都會顯示所選的路徑。點按路徑會把它完整顯示出來，方便拷貝；按右鍵則直接在 Finder 中打開。

檢視美工圖案

• 使用右上角的滑桿可調整縮覽圖的大小。
•「詳細檢視」（或按兩下某個美工圖案）會大幅顯示單個圖形。使用方向鍵 ← → 可瀏覽該檔案夾，按兩下即可返回「概覽」。
• 縮覽圖只有在你看到它們時才會計算。因此在非常大的檔案夾中會先出現佔位圖，隨後逐步填入。

選擇

選擇方式與「照片」App 相同：
• 點按：選擇單個美工圖案
• ⌘-點按：將個別美工圖案加入選擇或從選擇中移除
• ⇧-點按：選擇一段連續範圍
• 在空白處拖移：拉出選擇矩形（橡皮筋）
• ⌘A：選擇該檔案夾中的所有美工圖案
• 點按空白處：取消選擇

輸出

1. 在「2. 輸出」下選擇「目標檔案夾 …」。點按路徑可完整顯示該路徑，並在需要時前往 Finder。
2.「輸出所選項目」會輸出已標示的美工圖案，「全部輸出」則輸出整個（已篩選的）檔案夾。

向量圖形將儲存為 .svg。純點陣圖像以及 3D 模型將儲存為 .png，以免遺失內容。SVG 檔案已經是目標格式，因此對其停用輸出。

透過快速選單（在美工圖案上按右鍵），可將其輸出到同一個目標檔案夾、在 Finder 中顯示該檔案、重新命名檔案或移到垃圾桶。若尚未設定目標檔案夾，則會詢問一次。

如果目標檔案已經存在，sVectorLift 會先詢問：「取代」、「兩者都保留」（在旁邊另存為「名稱 2.svg」）、「略過」或「取消」。檔案有多個時，用「套用至全部」就能把你的回答用於整個輸出過程。接著輸出會在側邊欄顯示進度列，你隨時都能取消。

重新命名可以用 ⌘Z 還原，也可以用 ⇧⌘Z 重做——只要該檔案還在已打開的收藏中。輸出進行期間，重新命名和刪除會暫時停用：該次輸出使用的是它啟動時的檔案名稱。

輸出檔案夾結構

若要轉換整個檔案夾及其所有子檔案夾，請使用「輸出檔案夾結構」視窗。可透過「檔案 → 輸出檔案夾結構 …」或側邊欄中的同名按鈕打開該視窗，在其中選擇來源檔案夾和目標檔案夾，然後按一下「全部輸出」開始。目標位置中會建立相同的檔案夾結構；SVG 檔案會原封不動地一併拷貝，不含受支援檔案的檔案夾則不會建立。過程中不會詢問：目標位置中已有的內容會被略過。若同一檔案夾中有多個檔案同名，其後的每個檔案都會加上其原始副檔名，例如「geometry (cmx).svg」。

設定

在「sVectorLift → 設定 …」（⌘,）中可以設定 3D 模型算圖尺寸。

3D 模型沒有向量形式；輸出時會當成影像來計算。數值越大，PNG 越清晰——輸出花的時間也越長。允許的範圍是 256 到 8192 像素，預設為 1024。

在同一個視窗裡也能找到語言選擇的按鈕。

鍵盤快速鍵

• ⌘O：選擇檔案夾
• ⌘A：選擇所有美工圖案
• ← →：在詳細檢視中瀏覽檔案夾
• 按兩下：在概覽與詳細檢視之間切換
• ⌃⌘S：顯示或隱藏側邊欄
• ⌘/：顯示本輔助說明
• ⌘W：關閉視窗（經詢問後結束 App）
• ⌘Q：結束 App
• ⌘Z：還原重新命名
• ⇧⌘Z：重做重新命名

語言

sVectorLift 會採用你系統的語言。若想以其他語言使用本 App，請在系統設定中進行設定：

系統設定 → 一般 → 語言與地區 → 向下捲動到「App」部分 →「+」→ sVectorLift → 所需語言

此設定僅對 sVectorLift 生效，系統的其餘部分不受影響。

如果美工圖案未顯示

• 若顯示問號而非預覽，表示該檔案無法讀取——例如檔案已損壞，或包含 sVectorLift 無法辨識的格式。
• sVectorLift 專為美工圖案收藏而設計：圖畫、符號、插圖。CorelDRAW 的多頁手冊和印刷範本並非目標對象，可能顯示不完整。

動畫 SVG

對於動畫 SVG 檔案，sVectorLift 會以靜態影像顯示，動畫本身不會播放。
