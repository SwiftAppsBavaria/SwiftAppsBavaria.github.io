Справка SwiftRename

Обзор

SwiftRename — это инструмент для одновременного переименования и упорядочивания нескольких файлов. Вы можете переименовывать файлы по дате, нумеровать их, добавлять префикс и автоматически сортировать по структуре папок.

Выбор папок

1. Нажмите значок папки в поле ввода папки, чтобы выбрать папку с файлами, которые необходимо переименовать. Также можно перетащить папки из Finder в поля папок. С помощью маленькой стрелки на значке папки вы можете быстро снова выбрать недавно использованную папку.
2. Активируйте «Включить подпапки», чтобы обработать также файлы в подпапках.
3. Выберите папку вывода, в которую будут скопированы или перемещены переименованные файлы. Папки ввода и вывода могут быть одинаковыми (переименование в одном месте).
4. С помощью «Поменять» вы можете поменять местами папки ввода и вывода. С помощью «Обновить» вы можете перезагрузить оба списка файлов.

Режимы переименования

• Только дата: присваивает файлам имена по дате их создания (например, «2024-01-15 в 14-30-00.jpg»)
• Дата + исходное имя: вставляет дату перед исходным именем файла (например, «2024-01-15 в 14-30-00 - IMG_4523.jpg»).
• Нумерация с префиксом: нумерует файлы последовательно с выбираемым префиксом (например, «Отпуск_0001.jpg»).
• Сохранить исходное имя: сортирует файлы только по структуре папок, не изменяя имена файлов

При одинаковых именах файлов автоматически добавляется счетчик (например, «_1», «_2»).

Структура папок

Файлы могут автоматически распределяться в подпапки по дате:
• Нет: Все файлы напрямую в выходную папку
• Сохранить: Воспроизводит структуру подпапок входной папки
• Год: напр. «2024/»
• Год/Месяц: напр. «2024/01/»
• Год/Месяц/День: напр. «2024/01/15/»

Если файлы охватывают несколько десятилетий, создаются дополнительные папки десятилетий (напр. «2011-2020/2015/…»).

При выборе «Год/Месяц» и «Год/Месяц/День» прямо под выбором структуры папок появляется опция «Полная дата в именах подпапок». Если она включена, папки месяцев и дней содержат полную дату (например, «2024/2024-01/2024-01-15/» вместо «2024/01/15/»).

Предпросмотр имён

В заголовке списка исходных файлов можно выбрать одно из трёх представлений: список, дерево и предпросмотр имён (значок глаза). В предпросмотре под каждым текущим именем файла отображается планируемое новое имя вместе с целевой папкой — относительно папки назначения, то есть включая папки по датам и десятилетиям.

Для предпросмотра нужна выбранная папка назначения; он пересчитывается, как только вы измените режим, префикс, структуру папок или параметр «Использовать дату съёмки». При большом количестве файлов список заполняется постепенно, поскольку для каждого файла считывается дата съёмки.

Это планируемые имена: будет ли файл пропущен как дубликат и нужно ли при совпадении целевых имён добавлять счётчик («_1»), решается только при выполнении.

Дата съемки (EXIF)

Если функция «Использовать дату съёмки» включена, для фотографий и видео будет использоваться дата съемки из данных EXIF. Это более точно, чем дата создания файла, которая может измениться при копировании.

Поддерживается множество форматов фотографий, включая JPEG, HEIC, PNG, TIFF и распространенные форматы RAW (CR2, CR3, NEF, ARW, DNG, RAF и многие другие).

Если дата EXIF отсутствует, автоматически используется дата создания файла.

Фильтр расширения файлов

Используйте выпадающее меню «Расширения файлов» для фильтрации отображаемых файлов по типу:
• Доступные расширения автоматически определяются из входной папки.
• Выберите одно или несколько расширений кликом (⌘-клик для переключения, ⇧-клик для диапазона).
• «Все расширения файлов» сбрасывает фильтр и показывает все файлы.
• Фильтр сохраняется при смене папки, если расширения там существуют.

обнаружение дубликатов

Если функция «Проверять дубликаты» включена, перед копированием или перемещением будут обнаружены дубликаты — как в папке ввода, так и в папке вывода (всё дерево назначения). Обнаружение основано на размере файла и побайтовом сравнении содержимого файла; для изображений и видео метаданные, такие как EXIF, пропускаются. Дата важна только при дополнительном сравнении содержимого изображений.

Найденные дубликаты отображаются в обзоре с миниатюрами. Затем вы можете решить, хотите ли вы продолжить (дубликаты будут пропущены) или отменить процесс.

С дополнительной опцией «Сравнивать только содержимое изображения (медленно)» для изображений сравниваются только декодированные пиксельные данные. Метаданные, такие как ключевые слова, теги или записи EXIF, игнорируются. Таким образом также обнаруживаются идентичные изображения, которые были повторно сжаты при сохранении ключевых слов. Этот вариант значительно медленнее и активен только при включённой проверке дубликатов. В качестве кандидатов рассматриваются только изображения с одинаковым форматом файла и схожим размером. Максимально допустимая разница в размере настраивается в Настройках (⌘,) в разделе «Допуск размера при сравнении изображений» (по умолчанию: 128 КБ). Форматы RAW часто требуют больших значений, так как метаданные, например ключевые слова, могут занимать несколько десятков КБ на запись.

Если программа переупаковала или повторно экспортировала видео, оно считается отдельным файлом — даже при одинаковых изображении и звуке. Для видео нет сравнения содержимого, как у изображений.

Копирование и перемещение

• Копировать: исходные файлы сохраняются, копии создаются в папке вывода.
• Переместить: файлы перемещаются в папку вывода.

Перед выполнением SwiftRename проверяет, достаточно ли места на целевом диске. При недостаточном месте появляется предупреждение. Вы можете продолжить процесс, несмотря на это.

Под списком ввода отображается общий размер файлов, под списком вывода — свободное место на целевом диске.

Отмена и повторение

Каждую операцию с файлами можно отменить:
• ⌘Z: отменить последнюю операцию
• ⌘⇧Z: повторить отмененную операцию

При отмене копирования скопированные файлы перемещаются в корзину. При отмене перемещения файлы возвращаются в исходное место.

Прогресс и отмена

Во время обработки отображается индикатор прогресса с указанием процента выполнения. Вы можете остановить процесс в любое время, нажав «Отмена». Уже обработанные файлы сохраняются и могут быть отменены с помощью ⌘Z.

Сочетания клавиш

• ⌘O: выбрать папку ввода
• ⌘⇧O: выбрать папку вывода
• ⌘Z: отменить
• ⌘⇧Z: повторить
• ⌘,: настройки
• ⌘/: отобразить справку
• ⌘Q: закрыть приложение

советы

• Перед крупными операциями по переименованию создайте резервную копию ваших файлов.
• Используйте предварительный просмотр в левой области, чтобы проверить результат переименования перед его выполнением.
• Щелкнув правой кнопкой мыши по файлу в списке, вы можете отобразить его в Finder.
• В Настройках (⌘,) вы можете изменить параметр «Допуск размера при сравнении изображений». При возникновении проблем нажмите там «Сохранить журнал…», чтобы записать сообщения за последние семь дней в текстовый файл.
