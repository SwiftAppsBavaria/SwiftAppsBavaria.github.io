sVectorLift 帮助

概览

sVectorLift 可打开 CorelDRAW 时代的旧矢量剪贴画，并将其转换为 SVG——即当今程序仍能使用的图形。请在左侧选择一个文件夹，右侧便会以预览形式显示其中的剪贴画。所选图形可导出到你指定的目标文件夹。

支持的格式

• CorelDRAW 文稿（.cdr），版本 6 至 9
• Corel Binary Meta File（.cmx）——也包括旧的 CDRX 变体
• Windows Metafile（.wmf）
• Computer Graphics Metafile（.cgm）
• QuickDraw 3D 图元文件（.3dm、.3dmf）——将渲染为图像
• Scalable Vector Graphics （.svg）——直接显示

许多扩展名为 .cdr 的文件其实根本不是 CorelDRAW 文稿，而是 CMX。常见的转换器正是在这一点上失败——而 sVectorLift 两者都能读取。

选择文件夹

1. 点按“选择文件夹 …”（或按 ⌘O）以打开包含剪贴画收藏的文件夹。其下方会显示文件夹树。
2. 点按树中的某个文件夹即可载入其中的剪贴画。子文件夹可通过三角形展开。
3. 下次启动时会重新打开最近使用的文件夹 — 连同最近打开的子文件夹以及所选文件。通过“文件 → 最近使用的文件夹”可直接返回到之前的收藏。

也可从访达打开单个文件（“打开方式”或连按两下）：如果该文件位于收藏中，sVectorLift 会跳转至该文件；如果位于收藏之外，则会单独显示它，并且仅在切换到概览时才请求文件夹访问权限。

通过“筛选（名称或关键词）”栏，可按名称或关键词过滤剪贴画。

将分隔条拖向网格即可调整边栏的宽度。使用边栏顶部的按钮 — 或按 ⌃⌘S — 可将其完全隐藏，让剪贴画占满整个窗口宽度。

两个文件夹按钮旁边都会显示所选的路径。点按路径会把它完整显示出来，方便拷贝；按右键则直接在访达中打开。

查看剪贴画

• 使用右上角的滑块可调整缩略图的大小。
•“详细视图”（或连按两下某个剪贴画）会大幅显示单个图形。使用方向键 ← → 可浏览该文件夹，连按两下即可返回“概览”。
• 缩略图只有在你看到它们时才会计算。因此在非常大的文件夹中会先出现占位图，随后逐步填充。

选择

选择方式与“照片”App 相同：
• 点按：选择单个剪贴画
• ⌘-点按：将单个剪贴画加入选择或从选择中移除
• ⇧-点按：选择一段连续范围
• 在空白处拖移：拉出选择矩形（橡皮筋）
• ⌘A：选择该文件夹中的所有剪贴画
• 点按空白处：取消选择

导出

1. 在“2. 导出”下选择“目标文件夹 …”。点按路径可完整显示该路径，并在需要时前往访达。
2.“导出所选项”会导出已标记的剪贴画，“全部导出”则导出整个（已筛选的）文件夹。

矢量图形将存储为 .svg。纯栅格图像以及 3D 模型将存储为 .png，以免丢失内容。SVG 文件已经是目标格式，因此对其禁用导出。

通过快捷菜单（在剪贴画上点按鼠标右键），可将其导出到同一目标文件夹、在访达中显示该文件、重命名文件或移到废纸篓。如果尚未设置目标文件夹，则会询问一次。

如果目标文件已经存在，sVectorLift 会先询问：“替换”、“两者都保留”（在旁边另存为“名称 2.svg”）、“跳过”或“取消”。文件有多个时，用“应用于全部”就能把你的回答用于整个导出过程。之后导出会在边栏显示进度条，你可以随时取消。

重命名可以用 ⌘Z 撤销，也可以用 ⇧⌘Z 重做——只要该文件还在已打开的收藏中。导出进行期间，重命名和删除会短暂停用：该次导出使用的是它启动时的文件名。

导出文件夹结构

要转换整个文件夹及其所有子文件夹，请使用“导出文件夹结构”窗口。可通过“文件 → 导出文件夹结构 …”或边栏中的同名按钮打开该窗口，在其中选择源文件夹和目标文件夹，然后点按“全部导出”开始。目标位置中会创建相同的文件夹结构；SVG 文件会原样一并拷贝，不含受支持文件的文件夹不会被创建。过程中不会询问：目标位置中已有的内容会被跳过。如果同一文件夹中有多个文件同名，其后的每个文件都会带上其原始扩展名，例如“geometry (cmx).svg”。

设置

在“sVectorLift → 设置 …”（⌘,）中可以设定 3D 模型渲染尺寸。

3D 模型没有矢量形式；导出时会按图像来计算。数值越大，PNG 越清晰——导出花的时间也越长。允许的范围是 256 到 8192 像素，默认为 1024。

在同一个窗口里还能找到语言选择的按钮。

键盘快捷键

• ⌘O：选择文件夹
• ⌘A：选择所有剪贴画
• ← →：在详细视图中浏览文件夹
• 连按两下：在概览与详细视图之间切换
• ⌃⌘S：显示或隐藏边栏
• ⌘/：显示本帮助
• ⌘W：关闭窗口（经询问后退出 App）
• ⌘Q：退出 App
• ⌘Z：撤销重命名
• ⇧⌘Z：重做重命名

语言

sVectorLift 会采用你系统的语言。若想以其他语言使用本 App，请在系统设置中进行设定：

系统设置 → 通用 → 语言与地区 → 向下滚动到“App”部分 →“+”→ sVectorLift → 所需语言

此设置仅对 sVectorLift 生效，系统的其余部分不受影响。

如果剪贴画未显示

• 若显示问号而非预览，表示该文件无法读取——例如文件已损坏，或包含 sVectorLift 无法识别的格式。
• sVectorLift 专为剪贴画收藏而设计：图画、符号、插图。CorelDRAW 的多页手册和印刷模板并非目标对象，可能显示不完整。

动画 SVG

对于动画 SVG 文件，sVectorLift 会以静态图像显示，动画本身不会播放。
