SwiftRename 手册

概述

SwiftRename 是一个用于同时重命名和整理多个文件的工具。您可以按日期重命名文件、连续编号、添加前缀，并自动将文件整理到文件夹结构中。

选择文件夹

1. 在输入文件夹旁点击文件夹图标，选择包含待重命名文件的文件夹。或者，您也可以将文件夹从 Finder 通过拖放方式拖到文件夹字段中。 点击文件夹图标上的小箭头，可快速重新打开最近使用过的文件夹。
2. 勾选“包含子文件夹”，以同时处理子文件夹中的文件。
3. 选择一个输出文件夹，用于复制或移动重命名后的文件。输入文件夹和输出文件夹可以相同（在原位置重命名）。
4. 点击“交换”可互换输入和输出文件夹；点击“刷新”可重新加载两个文件列表。

重命名模式

• 仅日期：根据文件的创建日期重命名（例如：“2024-01-15 - 14-30-00.jpg”）
• 日期 + 原名：在原始文件名前添加日期（例如：“2024-01-15 - 14-30-00 - IMG_4523.jpg”）
• 带前缀编号：使用可选前缀对文件进行连续编号（例如：“假期_0001.jpg”）
• 保留原始名称：仅将文件整理到文件夹结构中，不更改文件名

当出现相同文件名时，会自动添加编号（例如：“_1”、“_2”）。

文件夹结构

文件可以按日期自动排序到子文件夹：
• 无：所有文件直接放入输出文件夹
• 保留：在输出文件夹中重现输入文件夹的子文件夹结构
• 年：例如“2024/”
• 年/月：例如“2024/01/”
• 年/月/日：例如“2024/01/15/”

如果文件跨越多个十年，将创建额外的十年文件夹（例如“2011-2020/2015/…”）。

在“年/月”和“年/月/日”结构下，文件夹结构选择的正下方会显示“子文件夹名称中使用完整日期”选项。启用后，月份和日期文件夹将包含完整日期（例如“2024/2024-01/2024-01-15/”而不是“2024/01/15/”）。

名称预览

在输入列表的标题栏中可以选择三种视图：列表、树状和名称预览（眼睛图标）。在预览中，每个现有文件名下方会显示计划中的新名称及其目标文件夹——相对于输出文件夹，因此也包含日期文件夹和年代文件夹。

预览需要已选择的输出文件夹，只要更改模式、前缀、文件夹结构或“使用相机日期”选项，就会重新计算。文件较多时会逐步填充，因为需要读取每个文件的拍摄日期。

这些都是计划中的名称：文件是否会作为重复项被跳过，以及目标名称相同时是否需要附加计数器（“_1”），只有在执行时才会确定。

相机日期（EXIF）

如果启用“使用相机日期”，照片和视频将读取 EXIF 数据中的拍摄日期。这比复制时可能变化的文件创建日期更准确。

支持多种照片格式，包括 JPEG、HEIC、PNG、TIFF 以及常见的 RAW 格式（CR2、CR3、NEF、ARW、DNG、RAF 等）。

如果没有 EXIF 日期，将自动使用文件创建日期。

文件扩展名筛选

使用“文件扩展名”下拉菜单按类型筛选显示的文件：
• 可用的扩展名会自动从输入文件夹中检测。
• 点击选择一个或多个扩展名（⌘-点击切换，⇧-点击选择范围）。
• “所有文件扩展名”重置筛选器并显示所有文件。
• 切换文件夹时筛选器保持不变（如果扩展名存在）。

重复文件检测

如果启用“检查重复项”，在复制或移动之前会检测重复文件——包括输入文件夹和输出文件夹中的文件（整个目标目录树）。检测基于文件大小和文件内容的逐字节比较；对于图像和视频，会跳过 EXIF 等元数据。日期仅在附加的图像内容比较中起作用。

检测到的重复文件会以带预览图的列表显示。您可以决定是否继续操作（重复文件将被跳过），或取消该操作。

使用附加选项“仅比较图像内容（缓慢）”时，仅比较图像的解码像素数据。关键字、标签或 EXIF 条目等元数据将被忽略。这样还可以检测到在保存关键字时被重新压缩的相同图像。此选项速度慢得多，仅在启用重复检查时才生效。只有相同文件格式且文件大小相近的图像才会被视为候选项。允许的最大大小差异可以在设置（⌘,）中的“图像比较的大小容差”中调整（默认：128 KB）。RAW 格式通常需要更大的值，因为关键字等元数据每个条目可能占用数十 KB。

如果某个程序重新封装或重新导出了视频，即使画面和声音完全相同，它也会被视为独立文件。视频没有图像那样的内容比较。

复制与移动

• 复制：保留原始文件，并在输出文件夹中创建副本。
• 移动：将文件移动到输出文件夹。

在执行前，SwiftRename 会检查目标驱动器上是否有足够的可用存储空间。如果空间不足，将显示警告。您仍然可以继续该操作。

在输入列表下方会显示文件的总大小，在输出列表下方会显示目标驱动器上的可用空间。

撤销与重做

每个文件操作都可以撤销：
• ⌘Z：撤销上一次操作
• ⌘⇧Z：重做已撤销的操作

撤销复制操作时，复制的文件将被移动到废纸篓。撤销移动操作时，文件将被恢复到原来的位置。

进度与取消

处理过程中会显示带百分比的进度条。您可以随时点击“取消”停止操作。已处理的文件将保留，并可以使用 ⌘Z 撤销。

键盘快捷键

• ⌘O：选择输入文件夹
• ⌘⇧O：选择输出文件夹
• ⌘Z：撤销
• ⌘⇧Z：重做
• ⌘,：设置
• ⌘/：显示帮助
• ⌘Q：退出应用程序

小贴士

• 在进行较大的重命名操作之前，请先备份您的文件。
• 使用左侧区域的预览功能，在执行前检查重命名结果。
• 在列表中右键点击文件，可以在 Finder 中显示该文件。
• 在设置（⌘,）中可以调整“图像比较的大小容差”。如遇问题，可在同一处通过“存储日志…”将最近七天的消息存储为文本文件。
