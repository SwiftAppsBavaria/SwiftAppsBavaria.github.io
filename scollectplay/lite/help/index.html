1. Getting Started

What is sCollectPlay Lite?

sCollectPlay Lite is a companion app to sCollect. It focuses purely on playback: no importing, no metadata editing, no synchronization. In return, it reads from three sources: folders, iTunes/Apple Music XML, and sCollect libraries.

First Launch

On first launch, sCollectPlay Lite shows a welcome dialog with notes on playing special formats (see section 4). Afterwards, the source picker appears, where you can choose a library.

Tip: sCollectPlay Lite requires macOS 14.0 or newer and is available in 24 languages.

2. Choosing a Source

sCollectPlay Lite supports three source types, available at startup or later via the File menu:

Scan a Folder

Pick any folder – sCollectPlay Lite scans it recursively for media files and reads metadata directly from the files (AVFoundation for audio/video, EbookTagKit for EPUB/PDF). This is the easiest way to get started without a sCollect library.

  • One source per session: In sCollectPlay Lite, a new folder replaces the current one, and nothing is restored on the next app launch.
  • MKV detection: Files with an .mp4 extension that are actually MKV are detected by their EBML signature and tagged accordingly.
  • Classification by duration: A folder doesn’t reveal whether a file is music or an audiobook. sCollectPlay Lite therefore sorts audio and video by length – audio: up to 10, 10–30, 30–60 and over 60 min; video: up to 5, 5–20, 20–70, 70–210 and over 210 min. E-books and PDFs are recognized by their file extension. If the length can’t be determined, a title is listed under “unknown length”.

Under Settings > Library > Scanned Folders, Refresh reads in only what has changed since the last read: new, modified and removed files.

sCollect Library

Choose the main folder of a sCollect library (the folder that contains the .scollect bundle; for older libraries, the folder with settings.json). sCollectPlay Lite reads the library files, playlists, and settings directly – including configurable field labels and smart playlists. Selecting a sCollect library replaces an active folder scan. You can also double-click the .scollect bundle in the Finder to open the library.

iTunes/Apple Music XML

Choose a Library.xml file or a .musiclibrary bundle. sCollectPlay Lite parses tracks and playlists (standard and smart). System playlists (Master, Distinguished Kind) are skipped. sCollectPlay Lite takes the media types from the XML itself: Music, Audiobook, Podcast, Home Video, Feature Film, Series and Music Video. On open, you’re asked once for access to the corresponding media folder so sCollectPlay Lite can reach the files.

Note: Exactly one kind of source is loaded at a time. Every newly opened source replaces the previous one, including another folder. The window’s title bar shows the kind and name of the source, e.g. Folder “Music” or Library “sCollect”; point to the title to see the full path.

sCollectPlay Lite does not remember any sources: on the next launch, the source picker appears again.

3. Browsing Your Library

Sidebar

The sidebar shows categories and media types as a two-level accordion (e.g. Audio > Music / Audiobook / Podcast) along with all loaded playlists. Switching between media types or playlists updates the track list on the right.

Track List

  • Columns: Which columns are shown is fixed in sCollectPlay Lite.
  • Sort: Click a column header to sort by that column; click again to reverse the order.
  • Column width: Drag the divider in the column header.

Search

The search field in the toolbar filters by title, artist, album, genre, and other fields. In playlists, the search additionally applies to the playlist contents.

4. Playback

Playing Audio

Select an audio entry and press Space or the play button in the player bar. The player bar shows:

  • Cover art, title, and artist
  • Timeline for scrubbing forward and backward
  • Volume control
  • Shuffle and repeat modes
  • For videos additionally: slow motion and frame-step controls

Playing Video

Movies open in a separate video window. Audio tracks and subtitles can be switched in the Playback menu. Use ⌘⌃F to toggle full-screen mode.

External Playback

Some formats are not natively supported by macOS / AVFoundation. sCollectPlay Lite detects this and opens these files automatically in an external player:

  • Special video formats: MKV, AVI, FLV, MPG, MPEG, VOB, DivX
  • Modern codecs: AV1 in MP4 (on older Macs without a hardware decoder)
  • High-resolution audio: DSD (DFF, DSF)
  • Other audio formats: OGG Vorbis, WMA

The preferred player is detected automatically: VLC, IINA, or MPV (in that order). You can override the choice in Settings > Playback/Playlist > External player for unsupported codecs. If none of these players are installed, the default app for the format is used – we recommend VLC Media Player (free, open source).

Playback Modes

  • Shuffle: Plays the current list in random order.
  • Repeat (List): Repeats the entire list after the last track.
  • Repeat (Track): Repeats the current track endlessly.

5. Playlists

sCollectPlay Lite shows all playlists from the loaded library – both standard and smart playlists. Smart playlists are re-evaluated against their stored criteria whenever the item set changes. Editing is not supported; that’s what sCollect is for.

When loading an XML library, both standard and smart playlists are imported. System playlists (Master, Distinguished Kind) are skipped.

6. Deleting Media Files

The track context menu has a Delete media file entry. By default, a confirmation dialog appears beforehand (can be disabled in Settings). The file is moved to the Trash, and the entry is removed from the library.

With Edit > Undo (⌘Z) you bring the file back from the Trash, together with its entry; Edit > Redo (⇧⌘Z) deletes it again.

Network shares: SMB and NFS shares typically have no Trash. sCollectPlay Lite detects this and asks you to confirm before deleting – the file is removed permanently and cannot be restored. You can cancel; in that case, both entry and file remain unchanged.

7. Settings

Open Preferences via sCollectPlay Lite > Settings… (⌘,). They are organized into several tabs; some fields are read-only (showing values from the loaded sCollect library or defaults) – they indicate what would be available in sCollect.

General

  • Confirm deletion: Ask before moving files to the Trash.
  • Language: The app follows the system language. The Open language settings in System Settings button takes you to General > Language & Region; in the «Applications» section there you choose a separate language for sCollectPlay Lite.
  • Artwork folder: Cover images normally sit in a folder «Artworks» inside the library. With Choose… you specify another folder; it applies only to the loaded library, and Remove detaches it again.
  • Media Folder: appears only if the library uses folders outside its own folder. For each folder, Choose grants access and Remove withdraws it.

Below these, grayed out, are the settings that only sCollect can change (such as album covers, books & PDFs, multiple values, duplicates).

Library

At the top, the three sources are listed one below the other: Scanned Folders, XML Library, and sCollect Library. Only one is active at a time – its circle is filled. Clicking another circle opens the selection dialog for that kind.

  • Scanned Folders: the path, number of tracks and time of the last read for each folder, plus Refresh.
  • sCollect Library: the Storage location of the loaded library, with Change….

Below these, grayed out, are the fields that only sCollect offers (Import, Media Folder, Actions).

Playback/Playlist

  • Video window always on top: The video window always stays above all other windows.
  • Pause video when minimized: Pauses playback while the video window is minimized and resumes it when the window is restored.
  • Volume during slow motion / frame step: Volume reduction in dB during slow-motion and single-frame mode.
  • External player for unsupported codecs: Preferred player for codecs that AVFoundation cannot decode (see section 4). Detected: VLC, IINA, and MPV.

Category Labels and Field Labels

These two tabs show the names of the categories and media types, and of the fields, as the loaded sCollect library defines them. They can only be changed in sCollect.

Statistics

The number of tracks per media type and of playlists per category, plus the total number of tracks.

Note: Disabled fields show settings that are available in sCollect (the main app) but not in sCollectPlay Lite – for example tag editing, import modes, or sync options.
