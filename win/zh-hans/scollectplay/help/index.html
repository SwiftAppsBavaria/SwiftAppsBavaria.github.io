sCollectPlay 手册

入门

sCollectPlay 播放你的媒体——来自任意文件夹、iTunes XML 文件和 sCollect 媒体库。导入、编辑元数据和同步不在其中；这些由 sCollect 负责。

启动时会出现来源选择，其中有三个按钮：“扫描文件夹…”、“打开 XML 媒体库…”和“选择 sCollect 媒体库…”。“文件”菜单中也有相同的命令。

下次启动时，sCollectPlay 会自动加载上次使用的来源。

如果在启动时按住 Shift 键，则会改为显示来源选择。如果媒体库或扫描的文件夹位于网络上，sCollectPlay 会先询问是否加载该来源——可以在 设置 > 通用 中通过“启动时提示网络媒体库”关闭此询问。如果驱动器在 20 秒内没有响应，sCollectPlay 会给出提示并显示来源选择。

在“文件”菜单中，每个命令下方列出最近使用的文件夹、媒体库和 XML 文件，各最多十个。“清空列表”会清空一个列表；已无法访问的项目在单击时会消失。

扫描文件夹

选择任意文件夹。sCollectPlay 会在该文件夹及其子文件夹中搜索音频、视频、电子书和 PDF 文件，并直接从文件中读取标题、艺术家、专辑和时长。对于某些格式——例如 WMA、OGG、AIFF 或 AVI——它只读取时长，此时以文件名作为标题。隐藏文件不包括在内。

按内容分类：sCollectPlay 根据文件对自身的描述来给音频分类：.m4b 文件以及风格为 Audiobook、Audio Theatre 或 Spoken Word（也包括德语，例如 Hörbuch、Hörspiel 或 Kabarett）的项目列在“有声书”下，播客以及风格为 Podcast 或 Speech 的项目列在“播客”下，其余全部列在“音乐”下。音乐视频、电影和剧集根据媒体类型识别（例如 iTunes 写入文件的媒体类型），剧集还可根据文件名中的“S01E02”识别。注明了摄像机或带有 IMG_1234 这类相机文件名的影片列在“摄像机”下，其余影片列在“家庭录像”下。电子书和 PDF 则根据文件扩展名识别。边栏只显示含有内容的类型。

自行选择类型：如果某个项目归类有误，请将其从列表拖到边栏中的另一个类型上 – 拖动时，空的类型也会显示在那里。sCollectPlay 会为该文件记住这一设置，下次读取文件夹时同样有效；文件本身不会被更改。

如果扫描没有找到可以播放或阅读的内容，sCollectPlay 会给出提示。

“文件 > 更新已扫描的文件夹”（Ctrl+R）只读取自上次读取以来发生的更改——新增、更改和移除的文件——并报告结果。暂时无法访问的文件夹会保留其之前的状态。

列表上方最右侧的 ↻ 按钮也能完成同样的操作。

可以依次扫描多个文件夹；它们的内容会一起显示。标题栏显示第一个文件夹的名称，并统计其余文件夹的数量。

启动时，sCollectPlay 按上次读取时的状态显示已扫描的文件夹，而不重新搜索。如果在加载了媒体库或 XML 时扫描文件夹，之前扫描过的文件夹也会一并恢复。

sCollect 媒体库

选择 sCollect 媒体库的主文件夹——即包含 .scollect 包的文件夹。sCollectPlay 会读取项目、播放列表和设置。

sCollectPlay 不会更改媒体库本身。当你为曲目评分，或把音乐、有声书或影片播放到结束时，它会连同日期和时间把这一点记录在媒体库文件夹中的 rueckmeldungen.json 文件里 – 无论你打开的是主媒体库还是副本。sCollect 会在打开主媒体库时、在投影之前以及在修复同步错误…之前接收这些信息：评分以较新的为准，播放次数相加。随后 sCollect 把评分写入文件，并把一切传给所有副本。在此之前，sCollectPlay 就已经显示它自己的评分和播放次数。

如果媒体库是在 Mac 上创建的，其中记录的是 Mac 路径。sCollectPlay 通过媒体库文件夹查找文件；对于位于其外部的媒体，只要能从媒体库推断出来，它就会把 Mac 路径对应到相应的 Windows 文件夹。找不到的文件仍保留在列表中，但无法播放。

iTunes XML

选择 iTunes for Windows 创建的 XML 文件（iTunes Music Library.xml——在 iTunes 的高级偏好设置中开启共享 XML 文件后，iTunes 会写入该文件），或从 Apple Music 导出的 Library.xml。sCollectPlay 会读取项目和播放列表——智能播放列表按 iTunes 最后一次保存的内容作为固定列表读取——并跳过“媒体库”或“音乐”等系统列表。媒体类型来自 XML 本身：音乐、有声书、播客、家庭录像、电影、剧集和音乐视频。

在 Mac 上导出的 XML 指向 Mac 路径；sCollectPlay 在 Windows 上找不到这些文件。

每次只加载一种来源。打开媒体库或 XML 会替换之前加载的内容。窗口标题栏显示来源的类型和名称，例如：文件夹“音乐”、媒体库“sCollect”。

浏览媒体库

边栏以折叠面板的形式显示类别和媒体类型——每次只展开一个类别。在展开的类别下方，其播放列表位于“播放列表”区域中；没有类别的播放列表位于最下方。

单击列标题即按该列排序，再次单击则反转顺序。按住 Shift 可添加一个排序级别，按住 Alt 则移除一个；列标题上下文菜单中的“重置排序”只保留第一级。sCollectPlay 会为每种媒体类型记住排序。

搜索框按标题、艺术家、专辑、流派及其他字段筛选——在播放列表中也可以。

评分：使用 sCollect 媒体库时，点击评分列中的星星：第一次点击设为一颗完整的星，第二次设为半颗星，第三次清除评分。要同时为多首曲目评分，请先选中它们，然后右键点击 > 评分。对于扫描的文件夹和 XML 媒体库，星星仅用于显示。

删除：对于扫描的文件夹，右键点击 > 删除媒体文件 会将文件移到回收站并从列表中移除；如果选中了多首曲目，则全部删除。sCollectPlay 是否先询问，可在 设置 > 通用 > 确认删除 中设置。如果文件位于没有回收站的驱动器上，例如网络或 U 盘，它总会询问，因为在那里文件会被永久删除。只有从回收站还原文件才能撤销删除；随后使用 更新已扫描的文件夹 即可让它重新出现在列表中。在 sCollect 媒体库和 XML 媒体库中，sCollectPlay 不会删除任何内容——那里的文件分别归 sCollect 和 iTunes 管理。

可通过列标题上下文菜单中的“自定义列…”选择显示哪些列；其中的“最佳宽度”可将宽度调整到合适大小。用鼠标拖动可更改宽度和顺序。sCollectPlay 会在这台电脑上记住这些设置；默认使用 sCollect 媒体库中的列。

列浏览器会在项目列表上方显示选择列：流派、艺术家、专辑、作曲和分组。列表右上方的按钮用于打开和关闭它；它在播放列表中同样有效。

• 单击某个值即按其筛选，Ctrl+单击可添加或移除一个值。同一列中的多个值按“或”组合，不同列之间按“与”组合。最上面一行“全部”会取消该列的选择。
• 如果某列条目非常多，sCollectPlay 会按首字母将它们归入可展开的组。

播放

双击项目或按 Enter 键即可播放；空格键用于开始和暂停。播放器栏显示封面、标题和艺术家、用于跳转的时间轴，以及随机播放、上一曲、后退 10 秒、停止、播放、前进 10 秒、下一曲和重复（关、列表、单曲）按钮，另有音量；播放影片时还会增加慢动作和逐帧。只要你没有选择其他内容，列表中的选择就会随正在播放的项目移动。

影片会在单独的视频窗口中打开。移动鼠标时会显示其控制栏：时间、上一曲和下一曲、后退和前进 10 秒、慢动作、逐帧、音轨（有多个时）、字幕（如有）和全屏。F11 和“播放”菜单中的快捷键在这里同样有效，按 Esc 退出全屏。关闭视频窗口即停止播放。影片结束时窗口保持打开，除非已为其媒体类型打开“结束后继续播放”——此时会接着播放下一曲，播放到列表末尾时，窗口会自动关闭。

结束后继续播放：一首曲目结束后是否继续播放下一首，由你按媒体类型设置，位于设置 > 播放/播放列表 > 结束后继续播放。默认情况下，所有音频类型和音乐视频为开启，电影、剧集、家庭录像和摄像机影片为关闭 – 此时影片会停在结尾（或停止标记处）。重复（单曲）仍会重复播放。sCollectPlay 会记住你在这里所做的更改；其他所有媒体类型沿用媒体库的设置。

通过项目的上下文菜单，你可以立即播放、下一首播放或将其添加到播放队列。上下文菜单中还有“在资源管理器中显示”和“用默认程序打开”。

sCollectPlay 使用 Windows 的媒体播放服务进行播放，它支持大多数格式——MP3、AAC/M4A、FLAC、OGG、Opus 和 WMA，以及 MP4、MKV、AVI、WMV、MPG、TS 和 VOB。Windows 自身无法播放的内容——例如 AIFF、CAF、DSD（DSF、DFF）、FLV 或受复制保护的影片——sCollectPlay 会用该文件类型的默认应用打开。书籍和 PDF 也会在默认应用中打开。

播放列表

来源的播放列表列在边栏的“播放列表”下——普通播放列表按保存的顺序排列，智能播放列表按其规则计算。它们只能在 sCollect 中更改。

在“我的播放列表”下，无论加载的是哪种来源，你都可以创建自己的播放列表：

• 创建：“我的播放列表”旁边的加号提供“新建播放列表…”和“新建智能播放列表…”。
• 添加：项目列表上下文菜单中的“添加到播放列表”会添加所选项目，或新建一个播放列表；在你自己的播放列表中，“从播放列表移除”可将其再次移除。
• 智能播放列表会按规则自动组合；播放列表上下文菜单中的“编辑…”可更改规则。
• 播放列表的上下文菜单中还有“重命名…”（适用于普通播放列表）和“删除播放列表”。在边栏中，按 F2 可重命名所选播放列表；按 Delete 会在确认后删除，按 Ctrl+Delete 则与上下文菜单中的“删除播放列表”一样不经确认直接删除。“编辑”>“撤销”（Ctrl+Z）可恢复已删除的播放列表。

sCollectPlay 将你自己的播放列表保存在这台电脑上，绝不会保存在媒体库或 XML 中。即使重新扫描后，它也会按文件路径重新找到其中的项目。

播放列表上下文菜单中的“导出到 VLC/设备…”——或“文件 > 将播放列表导出到 VLC/设备…”——会把整个播放列表的音频和视频文件（即使搜索当前正在筛选）复制到你选择的文件夹，例如 SD 卡或 U 盘。其中会创建一个以播放列表命名的子文件夹，按艺术家和专辑整理，并附带一个使用相对路径的 .m3u8 播放列表文件。书籍和杂项会被跳过并计数。

• 如果你再次将同一播放列表导出到同一位置，sCollectPlay 只复制新增或大小不同的内容，并重新写入列表。你从播放列表中移除的项目仍作为文件保留在文件夹中。
• “取消”会结束导出；此时列表包含到那时为止已复制的项目。

不要拆散导出的文件夹——列表只能相对于自身所在位置找到其中的项目。这样，VLC 和任何能读取 M3U8 列表的播放器都会显示该播放列表。

设置

“文件 > 设置…”（Ctrl+,）可打开设置。灰色显示的值来自已加载的 sCollect 媒体库（未加载媒体库时为默认值），只能在 sCollect 中更改。

• 通用：语言（跟随 Windows），以及——对于在 Mac 上创建的媒体库——媒体文件夹。你可以在那里为媒体库的每个 Mac 文件夹指定其文件在这台电脑上所在的 Windows 文件夹；仍缺少的会以红色显示，并附项目数。
• 媒体库：三种来源类型。单击另一个圆圈即可切换来源。对于已扫描的文件夹，每个文件夹都会显示其项目数和读取时间；“更新”只读取更改的内容。
• 播放/播放列表：“视频窗口始终在最前”和“最小化时暂停视频”。
• 类别标签、字段标签和统计显示已加载来源的名称和数量。

在完整版中，你还可以在那里移除单个文件夹、用“全部更新”一次更新所有文件夹，以及加载最近使用的媒体库之一。单击某个圆圈会打开该类型最近使用的来源。

键盘快捷方式

空格键 – 播放 / 暂停
Enter – 播放所选项目
Ctrl+→ – 下一曲
Ctrl+← – 上一曲
Ctrl+↑ – 增大音量
Ctrl+↓ – 减小音量
F11 – 视频全屏开/关
Esc – 退出视频全屏
Ctrl+R – 更新已扫描的文件夹
Ctrl+Shift+O – 选择 sCollect 媒体库…
Ctrl+, – 设置
F1 – 帮助
Alt+F4 – 退出
