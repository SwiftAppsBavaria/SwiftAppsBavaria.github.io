sVectorLift 手册

概览

sVectorLift 可打开 CorelDRAW 时代的旧矢量剪贴画，并将其转换为 SVG——即当今程序仍能使用的图形。请在左侧选择一个文件夹，右侧便会以预览形式显示其中的剪贴画。所选图形可导出到你指定的目标文件夹。

支持的格式

• CorelDRAW 文稿（.cdr），版本 6 至 9
• Corel Binary Meta File（.cmx）——也包括旧的 CDRX 变体
• Windows Metafile（.wmf）
• Computer Graphics Metafile（.cgm）
• QuickDraw 3D 图元文件（.3dm、.3dmf）——将渲染为图像
• Scalable Vector Graphics （.svg）——直接显示

许多扩展名为 .cdr 的文件其实根本不是 CorelDRAW 文稿，而是 CMX。常见的转换器正是在这一点上失败——而 sVectorLift 两者都能读取。

sVectorLift 打开 CorelDRAW 模板（.cdt）的方式与 CorelDRAW 文稿相同。

选择文件夹

1. 点按“选择文件夹 …”（或 Ctrl+O），打开存放剪贴画收藏的文件夹。下方会显示文件夹树。
2. 点按树中的文件夹即可载入其中的剪贴画。用箭头展开子文件夹。
3. 下次启动时，会重新打开上次使用的文件夹，包括上次打开的子文件夹和标记的文件。通过“文件 → 最近使用的文件夹”可直接返回以前的收藏。

也可以从文件资源管理器打开单个文件（“打开方式”或双击）：如果它位于当前显示的文件夹中，sVectorLift 会跳到它；否则会单独显示该文件，只有在切换到概览时才转到它所在的文件夹。

用“筛选（名称或关键词）”字段可按名称或关键词隐藏剪贴画。

将分隔线朝网格拖动即可更改边栏宽度。用边栏顶部的按钮（或 Ctrl+Shift+S）可完全隐藏边栏，让剪贴画使用整个窗口宽度。

两个文件夹按钮旁边都会显示所选路径。点按可完整显示以便复制，右键点按可直接转到文件资源管理器。

要重新整理收藏，请将标记的剪贴画拖到树中的文件夹上：在同一驱动器上会移到那里，拖到其他驱动器则会复制。按住 Ctrl 键可复制，按住 Shift 键可移动，与文件资源管理器相同。你也可以将它们拖到文件资源管理器中。在文件资源管理器中所做的更改会在“刷新”（F5 或边栏顶部的圆形箭头）后显示。

用 Ctrl+Z 可撤消重新整理：移动的项目会回到原来的位置，副本则由 sVectorLift 移到回收站。替换了现有文件的副本会保留。拖到文件资源管理器中的项目会被复制，原件仍保留在收藏中。如果拖动时按住 Shift 键，则会移动，sVectorLift 无法撤消此操作。

查看剪贴画

• 使用右上角的滑块可调整缩略图的大小。
•“详细视图”（或连按两下某个剪贴画）会大幅显示单个图形。使用方向键 ← → 可浏览该文件夹，连按两下即可返回“概览”。
• 缩略图只有在你看到它们时才会计算。因此在非常大的文件夹中会先出现占位图，随后逐步填充。

选择

选择方式与文件资源管理器相同：
• 点按：选择单个剪贴画
• Ctrl+点按：将单个剪贴画加入或移出所选内容
• Shift+点按：选择连续范围
• 在空白处拖动：拉出选择矩形
• Ctrl+A：选择文件夹中的所有剪贴画
• 点按空白处：取消选择

导出

1. 在“2. 导出”下选择目标文件夹。点按路径可完整显示，必要时可转到文件资源管理器。
2. “导出所选项”写出标记的剪贴画，“全部导出”写出整个文件夹。

矢量图形存储为 .svg。纯栅格图像和 3D 模型存储为 .png，以免丢失任何内容。SVG 文件已经是目标格式，因此对其停用导出。

通过上下文菜单（右键点按剪贴画）可导出到同一目标文件夹、在文件资源管理器中显示文件、重命名文件或将其移到回收站。如果尚未设置目标文件夹，会询问一次。

如果目标文件已经存在，sVectorLift 会先询问：“替换”、“两者都保留”（在旁边另存为“名称 2.svg”）、“跳过”或“取消”。文件有多个时，用“应用于全部”就能把你的回答用于整个导出过程。之后导出会在边栏显示进度条，你可以随时取消。

用 Ctrl+Z 可撤消重命名，用 Ctrl+Y 可重做——前提是文件仍在打开的收藏中。导出期间，重命名和删除会暂时锁定：导出使用的是开始时有效的文件名。

使用“导出为 PNG”或“导出为 JPG”（在上下文菜单和“文件”菜单中），每个剪贴画（即使是 SVG 文件）都会按设置中的渲染大小计算为图像。图像存入同一目标文件夹。

导出文件夹结构

要转换整个文件夹及其子文件夹，请使用“导出文件夹结构”窗口。通过“文件 → 导出文件夹结构 …”或边栏中的同名按钮打开它，在其中选择源文件夹和目标文件夹，然后点按“全部导出”开始。目标中会创建相同的文件夹结构；SVG 文件原样复制，不包含支持文件的文件夹不会创建。不会询问任何问题：目标中已有的内容会被跳过。如果同一文件夹中多个文件同名，之后的每个文件都会带上原来的扩展名，例如“geometry (cmx).svg”。

设置

在“文件 → 设置 …”（Ctrl+,）中设置 3D 模型的渲染大小。

3D 模型没有矢量形式；导出时会计算为图像。数值越大，PNG 越清晰，导出所需时间也越长。允许 256 到 8192 像素，默认值为 1024。

在同一窗口中还有转到 Windows 语言设置的按钮。

在“文件类型”中可以看到 Windows 双击旧格式时使用哪个应用。可在 Windows 设置的“默认应用”中更改；按钮会直接带你到那里。

相同的渲染尺寸也适用于“导出为 PNG”和“导出为 JPG”。

键盘快捷键

• Ctrl+O：选择文件夹
• Ctrl+A：选择所有剪贴画
• ← →：在详细视图中翻阅文件夹
• 双击：在概览和详细视图之间切换
• Ctrl+Shift+S：显示或隐藏边栏
• Ctrl+Z：撤消重命名或重新整理
• Ctrl+Y：重做重命名或重新整理
• Ctrl+,：设置
• F1：显示本帮助
• Alt+F4：关闭窗口（询问后退出应用）

语言

应用的语言跟随 Windows 显示语言。若要更改：设置 → 时间和语言 → 语言和区域。

如果剪贴画未显示

• 若显示问号而非预览，表示该文件无法读取——例如文件已损坏，或包含 sVectorLift 无法识别的格式。
• sVectorLift 专为剪贴画收藏而设计：图画、符号、插图。CorelDRAW 的多页手册和印刷模板并非目标对象，可能显示不完整。

动画 SVG

对于动画 SVG 文件，sVectorLift 会以静态图像显示，动画本身不会播放。
