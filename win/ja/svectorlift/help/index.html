sVectorLift マニュアル

概要

sVectorLift は、CorelDRAW 時代の古いベクタークリップアートを開き、SVG に変換します。これにより、今日のアプリケーションでも扱える図形になります。左側でフォルダを選択すると、右側にクリップアートがプレビューとして表示されます。選択したグラフィックは、お好きな書き出し先フォルダに書き出せます。

対応しているフォーマット

• CorelDRAW 書類（.cdr）バージョン 6 〜 9
• Corel Binary Meta File（.cmx）— 古い CDRX 形式にも対応
• Windows Metafile（.wmf）
• Computer Graphics Metafile（.cgm）
• QuickDraw 3D メタファイル（.3dm、.3dmf）— 画像としてレンダリングされます
• Scalable Vector Graphics（.svg） — そのまま表示されます

拡張子が .cdr のファイルの多くは、実際には CorelDRAW 書類ではなく CMX です。一般的なコンバータはまさにこの点で失敗しますが、sVectorLift は両方を読み込めます。

sVectorLift は、CorelDRAW テンプレート（.cdt）も CorelDRAW 書類と同じように開きます。

フォルダを選択

1. 「フォルダを選択 …」をクリック（または Ctrl+O）して、クリップアートのコレクションがあるフォルダを開きます。その下にフォルダツリーが表示されます。
2. ツリーでフォルダをクリックすると、そのクリップアートが読み込まれます。サブフォルダは矢印で展開します。
3. 次回の起動時には、最後に使ったフォルダが再び開きます。最後に開いたサブフォルダと選択していたファイルも元どおりです。「ファイル → 最近使ったフォルダ」から以前のコレクションにすぐ戻れます。

エクスプローラーから単一のファイルを開くこともできます（「プログラムから開く」またはダブルクリック）。表示中のフォルダにあれば sVectorLift はそのファイルに移動し、そうでなければファイルを単独で表示して、概要に切り替えたときに初めてそのフォルダに移動します。

「フィルタ（名前またはキーワード）」欄で、名前やキーワードによってクリップアートを絞り込めます。

サイドバーの幅は、区切り線をグリッドの方へドラッグして変更します。サイドバー上部のボタン（または Ctrl+Shift+S）でサイドバーを完全に隠すと、クリップアートがウィンドウの幅いっぱいに表示されます。

2 つのフォルダボタンの横には、選んだパスが表示されます。クリックするとコピー用に全体が表示され、右クリックするとエクスプローラーで直接開きます。

コレクションを整理し直すには、選択したクリップアートをツリー内のフォルダにドラッグします。同じドライブならそのフォルダに移動され、別のドライブならコピーされます。Ctrl キーを押したままにするとコピー、Shift キーを押したままにすると移動になります（エクスプローラーと同じです）。エクスプローラーにドラッグすることもできます。エクスプローラーで行った変更は、「更新」（F5 またはサイドバー上部の円形の矢印）の後に表示されます。

整理し直した操作は Ctrl+Z で元に戻せます。移動した項目は元の場所に戻り、コピーは sVectorLift がごみ箱に移動します。既存のファイルを置き換えたコピーは、そのまま残ります。エクスプローラーにドラッグしたものはコピーされ、元のファイルはコレクションに残ります。Shift キーを押したままドラッグすると移動になります。この操作は sVectorLift では元に戻せません。

クリップアートを表示する

• 右上のスライダで、サムネールの大きさを調整できます。
•「詳細表示」（またはクリップアートをダブルクリック）すると、1 つのグラフィックが大きく表示されます。矢印キー ← → でフォルダ内を移動でき、ダブルクリックで「概要」に戻ります。
• サムネールは、表示されるときに初めて計算されます。そのため、非常に大きなフォルダではまずプレースホルダが表示され、順次埋まっていきます。

選択

選択はエクスプローラーと同じように行えます:
• クリック: クリップアートを 1 つ選択
• Ctrl+クリック: クリップアートを個別に選択に追加または解除
• Shift+クリック: 連続した範囲を選択
• 空白部分でドラッグ: 選択範囲の四角形を描く
• Ctrl+A: フォルダ内のすべてのクリップアートを選択
• 空白部分をクリック: 選択を解除

書き出す

1. 「2. 書き出し」で書き出し先フォルダを選びます。パスをクリックすると全体が表示され、必要に応じてエクスプローラーで開けます。
2. 「選択項目を書き出す」は選択したクリップアートを、「すべて書き出す」はフォルダ全体を書き出します。

ベクターグラフィックは .svg として保存されます。純粋なラスター画像と 3D モデルは、何も失われないよう .png として保存されます。SVG ファイルはすでに書き出し形式なので、書き出しは無効です。

コンテキストメニュー（クリップアートを右クリック）から、同じ書き出し先フォルダへの書き出し、エクスプローラーでの表示、名前の変更、ごみ箱への移動ができます。書き出し先フォルダがまだ設定されていない場合は、一度だけ尋ねられます。

書き出し先のファイルがすでにある場合、sVectorLift は先に確認します。「置き換える」、「両方とも残す」（隣に「名前 2.svg」として書き出します）、「スキップ」、「キャンセル」です。複数のファイルのときは「すべてに適用」で、答えをその実行全体に引き継げます。その後、書き出しはサイドバーの進捗バーとともに進み、いつでも中止できます。

名前の変更は Ctrl+Z で元に戻し、Ctrl+Y でやり直せます（ファイルが開いているコレクション内にある間）。書き出し中は、名前の変更と削除が一時的にロックされます。書き出しは開始時のファイル名で処理するためです。

「PNG として書き出す」または「JPG として書き出す」（コンテキストメニューと「ファイル」メニュー）を使うと、SVG ファイルも含めすべてのクリップアートが、設定のレンダリングサイズで画像として計算されます。画像は同じ書き出し先フォルダに保存されます。

フォルダ構造を書き出す

サブフォルダを含むフォルダ全体は、「フォルダ構造を書き出す」ウィンドウで変換します。「ファイル → フォルダ構造を書き出す …」またはサイドバーの同名のボタンで開き、そこで元のフォルダと書き出し先フォルダを選んで「すべて書き出す」で開始します。書き出し先には同じフォルダ構造が作られます。SVG ファイルはそのままコピーされ、対応ファイルのないフォルダは作成されません。確認はありません。書き出し先にすでにあるものはスキップされます。同じフォルダ内に同じ名前のファイルが複数ある場合、2 つ目以降には元の拡張子が付きます（例:「geometry (cmx).svg」）。

設定

「ファイル → 設定 …」（Ctrl+,）で 3D モデルのレンダリングサイズを設定します。

3D モデルにはベクター形式がないため、書き出し時に画像として計算されます。値が大きいほど PNG は鮮明になりますが、書き出しに時間がかかります。256〜8192 ピクセルを指定でき、既定値は 1024 です。

同じウィンドウに、Windows の言語設定を開くボタンもあります。

「ファイルの種類」では、古い形式をダブルクリックしたときに Windows がどのアプリで開くかを確認できます。変更は Windows の設定の「既定のアプリ」で行います。ボタンから直接開けます。

同じレンダリングサイズが「PNG として書き出す」と「JPG として書き出す」にも適用されます。

キーボードショートカット

• Ctrl+O: フォルダを選択
• Ctrl+A: すべてのクリップアートを選択
• ← →: 詳細表示でフォルダ内を移動
• ダブルクリック: 概要と詳細表示を切り替え
• Ctrl+Shift+S: サイドバーの表示/非表示
• Ctrl+Z: 名前の変更または整理し直しを元に戻す
• Ctrl+Y: 名前の変更または整理し直しをやり直す
• Ctrl+,: 設定
• F1: このヘルプを表示
• Alt+F4: ウィンドウを閉じる（確認後にアプリを終了）

言語

アプリの言語は Windows の表示言語に従います。変更するには、「設定」→「時刻と言語」→「言語と地域」を開いてください。

クリップアートが表示されない場合

• プレビューの代わりに疑問符が表示される場合、そのファイルは読み込めませんでした。ファイルが壊れているか、sVectorLift が対応していないフォーマットが含まれている可能性があります。
• sVectorLift はクリップアートのコレクション（絵、シンボル、イラスト）のために作られています。CorelDRAW の複数ページのパンフレットや印刷用テンプレートは対象ではなく、不完全に表示されることがあります。

アニメーション SVG

アニメーション SVG ファイルは、sVectorLift では静止画として表示され、動き自体は再生されません。
