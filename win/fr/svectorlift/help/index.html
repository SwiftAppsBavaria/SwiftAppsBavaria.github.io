Manuel de sVectorLift

Vue d’ensemble

sVectorLift ouvre les anciens cliparts vectoriels de l’époque CorelDRAW et les convertit en SVG — des images que les programmes actuels peuvent de nouveau exploiter. Choisissez un dossier à gauche : les cliparts apparaissent à droite sous forme d’aperçus. Vous exportez les images sélectionnées dans un dossier de destination de votre choix.

Formats pris en charge

• Documents CorelDRAW (.cdr), versions 6 à 9
• Corel Binary Meta File (.cmx) — y compris l’ancienne variante CDRX
• Windows Metafile (.wmf)
• Computer Graphics Metafile (.cgm)
• Métafichiers QuickDraw 3D (.3dm, .3dmf) — rendus sous forme d’image
• Scalable Vector Graphics (.svg) — s’affichent directement

De nombreux fichiers portant l’extension .cdr ne sont en réalité pas des documents CorelDRAW, mais des CMX. C’est précisément là que les convertisseurs habituels échouent — sVectorLift lit les deux.

sVectorLift ouvre les modèles CorelDRAW (.cdt) exactement comme les documents CorelDRAW.

Choisir un dossier

1. Cliquez sur « Choisir un dossier… » (ou Ctrl+O) pour ouvrir le dossier de votre collection de cliparts. L’arborescence des dossiers apparaît en dessous.
2. Un clic sur un dossier de l’arborescence charge ses cliparts. Dépliez les sous-dossiers avec la flèche.
3. Au prochain démarrage, le dernier dossier utilisé s’ouvre à nouveau — avec le dernier sous-dossier ouvert et le fichier sélectionné. Avec « Fichier → Dossiers récents », vous revenez directement à une collection précédente.

Vous pouvez aussi ouvrir un seul fichier depuis l’Explorateur de fichiers (« Ouvrir avec » ou double-clic) : s’il se trouve dans le dossier affiché, sVectorLift y saute ; sinon, il l’affiche seul et ne passe à son dossier que lorsque vous revenez à la vue d’ensemble.

Le champ « Filtrer (nom ou mot-clé) » masque les cliparts par nom ou mot-clé.

Pour changer la largeur de la barre latérale, faites glisser le séparateur vers la grille. Le bouton en haut de la barre — ou Ctrl+Maj+S — la masque entièrement pour que les cliparts occupent toute la largeur de la fenêtre.

Le chemin choisi s’affiche à côté des deux boutons de dossier. Un clic l’affiche en entier pour le copier, un clic droit mène directement à l’Explorateur de fichiers.

Pour réorganiser votre collection, faites glisser les cliparts sélectionnés sur un dossier de l’arborescence : sur le même lecteur, ils y sont déplacés ; vers un autre lecteur, ils sont copiés. Maintenez la touche Ctrl enfoncée pour copier, Maj pour déplacer — comme dans l’Explorateur de fichiers. Vous pouvez aussi les faire glisser dans l’Explorateur de fichiers. Les modifications effectuées dans l’Explorateur de fichiers apparaissent après « Actualiser » (F5 ou la flèche circulaire en haut de la barre latérale).

Avec Ctrl+Z, vous annulez la réorganisation : les éléments déplacés reprennent leur ancien emplacement, et sVectorLift place les copies dans la Corbeille. Une copie qui a remplacé un fichier existant est conservée. Ce que vous faites glisser dans l’Explorateur de fichiers est copié ; l’original reste dans la collection. Si vous maintenez la touche Maj enfoncée, il est déplacé — sVectorLift ne peut pas l’annuler.

Consulter les cliparts

• Le curseur en haut à droite permet de régler la taille des aperçus.
• « Vue détaillée » (ou un double-clic sur un clipart) affiche une image en grand. Les touches fléchées ← → permettent de parcourir le dossier ; un double-clic ramène à la Vue d’ensemble.
• Les aperçus ne sont calculés qu’au moment où vous les voyez. Dans les dossiers très volumineux, des espaces réservés apparaissent donc d’abord, puis se remplissent progressivement.

Sélectionner

La sélection fonctionne comme dans l’Explorateur de fichiers :
• Clic : sélectionner un seul clipart
• Ctrl+clic : ajouter des cliparts à la sélection ou les en retirer
• Maj+clic : sélectionner une plage continue
• Glisser dans le vide : tracer un rectangle de sélection
• Ctrl+A : sélectionner tous les cliparts du dossier
• Clic dans le vide : annuler la sélection

Exporter

1. Choisissez un dossier de destination sous « 2. Exportation ». Un clic sur le chemin l’affiche en entier et mène si besoin à l’Explorateur de fichiers.
2. « Exporter la sélection » écrit les cliparts sélectionnés, « Tout exporter » le dossier entier.

Les graphiques vectoriels sont enregistrés en .svg. Les images purement matricielles — et les modèles 3D — sont enregistrées en .png pour que rien ne se perde. Les fichiers SVG sont déjà au format cible ; l’exportation est désactivée pour eux.

Le menu contextuel (clic droit sur un clipart) permet d’exporter dans le même dossier de destination, d’afficher le fichier dans l’Explorateur de fichiers, de le renommer ou de le déplacer vers la Corbeille. Si aucun dossier de destination n’est encore défini, il vous est demandé une fois.

Si un fichier de destination existe déjà, sVectorLift vous demande d’abord quoi faire : « Remplacer », « Conserver les deux » (écrit à côté, sous la forme « Nom 2.svg »), « Ignorer » ou « Annuler ». Pour plusieurs fichiers, « Appliquer à tout » reprend votre réponse pour toute la série. L’exportation se déroule ensuite avec une barre de progression dans la barre latérale, et vous pouvez l’arrêter à tout moment.

Ctrl+Z annule un renommage et Ctrl+Y le rétablit — tant que le fichier se trouve dans la collection ouverte. Pendant une exportation, renommer et supprimer sont brièvement bloqués : l’exportation travaille avec les noms de fichiers valables à son démarrage.

Avec « Exporter en PNG » ou « Exporter en JPG » — dans le menu contextuel et dans le menu « Fichier » —, chaque clipart est calculé comme image, même un fichier SVG, à la taille de rendu des paramètres. Les images vont dans le même dossier de destination.

Exporter la structure de dossiers

Pour convertir un dossier entier avec ses sous-dossiers, utilisez la fenêtre « Exporter la structure de dossiers ». Ouvrez-la via « Fichier → Exporter la structure de dossiers… » ou le bouton du même nom dans la barre latérale, choisissez-y les dossiers source et de destination, puis lancez avec « Tout exporter ». La même structure de dossiers est créée dans la destination ; les fichiers SVG sont copiés tels quels et les dossiers sans fichiers pris en charge ne sont pas créés. Aucune question n’est posée : ce qui existe déjà dans la destination est ignoré. Si plusieurs fichiers d’un dossier portent le même nom, chaque fichier supplémentaire reçoit son extension d’origine, par exemple « geometry (cmx).svg ».

Paramètres

Dans « Fichier → Paramètres… » (Ctrl+,), vous réglez la taille de rendu des modèles 3D.

Les modèles 3D n’ont pas de forme vectorielle ; pour l’exportation, ils sont calculés comme image. Plus la valeur est grande, plus le PNG est net — et plus l’exportation dure. Les valeurs autorisées vont de 256 à 8192 pixels, la valeur par défaut est 1024.

Dans la même fenêtre se trouve aussi le bouton vers les paramètres de langue de Windows.

Sous « Types de fichiers », vous voyez avec quelle application Windows ouvre les anciens formats par double-clic. Cela se modifie dans « Applications par défaut » des Paramètres Windows ; le bouton y mène directement.

La même taille de rendu s’applique à « Exporter en PNG » et à « Exporter en JPG ».

Raccourcis clavier

• Ctrl+O : choisir un dossier
• Ctrl+A : sélectionner tous les cliparts
• ← → : parcourir le dossier en vue détaillée
• Double-clic : basculer entre vue d’ensemble et vue détaillée
• Ctrl+Maj+S : afficher ou masquer la barre latérale
• Ctrl+Z : annuler le renommage ou la réorganisation
• Ctrl+Y : rétablir le renommage ou la réorganisation
• Ctrl+, : paramètres
• F1 : afficher cette aide
• Alt+F4 : fermer la fenêtre (quitte l’application après confirmation)

Langue

La langue de l'app suit la langue d'affichage de Windows. Pour la modifier : Paramètres → Heure et langue → Langue et région.

Si un clipart n’apparaît pas

• Un point d’interrogation à la place d’un aperçu signifie que le fichier n’a pas pu être lu — par exemple parce qu’il est endommagé ou qu’il contient un format que sVectorLift ne connaît pas.
• sVectorLift est conçu pour les collections de cliparts : dessins, symboles, illustrations. Les brochures de plusieurs pages et les modèles d’impression CorelDRAW ne sont pas son objectif et peuvent apparaître incomplets.

SVG animés

sVectorLift affiche les fichiers SVG animés sous forme d’image fixe – l’animation elle-même n’est pas lue.
