Manuel de SwiftRename

Aperçu

SwiftRename est un outil permettant de renommer et d'organiser plusieurs fichiers simultanément. Vous pouvez renommer des fichiers par date, les numéroter, leur attribuer un préfixe et les classer automatiquement dans une structure de dossiers.

Sélectionner les dossiers

1. Cliquez sur l'icône de dossier du dossier d'entrée pour sélectionner le dossier contenant les fichiers à renommer. Vous pouvez également faire glisser des dossiers depuis l'Explorateur de fichiers vers les champs de dossier. À l'aide de la petite flèche sur l'icône de dossier, vous sélectionnez à nouveau rapidement un dossier récemment utilisé.
2. Activez « Inclure les sous-dossiers » pour traiter également les fichiers contenus dans les sous-dossiers.
3. Sélectionnez un dossier de sortie dans lequel les fichiers renommés seront copiés ou déplacés. Les dossiers d'entrée et de sortie peuvent être identiques (renommage au même emplacement).
4. Avec « Inverser », vous échangez les dossiers d'entrée et de sortie. Avec « Actualiser », vous rechargez les deux listes de fichiers.

Modes de renommage

• Date uniquement : nomme les fichiers d'après leur date – la date de prise de vue si « Utiliser la date de prise de vue » est activé et que le fichier en possède une, sinon la date du fichier (par exemple « 2024-01-15 à 14-30-00.jpg »)
• Date + nom original : ajoute la date avant le nom de fichier d'origine (par exemple « 2024-01-15 à 14-30-00 - IMG_4523.jpg »)
• Numérotation avec préfixe : numérote les fichiers de manière consécutive avec un préfixe sélectionnable (par exemple « Vacances_0001.jpg »)
• Conserver le nom d'origine : classe uniquement les fichiers dans la structure de dossiers, sans modifier le nom des fichiers

Si des noms de fichiers sont identiques, un compteur est automatiquement ajouté (par exemple « _1 », « _2 »). Les caractères que Windows n'autorise pas dans les noms de fichiers sont remplacés par « _ ».

Structure des dossiers

Les fichiers peuvent être automatiquement classés dans des sous-dossiers par date :
• Aucune : Tous les fichiers directement dans le dossier de sortie
• Conserver : Reproduit la structure des sous-dossiers du dossier d’entrée
• Année : p. ex. « 2024\ »
• Année/Mois : p. ex. « 2024\01\ »
• Année/Mois/Jour : p. ex. « 2024\01\15\ »

Si les fichiers couvrent plusieurs décennies, des dossiers de décennie supplémentaires sont créés (p. ex. « 2011-2020\2015\… »).

Pour « Année/Mois » et « Année/Mois/Jour », l’option « Date complète dans les noms de sous-dossiers » apparaît directement sous le sélecteur de structure de dossiers. Une fois activée, les dossiers de mois et de jour contiennent la date complète (par ex. « 2024\2024-01\2024-01-15\ » au lieu de « 2024\01\15\ »).

Aperçu des noms

En haut de la liste d'entrée, trois vues sont proposées : liste, arborescence et aperçu des noms (icône en forme d'œil). Dans l'aperçu, le nouveau nom prévu et son dossier de destination apparaissent sous chaque nom de fichier actuel – par rapport au dossier de sortie, donc y compris les dossiers de date et de décennie.

L'aperçu nécessite un dossier de sortie sélectionné et se recalcule dès que vous modifiez le mode, le préfixe, la structure des dossiers ou l'option « Utiliser la date de prise de vue ». Avec beaucoup de fichiers, il se remplit progressivement, car la date de prise de vue doit être lue pour chaque fichier.

Ce sont des noms prévus : le fait qu'un fichier soit ignoré comme doublon et qu'un compteur (« _1 ») doive être ajouté en cas de nom de destination identique ne se décide qu'à l'exécution.

Date de la caméra (EXIF)

Lorsque l'option « Utiliser la date de prise de vue » est activée, la date de prise de vue est lue à partir des données EXIF pour les photos et à partir des informations contenues dans le film pour les vidéos. Cette date est plus précise que la date du fichier, qui peut changer lors de la copie.

De nombreux formats photo sont pris en charge, notamment JPEG, HEIC, PNG, TIFF et les formats RAW courants (CR2, CR3, NEF, ARW, DNG, RAF, etc.).

Si aucune date de prise de vue n'est disponible, la date du fichier est utilisée – la plus ancienne des dates de création et de modification.

Filtre d'extension de fichier

Utilisez le menu déroulant « Extensions de fichiers » pour filtrer les fichiers affichés par type :
• Les extensions disponibles sont détectées automatiquement depuis le dossier d'entrée.
• Sélectionnez une ou plusieurs extensions en cliquant dessus.
• « Toutes les extensions » réinitialise le filtre et affiche tous les fichiers.
• Le filtre est conservé lors du changement de dossier, tant que les extensions y existent.

Détection des doublons

Lorsque l'option « Vérifier les doublons » est activée, les doublons sont détectés avant la copie ou le déplacement, tant dans le dossier d'entrée que dans le dossier de sortie (toute l'arborescence de destination). La détection est basée sur la taille du fichier et une comparaison octet par octet du contenu du fichier ; pour les images JPEG et les vidéos, les métadonnées telles que l'EXIF sont ignorées, pour les autres formats chaque octet compte. La date n'intervient que pour la comparaison supplémentaire du contenu des images.

Les doublons trouvés sont affichés dans un aperçu avec des miniatures. Vous pouvez alors décider de continuer (les doublons sont ignorés) ou d'annuler l'opération.

Avec l'option supplémentaire « Comparer uniquement le contenu de l'image (lent) », seules les données de pixels décodées des images sont comparées. Les métadonnées telles que les mots-clés, les balises ou les entrées EXIF sont ignorées. Cela permet également de détecter des images identiques dont les métadonnées diffèrent. Cette variante est nettement plus lente et n'est active que lorsque la vérification des doublons est activée. Seules les images avec le même format de fichier et une taille de fichier similaire sont considérées comme candidates – la différence de taille maximale autorisée peut être ajustée dans les paramètres (Ctrl+,) sous « Tolérance de taille pour la comparaison d'images » (par défaut : 128 Ko). Les formats RAW nécessitent souvent des valeurs plus élevées, car les métadonnées telles que les mots-clés peuvent occuper plusieurs dizaines de Ko par entrée. Les images que Windows ne peut pas décoder (par exemple un fichier RAW sans l'extension installée) ne sont pas reconnues comme identiques.

Si un programme a réencapsulé ou réexporté une vidéo, celle-ci est considérée comme un fichier distinct, même si l’image et le son sont identiques. Les vidéos ne disposent pas d’une comparaison du contenu comme les images.

Copier et déplacer

• Copier : les fichiers originaux sont conservés, des copies sont créées dans le dossier de sortie.
• Déplacer : les fichiers sont déplacés vers le dossier de sortie.

Avant l'exécution, SwiftRename vérifie si l'espace disponible sur le lecteur cible est suffisant. Si l'espace est insuffisant, un avertissement s'affiche. Vous pouvez néanmoins poursuivre l'opération.

La taille totale des fichiers s'affiche sous la liste d'entrée, tandis que l'espace disponible sur le lecteur cible s'affiche sous la liste de sortie.

Annuler et rétablir

Chaque opération peut être annulée :
• Ctrl+Z : annuler la dernière opération
• Ctrl+Y : rétablir une opération annulée

Lors de l'annulation d'une copie, les fichiers copiés sont supprimés s'ils n'ont pas été modifiés ; s'ils ont été modifiés entre-temps, ils sont placés dans la Corbeille. Lors de l'annulation d'un déplacement, les fichiers sont replacés à leur emplacement d'origine.

Avancement et annulation

Une barre de progression avec affichage en pourcentage s'affiche pendant le traitement. Vous pouvez interrompre l'opération à tout moment avec « Annuler » ou la touche Esc. Les fichiers déjà traités sont conservés et peuvent être annulés avec Ctrl+Z.

Raccourcis clavier

• Ctrl+O : ouvrir le dossier source
• Ctrl+Maj+O : ouvrir le dossier de sortie
• Ctrl+Z : annuler
• Ctrl+Y : rétablir
• Ctrl+, : paramètres
• F1 : afficher l'aide
• Esc : annuler l'opération en cours
• Alt+F4 : quitter l'app

Conseils

• Avant toute opération de renommage importante, effectuez une sauvegarde de vos fichiers.
• Utilisez l'aperçu des noms (icône en forme d'œil au-dessus de la liste d'entrée) pour vérifier le résultat avant l'exécution.
• Un clic droit sur un fichier dans la liste vous permet de l'afficher dans l'Explorateur de fichiers.
• Dans les paramètres (Ctrl+,), vous pouvez ajuster la « Tolérance de taille pour la comparaison d'images ». En cas de problème, cliquez à cet endroit sur « Enregistrer le journal… » pour sauvegarder les messages des sept derniers jours dans un fichier texte.
