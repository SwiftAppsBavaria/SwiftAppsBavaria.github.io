SwiftRename 설명서

개요

SwiftRename는 여러 파일을 동시에 이름 변경하고 정리하는 도구입니다. 파일을 날짜별로 이름 변경하거나, 번호를 매기거나, 접두사를 추가하고 자동으로 폴더 구조에 정렬할 수 있습니다.

폴더 선택

1. 입력 폴더의 폴더 아이콘을 클릭하여 이름을 변경할 파일이 있는 폴더를 선택합니다. 또는 파일 탐색기에서 폴더를 폴더 필드로 끌어다 놓을 수도 있습니다. 폴더 아이콘의 작은 화살표를 사용하면 최근에 사용한 폴더를 빠르게 다시 선택할 수 있습니다.
2. 하위 폴더의 파일도 처리하려면 “하위 폴더 포함”을 활성화합니다.
3. 이름이 변경된 파일을 복사하거나 이동할 출력 폴더를 선택합니다. 입력 폴더와 출력 폴더는 동일할 수 있습니다(동일 위치에서 이름 변경).
4. “교환”을 클릭하면 입력 폴더와 출력 폴더가 바뀝니다. “업데이트”를 클릭하면 두 파일 목록이 다시 로드됩니다.

이름 변경 모드

• 날짜만: 파일 이름을 날짜로 지정합니다. “카메라 날짜 사용”이 켜져 있고 파일에 카메라 날짜가 있으면 카메라 날짜를, 그렇지 않으면 파일 날짜를 사용합니다(예: “2024-01-15 - 14-30-00.jpg”)
• 날짜 + 원래 이름: 원래 파일 이름 앞에 날짜를 추가합니다(예: “2024-01-15 - 14-30-00 - IMG_4523.jpg”)
• 접두사 번호 매기기: 선택한 접두사와 함께 파일에 연속 번호를 매깁니다(예: “휴가_0001.jpg”)
• 원래 파일 이름 유지: 파일 이름을 변경하지 않고 파일을 폴더 구조에 정렬하기만 합니다

파일 이름이 같으면 자동으로 카운터가 추가됩니다(예: “_1”, “_2”). Windows에서 파일 이름에 사용할 수 없는 문자는 “_”로 바뀝니다.

폴더 구조

파일을 날짜별로 하위 폴더에 자동 정리할 수 있습니다:
• 없음: 모든 파일을 출력 폴더에 바로 배치
• 유지: 입력 폴더의 하위 폴더 구조를 그대로 반영합니다
• 연도: 예) “2024/”
• 연도/월: 예) “2024/01/”
• 연도/월/일: 예) “2024/01/15/”

파일이 여러 십년에 걸치면 추가 십년 폴더가 생성됩니다 (예: “2011-2020/2015/…”).

“연도/월” 및 “연도/월/일”에서는 폴더 구조 선택 바로 아래에 “하위 폴더 이름에 전체 날짜 사용” 옵션이 나타납니다. 이 옵션을 켜면 월 및 일 폴더에 전체 날짜가 포함됩니다(예: “2024/01/15/” 대신 “2024/2024-01/2024-01-15/”).

이름 미리보기

입력 목록 머리글에서 목록, 트리, 이름 미리보기(눈 아이콘)의 세 가지 보기 중에서 선택할 수 있습니다. 미리보기에서는 현재 파일 이름 아래에 예정된 새 이름이 대상 폴더와 함께 표시됩니다. 출력 폴더를 기준으로 하므로 날짜 폴더와 연대 폴더도 포함됩니다.

미리보기에는 선택된 출력 폴더가 필요하며, 모드, 접두사, 폴더 구조 또는 “카메라 날짜 사용” 설정을 변경하면 즉시 다시 계산됩니다. 파일이 많으면 파일마다 촬영 날짜를 읽어야 하므로 목록이 차례로 채워집니다.

예정된 이름입니다. 파일이 중복으로 건너뛰어지는지, 대상 이름이 같을 때 카운터(“_1”)를 붙여야 하는지는 실행할 때 결정됩니다.

카메라 날짜 (EXIF)

“카메라 날짜 사용”이 활성화된 경우 사진은 EXIF 데이터에서, 동영상은 동영상 자체의 정보에서 촬영 날짜를 읽습니다. 이는 복사 시 변경될 수 있는 파일 날짜보다 더 정확합니다.

JPEG, HEIC, PNG, TIFF 및 일반적인 RAW 형식(CR2, CR3, NEF, ARW, DNG, RAF 등)을 포함한 다양한 사진 형식을 지원합니다.

촬영 날짜가 없으면 파일 날짜, 즉 생성 날짜와 수정 날짜 중 더 이른 날짜가 사용됩니다.

파일 확장자 필터

“파일 확장자” 드롭다운을 사용하여 표시된 파일을 유형별로 필터링할 수 있습니다:
• 사용 가능한 확장자는 입력 폴더에서 자동으로 감지됩니다.
• 클릭하여 하나 이상의 확장자를 선택합니다.
• “모든 파일 확장자”를 선택하면 필터가 초기화되고 모든 파일이 표시됩니다.
• 폴더를 바꿔도 해당 확장자가 그 폴더에 있으면 필터가 유지됩니다.

중복 감지

“중복 확인”이 활성화된 경우, 복사 또는 이동 전에 입력 폴더와 출력 폴더 모두(전체 대상 트리)에서 중복 파일이 감지됩니다. 감지는 파일 크기와 파일 내용의 바이트 비교를 기준으로 합니다. JPEG 이미지와 동영상에서는 EXIF 같은 메타데이터를 건너뛰고, 다른 형식에서는 모든 바이트를 비교합니다. 날짜는 추가적인 이미지 내용 비교에서만 의미가 있습니다.

발견된 중복 파일은 미리보기 이미지와 함께 목록으로 표시됩니다. 이후 계속 진행할지(중복 파일 건너뛰기) 또는 작업을 중단할지 선택할 수 있습니다.

추가 옵션 “이미지 내용만 비교 (느림)”을 사용하면 이미지의 디코딩된 픽셀 데이터만 비교됩니다. 키워드, 태그, EXIF 항목과 같은 메타데이터는 무시됩니다. 이렇게 하면 메타데이터가 서로 다른 동일한 이미지도 감지됩니다. 이 방식은 훨씬 느리며 중복 검사가 활성화된 경우에만 작동합니다. 동일한 파일 형식과 유사한 파일 크기를 가진 이미지만 후보로 간주됩니다. 최대 허용 크기 차이는 설정(Ctrl+,)의 “이미지 비교 크기 허용 오차”에서 조정할 수 있습니다(기본값: 128KB). RAW 형식은 키워드와 같은 메타데이터가 항목당 수십 KB를 차지할 수 있으므로 더 큰 값이 필요할 수 있습니다. Windows에서 디코딩할 수 없는 이미지(예: 확장이 설치되지 않은 RAW)는 동일한 것으로 인식되지 않습니다.

프로그램이 비디오를 다시 포장하거나 다시 내보낸 경우, 화면과 소리가 같더라도 별개의 파일로 간주됩니다. 비디오에는 이미지와 같은 내용 비교가 없습니다.

복사 및 이동

• 복사: 원본 파일은 그대로 유지되며, 복사본이 출력 폴더에 생성됩니다.
• 이동: 파일이 출력 폴더로 이동됩니다.

실행 전에 SwiftRename은 대상 드라이브에 충분한 저장 공간이 있는지 확인합니다. 공간이 부족하면 경고가 표시됩니다. 그래도 작업을 계속할 수 있습니다.

입력 목록 아래에는 파일의 총 크기가 표시되고, 출력 목록 아래에는 대상 드라이브의 사용 가능한 저장 공간이 표시됩니다.

실행 취소 및 다시 실행

모든 작업은 실행 취소할 수 있습니다:
• Ctrl+Z: 마지막 작업 실행 취소
• Ctrl+Y: 실행 취소한 작업 다시 실행

복사를 실행 취소하면 복사된 파일이 변경되지 않은 경우 삭제되고, 그사이에 변경된 경우 휴지통으로 이동됩니다. 이동을 실행 취소하면 파일이 원래 위치로 되돌아갑니다.

진행 및 중단

처리 중에는 진행률 표시줄이 퍼센트와 함께 표시됩니다. 언제든지 “취소” 또는 Esc 키를 눌러 작업을 중지할 수 있습니다. 이미 처리된 파일은 그대로 유지되며 Ctrl+Z를 눌러 실행 취소할 수 있습니다.

키보드 단축키

• Ctrl+O: 입력 폴더 선택
• Ctrl+Shift+O: 출력 폴더 선택
• Ctrl+Z: 실행 취소
• Ctrl+Y: 다시 실행
• Ctrl+,: 설정
• F1: 도움말 표시
• Esc: 진행 중인 작업 취소
• Alt+F4: 앱 종료

팁

• 대량 이름 변경 작업 전에 파일 백업을 생성하십시오.
• 실행 전에 이름 미리보기(입력 목록 위의 눈 아이콘)를 사용하여 결과를 확인하십시오.
• 목록에서 파일을 마우스 오른쪽 버튼으로 클릭하면 파일 탐색기에서 해당 파일을 표시할 수 있습니다.
• 설정(Ctrl+,)에서 “이미지 비교 크기 허용 오차”를 조정할 수 있습니다. 문제가 발생하면 같은 곳에서 “로그 저장…”을 사용하여 최근 7일간의 메시지를 텍스트 파일로 저장하십시오.
