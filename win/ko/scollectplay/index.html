sCollectPlay

폴더를 고르고 바로 재생 — 가져오기도 복사도 필요 없음

2026년 11월부터 Microsoft Store에서 제공

폴더를 고르고 바로 재생하세요. 음악, 오디오북, 팟캐스트, 영화, 전자책이 저절로 정리됩니다. 가져오기도, 계정도, 클라우드도 필요 없습니다. 재생목록이 담긴 iTunes 라이브러리(XML)도 지원합니다.

sCollectPlay는 컬렉션을 있는 자리 그대로 재생합니다. 어떤 폴더든, 외장 디스크든, 네트워크 드라이브든 상관없습니다. 폴더를 고르면 음악, 오디오북, 팟캐스트, 영화, 전자책이 하나의 목록에 정돈되어 나타납니다. 가져오기도, 복사도 없고, 파일은 무엇 하나 바뀌지 않습니다.

24개 언어: 영어, 독일어, 체코어, 크로아티아어, 네덜란드어, 핀란드어, 프랑스어, 헝가리어, 이탈리아어, 일본어, 한국어, 노르웨이어(보크몰), 페르시아어, 폴란드어, 포르투갈어, 루마니아어, 러시아어, 스페인어, 스웨덴어, 태국어, 터키어, 우크라이나어, 중국어(간체 및 번체). 앱은 Windows 표시 언어를 따릅니다.

두 가지 소스

  • 폴더: sCollectPlay는 폴더를 하위 폴더까지 살펴보고 제목, 아티스트, 앨범, 장르, 재생 시간을 파일 자체에서 읽습니다. 여러 폴더를 하나의 목록으로 합칠 수 있습니다. 다음 실행 시에는 마지막으로 읽어 들인 상태가 바로 표시되며, ‘스캔한 폴더 업데이트’(Ctrl+R)는 새로 추가되거나 변경되거나 삭제된 파일만 읽습니다.
  • iTunes XML: 재생목록, 별점, 재생 횟수가 담긴 Windows용 iTunes의 라이브러리. 곡이 음악, 오디오북, 팟캐스트, 장편 영화, 시리즈, 뮤직비디오 가운데 무엇인지는 앱이 XML에서 그대로 가져옵니다.

수고 없이 정돈됩니다

폴더는 파일이 노래인지 오디오북인지 알려 주지 않습니다. 그래서 sCollectPlay는 스캔할 때 길이로 나눕니다. 오디오는 10분 이하, 10~30분, 30~60분, 60분 초과로, 비디오는 짧은 클립부터 3시간 반이 넘는 영화까지. 그러면 노래, 오디오 드라마 에피소드, 오디오북이 아무것도 설정하지 않아도 따로따로 놓입니다. 전자책과 PDF는 확장자로 알아봅니다.

창의 제목 표시줄은 언제나 무엇이 열려 있는지 알려 줍니다. 어떤 폴더인지, 어떤 XML인지.

찾기

  • 제목, 아티스트, 앨범, 장르 등 여러 필드에 걸친 검색 — 재생목록 안에서도
  • 장르, 아티스트, 앨범, 작곡가, 그룹별 열 브라우저, 열마다 여러 개 선택. 수천 명의 아티스트도 끝없는 스크롤 없이: 첫 글자별로 묶어 줍니다
  • 열을 자유롭게 보이거나 숨길 수 있습니다. 파일 이름, 비트 전송률, 샘플률, 크기도. 너비와 순서는 마우스로 끌어서 바꿉니다
  • 최근에 쓴 폴더와 XML 파일이 ‘파일’ 메뉴에 준비되어 있고, 다음 실행 때는 마지막 소스가 다시 열립니다

재생

  • 대기열, 임의 재생, 반복을 갖춘 오디오 재생
  • 전용 창에서 재생하는 비디오, 슬로 모션, 프레임 단위 이동, 오디오 트랙 및 자막 선택, 전체 화면
  • Windows는 대부분의 형식을 직접 재생합니다 — MP3, AAC, FLAC, OGG, Opus, WMA는 물론 MP4, MKV, AVI, WMV, MPG까지. AIFF, DSD, FLV처럼 Windows가 모르는 형식은 Windows에서 해당 파일 형식에 지정된 앱으로 넘깁니다 — 이를테면 VLC
  • 직접 만든 재생목록과 스마트 재생목록
  • 모든 재생목록을 해당 파일과 함께 M3U8 목록이 든 폴더로 내보낼 수 있습니다 — SD 카드, USB 메모리 또는 원하는 폴더로. 이를테면 Android 기기의 VLC용으로

파일은 있는 그대로

sCollectPlay는 태그를 쓰지 않고, 메타데이터를 바꾸지 않으며, 아무것도 삭제하지 않습니다.

내 PC 안에서만

계정 없음, 클라우드 없음, 분석 없음, 광고 없음. 앱은 건네받은 폴더만 다룹니다. 언어마다 완전한 도움말이 들어 있습니다.

sCollectPlay Lite · 무료 — sCollectPlay의 간결한 버전: 간단히 폴더, iTunes XML 또는 sCollect 미디어 라이브러리를 열어 음악, 영화, 오디오북, 팟캐스트를 재생합니다 — 재생 목록과 오디오 및 자막 트랙, 슬로 모션과 프레임 단위 이동을 지원합니다. 세션당 하나의 소스만 사용할 수 있으며, 열 브라우저, 사용자 재생 목록, 최근 사용한 소스는 정식 버전 전용입니다.
