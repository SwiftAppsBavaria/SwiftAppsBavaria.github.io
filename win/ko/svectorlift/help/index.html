sVectorLift 설명서

개요

sVectorLift는 CorelDRAW 시대의 오래된 벡터 클립아트를 열어 SVG로 변환합니다. 덕분에 오늘날의 프로그램에서도 다시 사용할 수 있는 그래픽이 됩니다. 왼쪽에서 폴더를 선택하면 오른쪽에 클립아트가 미리보기로 나타납니다. 선택한 그래픽은 원하는 대상 폴더로 내보낼 수 있습니다.

지원되는 포맷

• CorelDRAW 도큐멘트(.cdr), 버전 6 ~ 9
• Corel Binary Meta File(.cmx) — 오래된 CDRX 방식도 지원
• Windows Metafile(.wmf)
• Computer Graphics Metafile(.cgm)
• QuickDraw 3D 메타파일(.3dm, .3dmf) — 이미지로 렌더링됩니다
• Scalable Vector Graphics (.svg) — 바로 표시됩니다

확장자가 .cdr인 파일 중 상당수는 실제로는 CorelDRAW 도큐멘트가 아니라 CMX입니다. 일반적인 변환기는 바로 이 지점에서 실패하지만, sVectorLift는 두 가지 모두를 읽습니다.

sVectorLift는 CorelDRAW 템플릿(.cdt)도 CorelDRAW 도큐멘트와 똑같이 엽니다.

폴더 선택

1. “폴더 선택 …”을 클릭하여(또는 Ctrl+O) 클립아트 컬렉션이 있는 폴더를 엽니다. 그 아래에 폴더 트리가 나타납니다.
2. 트리에서 폴더를 클릭하면 그 폴더의 클립아트가 로드됩니다. 하위 폴더는 화살표로 펼칩니다.
3. 다음에 실행하면 마지막으로 사용한 폴더가 다시 열립니다. 마지막으로 연 하위 폴더와 표시한 파일도 함께 복원됩니다. “파일 → 최근 사용한 폴더”에서 이전 컬렉션으로 바로 돌아갈 수 있습니다.

파일 탐색기에서 파일 하나를 열 수도 있습니다(“연결 프로그램” 또는 두 번 클릭). 표시 중인 폴더에 있으면 sVectorLift가 그 파일로 이동하고, 그렇지 않으면 파일만 따로 표시하며 개요로 전환할 때 비로소 그 폴더로 이동합니다.

“필터(이름 또는 키워드)” 필드로 이름이나 키워드에 따라 클립아트를 숨깁니다.

사이드바 너비는 구분선을 그리드 쪽으로 끌어 바꿉니다. 사이드바 위쪽의 버튼이나 Ctrl+Shift+S로 사이드바를 완전히 숨기면 클립아트가 창 너비 전체를 사용합니다.

두 폴더 버튼 옆에 선택한 경로가 표시됩니다. 클릭하면 복사할 수 있도록 전체 경로가 표시되고, 마우스 오른쪽 버튼으로 클릭하면 파일 탐색기로 바로 이동합니다.

모음을 다시 정리하려면 선택한 클립아트를 트리의 폴더로 드래그하십시오. 같은 드라이브에서는 해당 폴더로 이동되고, 다른 드라이브로는 복사됩니다. Ctrl 키를 누른 채로 놓으면 복사되고, Shift 키를 누른 채로 놓으면 이동됩니다. 파일 탐색기와 같습니다. 파일 탐색기로 드래그할 수도 있습니다. 파일 탐색기에서 변경한 내용은 “새로 고침”(F5 또는 사이드바 상단의 원형 화살표) 후에 표시됩니다.

다시 정리한 작업은 Ctrl+Z로 실행 취소할 수 있습니다. 이동한 항목은 원래 위치로 돌아가고, 복사본은 sVectorLift가 휴지통으로 이동합니다. 기존 파일을 대치한 복사본은 그대로 남습니다. 파일 탐색기로 드래그한 항목은 복사되며, 원본은 모음에 그대로 남습니다. Shift 키를 누른 채로 드래그하면 이동되며, 이 작업은 sVectorLift에서 실행 취소할 수 없습니다.

클립아트 보기

• 오른쪽 상단의 슬라이더로 미리보기 이미지의 크기를 조절합니다.
• “상세 보기”(또는 클립아트를 이중 클릭)를 사용하면 하나의 그래픽이 크게 표시됩니다. 화살표 키 ← → 로 폴더 안을 넘겨볼 수 있고, 이중 클릭하면 “개요”로 돌아갑니다.
• 미리보기 이미지는 화면에 보일 때 비로소 계산됩니다. 따라서 아주 큰 폴더에서는 먼저 자리 표시자가 나타났다가 차례로 채워집니다.

선택

선택은 파일 탐색기와 똑같이 작동합니다.
• 클릭: 클립아트 하나 선택
• Ctrl+클릭: 클립아트를 개별적으로 선택에 추가하거나 제거
• Shift+클릭: 연속된 범위 선택
• 빈 곳에서 드래그: 선택 사각형 그리기
• Ctrl+A: 폴더의 모든 클립아트 선택
• 빈 곳 클릭: 선택 해제

내보내기

1. “2. 내보내기”에서 대상 폴더를 선택합니다. 경로를 클릭하면 전체 경로가 표시되고 필요하면 파일 탐색기로 이동합니다.
2. “선택 항목 내보내기”는 선택한 클립아트를, “모두 내보내기”는 폴더 전체를 씁니다.

벡터 그래픽은 .svg로 저장됩니다. 순수 래스터 이미지와 3D 모델은 아무것도 잃지 않도록 .png로 저장됩니다. SVG 파일은 이미 대상 형식이므로 내보내기가 비활성화됩니다.

상황에 맞는 메뉴(클립아트를 마우스 오른쪽 버튼으로 클릭)에서 같은 대상 폴더로 내보내거나, 파일 탐색기에서 파일을 표시하거나, 이름을 바꾸거나, 휴지통으로 이동할 수 있습니다. 대상 폴더가 아직 설정되지 않았다면 한 번 묻습니다.

대상 파일이 이미 있으면 sVectorLift가 먼저 물어봅니다: “대치”, “둘 다 유지”(옆에 “이름 2.svg”로 저장), “건너뛰기” 또는 “취소”. 여러 파일을 내보낼 때는 “모두에 적용”으로 답변을 전체 작업에 적용할 수 있습니다. 그다음 내보내기는 사이드바의 진행 막대와 함께 진행되며, 언제든지 중단할 수 있습니다.

이름 바꾸기는 Ctrl+Z로 실행 취소하고 Ctrl+Y로 다시 실행할 수 있습니다. 단, 파일이 열려 있는 컬렉션 안에 있는 동안만 가능합니다. 내보내기 중에는 이름 바꾸기와 삭제가 잠시 잠깁니다. 내보내기는 시작할 때의 파일 이름으로 작업하기 때문입니다.

“PNG로 내보내기” 또는 “JPG로 내보내기”(상황에 맞는 메뉴와 “파일” 메뉴)를 사용하면 SVG 파일을 포함한 모든 클립아트가 설정의 렌더링 크기로 이미지로 계산됩니다. 이미지는 같은 대상 폴더에 저장됩니다.

폴더 구조 내보내기

하위 폴더를 포함한 폴더 전체는 “폴더 구조 내보내기” 창에서 변환합니다. “파일 → 폴더 구조 내보내기 …” 또는 사이드바의 같은 이름 버튼으로 열고, 원본 폴더와 대상 폴더를 선택한 다음 “모두 내보내기”로 시작합니다. 대상에 같은 폴더 구조가 만들어지며, SVG 파일은 그대로 복사되고 지원되는 파일이 없는 폴더는 만들지 않습니다. 아무것도 묻지 않습니다. 대상에 이미 있는 것은 건너뜁니다. 한 폴더에 이름이 같은 파일이 여러 개 있으면 두 번째부터는 원래 확장자가 붙습니다(예: “geometry (cmx).svg”).

설정

“파일 → 설정 …”(Ctrl+,)에서 3D 모델의 렌더링 크기를 설정합니다.

3D 모델에는 벡터 형식이 없으므로 내보낼 때 이미지로 계산됩니다. 값이 클수록 PNG가 선명해지지만 내보내기 시간이 길어집니다. 256~8192픽셀을 사용할 수 있으며 기본값은 1024입니다.

같은 창에 Windows 언어 설정으로 가는 버튼도 있습니다.

“파일 유형”에서 Windows가 오래된 형식을 두 번 클릭할 때 어떤 앱으로 여는지 확인할 수 있습니다. 변경은 Windows 설정의 “기본 앱”에서 합니다. 버튼을 누르면 바로 이동합니다.

같은 렌더링 크기가 “PNG로 내보내기”와 “JPG로 내보내기”에도 적용됩니다.

키보드 단축키

• Ctrl+O: 폴더 선택
• Ctrl+A: 모든 클립아트 선택
• ← →: 상세 보기에서 폴더 넘기기
• 두 번 클릭: 개요와 상세 보기 전환
• Ctrl+Shift+S: 사이드바 보기 또는 숨기기
• Ctrl+Z: 이름 바꾸기 또는 다시 정리 실행 취소
• Ctrl+Y: 이름 바꾸기 또는 다시 정리 다시 실행
• Ctrl+,: 설정
• F1: 이 도움말 표시
• Alt+F4: 창 닫기(확인 후 앱 종료)

언어

앱의 언어는 Windows 표시 언어를 따릅니다. 변경하려면 설정 → 시간 및 언어 → 언어 및 지역으로 이동하십시오.

클립아트가 나타나지 않는 경우

• 미리보기 대신 물음표가 표시되면 해당 파일을 읽을 수 없었다는 뜻입니다. 파일이 손상되었거나 sVectorLift가 알지 못하는 포맷이 포함되어 있을 수 있습니다.
• sVectorLift는 클립아트 모음(그림, 심볼, 일러스트레이션)을 위해 만들어졌습니다. CorelDRAW의 여러 페이지짜리 브로슈어나 인쇄용 템플릿은 대상이 아니며 불완전하게 보일 수 있습니다.

애니메이션 SVG

애니메이션 SVG 파일은 sVectorLift에서 정지 이미지로 표시되며, 움직임 자체는 재생되지 않습니다.
