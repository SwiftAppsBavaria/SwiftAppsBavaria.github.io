SwiftRename Manual

Overview

SwiftRename is a tool for renaming and organizing multiple files at once. You can rename files by date, number them sequentially, add a prefix, and automatically sort them into a folder structure.

Select Folders

1. Click the folder icon next to the input folder to choose the folder containing the files to rename. You can also drag folders from File Explorer onto the folder fields. The small arrow next to the folder icon lets you quickly pick a recently used folder again.
2. Turn on “Include subfolders” to also process files in subfolders.
3. Choose an output folder to which the renamed files are copied or moved. Input and output folder may be the same (renaming in place).
4. “Swap” exchanges the input and output folder. “Refresh” reloads both file lists.

Rename Modes

• Date only: Names files after their date – the camera date if “Use camera date” is on and the file has one, otherwise the file date (e.g. “2024-01-15 at 14-30-00.jpg”)
• Date + original name: Puts the date in front of the original file name (e.g. “2024-01-15 at 14-30-00 - IMG_4523.jpg”)
• Numbering with prefix: Numbers files consecutively with a prefix of your choice (e.g. “Vacation_0001.jpg”)
• Keep original name: Only sorts files into the folder structure without changing the file name

If two files get the same name, a counter is added automatically (e.g. “_1”, “_2”). Characters that Windows does not allow in file names are replaced by “_”.

Folder Structure

Files can be automatically sorted into subfolders by date:
• None: All files go directly into the output folder
• Preserve: Mirrors the input folder's subfolder structure
• Year: e.g., “2024/”
• Year/Month: e.g., “2024/01/”
• Year/Month/Day: e.g., “2024/01/15/”

If the files span multiple decades, additional decade folders will be created (e.g., “2011-2020/2015/…”).

For “Year/Month” and “Year/Month/Day,” the option “Full date in subfolder names” appears directly below the folder structure selector. When enabled, month and day folders contain the full date (e.g. “2024/2024-01/2024-01-15/” instead of “2024/01/15/”).

Name Preview

The header of the input list offers three views: list, tree and name preview (eye icon). The preview shows the planned new name and target folder below each current file name – relative to the output folder, including date and decade folders.

The preview needs an output folder and is recalculated as soon as you change the mode, prefix, folder structure or the “Use camera date” setting. With many files it fills in gradually, because the capture date of every file has to be read.

These are planned names: whether a file is skipped as a duplicate and whether a counter (“_1”) has to be added for an identical target name is only decided when the operation runs.

Camera Date (EXIF)

If “Use camera date” is turned on, the capture date of photos is read from the EXIF data and that of videos from the movie's own metadata. This is more accurate than the file date, which can change when files are copied.

Many photo formats are supported, including JPEG, HEIC, PNG, TIFF and common RAW formats (CR2, CR3, NEF, ARW, DNG, RAF and more).

If there is no capture date, the file date is used – the earlier of the creation and modification date.

File extension filter

Use the “File extensions” drop-down to filter the listed files by type:
• The available extensions are determined automatically from the input folder.
• Click to select one or more extensions.
• “All file extensions” resets the filter and shows all files.
• The filter is kept when you switch folders, as long as the extensions exist there.

Duplicate Detection

If “Check for duplicates” is turned on, duplicates are detected before copying or moving – both in the input and in the output folder (the whole target tree). Detection is based on file size and a byte comparison of the file contents; for JPEG images and videos, metadata such as EXIF is skipped, for other formats every byte counts. The date only matters for the additional image content comparison.

Duplicates found are shown in an overview with thumbnails. You can then decide whether to continue (duplicates are skipped) or cancel the operation.

With the additional option “Compare image content only (slow)”, only the decoded pixel data of images is compared. Metadata such as keywords, tags or EXIF entries is ignored. This also detects identical images whose metadata differs. This variant is considerably slower and only active when the duplicate check is on. Only images with the same file format and a similar file size are considered – the maximum allowed size difference can be adjusted in the settings (Ctrl+,) under “Size tolerance for image comparison” (default: 128 KB). RAW formats often need larger values, because metadata such as keywords can take up several dozen KB per entry. Images that Windows cannot decode (such as RAW without the extension installed) are never considered identical.

If a program has re-wrapped or re-exported a video, it counts as a separate file – even when picture and sound are identical. Videos have no content comparison like images do.

Copy and Move

• Copy: The original files are retained, and copies are created in the output folder.
• Move: The files are moved to the output folder.

Before executing, SwiftRename checks whether there is enough storage space on the destination drive. If there is insufficient space, a warning appears. You can continue the process anyway.

The total size of the files is displayed below the input list, and the free storage space on the destination drive is displayed below the output list.

Undo and Redo

Every operation can be undone:
• Ctrl+Z: Undo the last operation
• Ctrl+Y: Redo an undone operation

Undoing a copy deletes the copied files if they are unchanged; if they have been changed in the meantime, they go to the Recycle Bin. Undoing a move puts the files back where they were.

Progress and Cancel

While files are being processed, a progress bar with a percentage is shown. You can stop the operation at any time with “Cancel” or the Esc key. Files already processed stay where they are and can be undone with Ctrl+Z.

Keyboard Shortcuts

• Ctrl+O: Choose input folder
• Ctrl+Shift+O: Choose output folder
• Ctrl+Z: Undo
• Ctrl+Y: Redo
• Ctrl+,: Settings
• F1: Show help
• Esc: Cancel the running operation
• Alt+F4: Quit the app

Tips

• Back up your files before larger renaming operations.
• Use the name preview (eye icon above the input list) to check the result before running.
• Right-click a file in the list to show it in File Explorer.
• In the settings (Ctrl+,) you can adjust the “Size tolerance for image comparison”. If problems occur, use “Save Log…” there to save the messages of the last seven days as a text file.
