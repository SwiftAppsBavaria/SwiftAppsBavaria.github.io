Manuale di sVectorLift

Panoramica

sVectorLift apre le vecchie clipart vettoriali dell’era CorelDRAW e le converte in SVG: immagini che i programmi di oggi possono di nuovo utilizzare. A sinistra scegli una cartella, a destra compaiono le clipart come anteprime. Le immagini selezionate si esportano in una cartella di destinazione a tua scelta.

Formati supportati

• Documenti CorelDRAW (.cdr), dalla versione 6 alla 9
• Corel Binary Meta File (.cmx) — anche la vecchia variante CDRX
• Windows Metafile (.wmf)
• Computer Graphics Metafile (.cgm)
• Metafile QuickDraw 3D (.3dm, .3dmf) — vengono resi come immagine
• Scalable Vector Graphics (.svg) — vengono visualizzati direttamente

Molti file con estensione .cdr in realtà non sono affatto documenti CorelDRAW, ma CMX. È proprio qui che i convertitori abituali falliscono: sVectorLift legge entrambi.

sVectorLift apre i modelli CorelDRAW (.cdt) esattamente come i documenti CorelDRAW.

Scegli cartella

1. Fai clic su «Scegli cartella…» (o Ctrl+O) per aprire la cartella con la tua raccolta di clipart. Sotto compare l’albero delle cartelle.
2. Un clic su una cartella dell’albero ne carica le clipart. Le sottocartelle si espandono con la freccia.
3. Al prossimo avvio si riapre l’ultima cartella usata, con l’ultima sottocartella aperta e il file selezionato. Con «File → Cartelle recenti» torni direttamente a una raccolta precedente.

Puoi aprire anche un singolo file da Esplora file («Apri con» o doppio clic): se si trova nella cartella mostrata, sVectorLift ci salta; altrimenti lo mostra da solo e passa alla sua cartella solo quando torni alla Panoramica.

Con il campo «Filtra (nome o parola chiave)» nascondi le clipart per nome o parola chiave.

La larghezza della barra laterale si cambia trascinando il divisore verso la griglia. Con il pulsante in alto nella barra — o Ctrl+Maiusc+S — la nascondi del tutto, così le clipart usano l’intera larghezza della finestra.

Accanto ai due pulsanti delle cartelle compare il percorso scelto. Un clic lo mostra per intero da copiare, un clic destro porta direttamente a Esplora file.

Per riorganizzare la tua raccolta, trascina le clipart selezionate su una cartella dell’albero: sulla stessa unità vengono spostate lì, su un’altra unità vengono copiate. Tenendo premuto il tasto Ctrl copi, con Maiusc sposti, proprio come in Esplora file. Puoi trascinarle anche in Esplora file. Le modifiche che fai in Esplora file compaiono dopo «Aggiorna» (F5 o la freccia circolare in cima alla barra laterale).

Con Ctrl+Z annulli la riorganizzazione: gli elementi spostati tornano al loro posto precedente e sVectorLift sposta le copie nel Cestino. Una copia che ha sostituito un file esistente rimane al suo posto. Ciò che trascini in Esplora file viene copiato; l’originale resta nella raccolta. Se tieni premuto il tasto Maiusc, viene spostato: sVectorLift non può annullarlo.

Visualizzare le clipart

• Con il cursore in alto a destra imposti la dimensione delle anteprime.
• «Vista dettagliata» (o un doppio clic su una clipart) mostra una singola immagine in grande. Con i tasti freccia ← → scorri la cartella, un doppio clic riporta alla Panoramica.
• Le anteprime vengono calcolate solo quando le vedi. Nelle cartelle molto grandi compaiono quindi dapprima dei segnaposto, che si riempiono man mano.

Seleziona

La selezione funziona come in Esplora file:
• Clic: seleziona una singola clipart
• Ctrl+clic: aggiungi o togli singole clipart dalla selezione
• Maiusc+clic: seleziona un intervallo continuo
• Trascina nel vuoto: traccia un rettangolo di selezione
• Ctrl+A: seleziona tutte le clipart della cartella
• Clic nel vuoto: annulla la selezione

Esporta

1. Scegli una cartella di destinazione in «2. Esportazione». Un clic sul percorso lo mostra per intero e, se serve, porta a Esplora file.
2. «Esporta selezione» scrive le clipart selezionate, «Esporta tutto» l’intera cartella.

La grafica vettoriale viene salvata come .svg. Le immagini puramente raster — e i modelli 3D — vengono salvati come .png, così non si perde nulla. I file SVG sono già nel formato di destinazione; per loro l’esportazione è disattivata.

Con il menu contestuale (clic destro su una clipart) esporti nella stessa cartella di destinazione, mostri il file in Esplora file, lo rinomini o lo sposti nel Cestino. Se non è ancora impostata una cartella di destinazione, ti viene chiesta una volta.

Se il file di destinazione esiste già, sVectorLift te lo chiede prima: «Sostituisci», «Tieni entrambi» (scrive accanto, come «Nome 2.svg»), «Ignora» o «Annulla». Con più file, «Applica a tutti» estende la tua risposta all’intera operazione. L’esportazione prosegue poi con una barra di avanzamento nella barra laterale, e puoi interromperla in qualsiasi momento.

Una ridenominazione si annulla con Ctrl+Z e si ripete con Ctrl+Y, finché il file è nella raccolta aperta. Durante un’esportazione, rinomina ed elimina sono bloccati per poco: l’esportazione lavora con i nomi di file validi al suo avvio.

Con «Esporta come PNG» o «Esporta come JPG» — nel menu contestuale e nel menu «File» — ogni clipart viene calcolata come immagine, anche un file SVG, nella dimensione di rendering delle impostazioni. Le immagini finiscono nella stessa cartella di destinazione.

Esporta struttura cartelle

Un’intera cartella con le sue sottocartelle si converte nella finestra «Esporta struttura cartelle». La apri con «File → Esporta struttura cartelle…» o con l’omonimo pulsante della barra laterale, scegli lì la cartella di origine e quella di destinazione e avvii con «Esporta tutto». Nella destinazione si crea la stessa struttura di cartelle; i file SVG vengono copiati invariati e non si creano cartelle senza file supportati. Non viene chiesto nulla: ciò che è già nella destinazione viene ignorato. Se più file di una cartella hanno lo stesso nome, ognuno dei successivi riceve la sua estensione originale, ad esempio «geometry (cmx).svg».

Impostazioni

In «File → Impostazioni…» (Ctrl+,) imposti la dimensione di rendering dei modelli 3D.

I modelli 3D non hanno forma vettoriale; per l’esportazione vengono calcolati come immagine. Più alto è il valore, più nitido è il PNG — e più dura l’esportazione. Sono ammessi da 256 a 8192 pixel, il valore predefinito è 1024.

Nella stessa finestra trovi anche il pulsante per le impostazioni della lingua di Windows.

In «Tipi di file» vedi con quale app Windows apre i vecchi formati con un doppio clic. Si cambia in «App predefinite» nelle Impostazioni di Windows; il pulsante porta direttamente lì.

La stessa dimensione di rendering vale per «Esporta come PNG» ed «Esporta come JPG».

Abbreviazioni da tastiera

• Ctrl+O: scegli cartella
• Ctrl+A: seleziona tutte le clipart
• ← →: scorri la cartella nella vista dettagliata
• Doppio clic: passa tra panoramica e vista dettagliata
• Ctrl+Maiusc+S: mostra o nascondi la barra laterale
• Ctrl+Z: annulla la ridenominazione o la riorganizzazione
• Ctrl+Y: ripeti la ridenominazione o la riorganizzazione
• Ctrl+,: impostazioni
• F1: mostra questa guida
• Alt+F4: chiudi la finestra (esce dall’app dopo conferma)

Lingua

La lingua dell'app segue la lingua di visualizzazione di Windows. Per modificarla: Impostazioni → Data/ora e lingua → Lingua e area geografica.

Se una clipart non appare

• Un punto interrogativo al posto dell’anteprima significa che non è stato possibile leggere il file — ad esempio perché è danneggiato o contiene un formato che sVectorLift non conosce.
• sVectorLift è pensato per le raccolte di clipart: disegni, simboli, illustrazioni. Gli opuscoli su più pagine e i modelli di stampa di CorelDRAW non sono il suo scopo e possono apparire incompleti.

SVG animati

sVectorLift mostra i file SVG animati come immagine fissa – il movimento vero e proprio non viene riprodotto.
