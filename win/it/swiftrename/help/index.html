Manuale di SwiftRename

Panoramica

SwiftRename è uno strumento che consente di rinominare e organizzare più file contemporaneamente. È possibile rinominare i file in base alla data, numerarli in ordine progressivo, aggiungere un prefisso e ordinarli automaticamente in una struttura di cartelle.

Seleziona cartelle

1. Clicca sull'icona della cartella accanto alla cartella di input per selezionare la cartella contenente i file da rinominare. In alternativa, puoi trascinare le cartelle da Esplora file ai campi delle cartelle. Tramite la piccola freccia sull'icona della cartella puoi riselezionare rapidamente una cartella usata di recente.
2. Attiva “Includi sottocartelle” per elaborare anche i file nelle sottocartelle.
3. Seleziona una cartella di output in cui copiare o spostare i file rinominati. Le cartelle di input e output possono essere identiche (rinominazione nella stessa posizione).
4. Con “Scambiare” scambi la cartella di input e quella di output. Con “Aggiorna” ricarichi entrambi gli elenchi di file.

Modalità di rinomina

• Solo data: rinomina i file in base alla loro data – la data fotocamera, se “Usa data fotocamera” è attivo e il file ne ha una, altrimenti la data del file (ad es. “2024-01-15 alle 14-30-00.jpg”)
• Data + nome originale: inserisce la data prima del nome originale del file (ad es. “2024-01-15 alle 14-30-00 - IMG_4523.jpg”)
• Numerazione con prefisso: numera i file in modo progressivo con un prefisso selezionabile (ad es. “Vacanze_0001.jpg”)
• Mantieni nome originale: ordina soltanto i file nella struttura delle cartelle, senza modificare il nome del file

In caso di nomi di file identici, viene aggiunto automaticamente un contatore (ad es. “_1”, “_2”). I caratteri che Windows non consente nei nomi di file vengono sostituiti da “_”.

Struttura cartelle

I file possono essere automaticamente ordinati in sottocartelle per data:
• Nessuna: Tutti i file direttamente nella cartella di output
• Mantieni: Riproduce la struttura delle sottocartelle della cartella di input
• Anno: es. “2024/”
• Anno/Mese: es. “2024/01/”
• Anno/Mese/Giorno: es. “2024/01/15/”

Se i file coprono più decenni, vengono create cartelle aggiuntive per decennio (es. “2011-2020/2015/…”).

Per “Anno/Mese” e “Anno/Mese/Giorno” appare direttamente sotto il selettore della struttura delle cartelle l’opzione “Data completa nei nomi delle sottocartelle”. Se attivata, le cartelle di mese e giorno contengono la data completa (es. “2024/2024-01/2024-01-15/” invece di “2024/01/15/”).

Anteprima dei nomi

In cima all'elenco di input puoi scegliere tra tre viste: elenco, albero e anteprima dei nomi (icona a forma di occhio). Nell'anteprima, sotto ogni nome di file attuale compare il nuovo nome previsto con la relativa cartella di destinazione – rispetto alla cartella di output, quindi comprese le cartelle di data e di decennio.

L'anteprima richiede una cartella di output selezionata e viene ricalcolata non appena modifichi la modalità, il prefisso, la struttura cartelle o l'opzione “Usa data fotocamera”. Con molti file si riempie gradualmente, perché per ogni file va letta la data di scatto.

Sono nomi previsti: se un file viene saltato come duplicato e se, in caso di nome di destinazione uguale, occorre aggiungere un contatore (“_1”) si decide solo durante l'esecuzione.

Data della fotocamera (EXIF)

Se l'opzione “Usa data fotocamera” è attivata, per le foto la data di scatto viene letta dai dati EXIF, per i video dalle informazioni contenute nel filmato. Questa data è più precisa della data del file, che può cambiare durante la copia.

Sono supportati molti formati fotografici, tra cui JPEG, HEIC, PNG, TIFF e i formati RAW più comuni (CR2, CR3, NEF, ARW, DNG, RAF e molti altri).

Se non è disponibile una data di scatto, viene utilizzata la data del file – la meno recente tra la data di creazione e quella di modifica.

Filtro estensione file

Con il menu a tendina “Estensioni file” puoi filtrare i file visualizzati per tipo:
• Le estensioni disponibili vengono rilevate automaticamente dalla cartella di input.
• Seleziona una o più estensioni con un clic.
• “Tutte le estensioni” reimposta il filtro e mostra tutti i file.
• Il filtro viene mantenuto al cambio di cartella, a condizione che le estensioni siano presenti.

Rilevamento dei duplicati

Se l'opzione “Verifica duplicati” è attivata, prima di copiare o spostare i file vengono rilevati i duplicati, sia nella cartella di input che in quella di output (l'intero albero di destinazione). Il rilevamento si basa sulla dimensione del file e su un confronto byte per byte del contenuto del file; per le immagini JPEG e i video i metadati come l'EXIF vengono ignorati, per gli altri formati conta ogni byte. La data è rilevante solo per il confronto aggiuntivo del contenuto delle immagini.

I duplicati trovati vengono visualizzati in una panoramica con miniature. Puoi quindi decidere se continuare (i duplicati vengono saltati) o annullare l'operazione.

Con l'opzione aggiuntiva “Confronta solo il contenuto dell'immagine (lento)”, per le immagini vengono confrontati solo i dati dei pixel decodificati. I metadati come parole chiave, tag o voci EXIF vengono ignorati. In questo modo vengono riconosciute anche immagini identiche i cui metadati sono diversi. Questa variante è notevolmente più lenta ed è attiva solo quando il controllo dei duplicati è abilitato. Come candidate vengono considerate solo le immagini con lo stesso formato di file e una dimensione di file simile – la differenza di dimensione massima consentita può essere regolata nelle impostazioni (Ctrl+,) alla voce “Tolleranza di dimensione per il confronto delle immagini” (predefinito: 128 KB). I formati RAW richiedono spesso valori più grandi, poiché i metadati come le parole chiave possono occupare diverse decine di KB per voce. Le immagini che Windows non è in grado di decodificare (ad esempio RAW senza l'estensione installata) non vengono riconosciute come identiche.

Se un programma ha reimpacchettato o riesportato un video, questo viene considerato un file a sé stante, anche a parità di immagine e audio. Per i video non esiste un confronto del contenuto come per le immagini.

Copiare e spostare

• Copia: i file originali vengono conservati, le copie vengono create nella cartella di destinazione.
• Sposta: i file vengono spostati nella cartella di destinazione.

Prima dell'esecuzione, SwiftRename verifica se sullo spazio di destinazione è disponibile spazio sufficiente. Se lo spazio è insufficiente, viene visualizzato un avviso. È comunque possibile continuare con l'operazione.

Sotto l'elenco di input viene visualizzata la dimensione totale dei file, sotto l'elenco di output lo spazio libero sullo spazio di destinazione.

Annulla e ripeti

Ogni operazione può essere annullata:
• Ctrl+Z: annulla l'ultima operazione
• Ctrl+Y: ripeti un'operazione annullata

Quando annulli una copia, i file copiati vengono eliminati se non sono stati modificati; se nel frattempo sono stati modificati, vengono spostati nel Cestino. Quando annulli uno spostamento, i file vengono riportati nella loro posizione originale.

Avanti e Annulla

Durante l'elaborazione viene visualizzata una barra di avanzamento con indicazione della percentuale. Puoi interrompere l'operazione in qualsiasi momento con “Annulla” o con il tasto Esc. I file già elaborati vengono mantenuti e possono essere annullati con Ctrl+Z.

Scorciatoie da tastiera

• Ctrl+O: seleziona la cartella di input
• Ctrl+Maiusc+O: seleziona la cartella di output
• Ctrl+Z: annulla
• Ctrl+Y: ripeti
• Ctrl+,: impostazioni
• F1: mostra la guida
• Esc: annulla l'operazione in corso
• Alt+F4: esci dall'app

Consigli

• Prima di eseguire operazioni di rinominazione di grandi dimensioni, esegui un backup dei tuoi file.
• Usa l'anteprima dei nomi (icona a forma di occhio sopra l'elenco di input) per verificare il risultato prima dell'esecuzione.
• Con un clic destro su un file nell'elenco puoi visualizzarlo in Esplora file.
• Nelle impostazioni (Ctrl+,) puoi regolare la “Tolleranza di dimensione per il confronto delle immagini”. In caso di problemi, usa lì “Salva registro…” per salvare i messaggi degli ultimi sette giorni in un file di testo.
