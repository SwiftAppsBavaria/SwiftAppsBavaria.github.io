SwiftRename

Rinomina i file in blocco

Prossimamente · Microsoft Store

Leggi il manuale completo →

Rinomina centinaia di foto e file in una volta: per data della fotocamera, numerati o in cartelle per anno e mese. I duplicati sono trovati e ignorati automaticamente.

SwiftRename è uno strumento che consente di rinominare e organizzare più file contemporaneamente. È possibile rinominare i file in base alla data, numerarli in ordine progressivo, aggiungere un prefisso e ordinarli automaticamente in una struttura di cartelle.
