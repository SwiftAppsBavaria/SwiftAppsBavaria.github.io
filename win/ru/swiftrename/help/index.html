Руководство по SwiftRename

Обзор

SwiftRename — это инструмент для одновременного переименования и упорядочивания нескольких файлов. Вы можете переименовывать файлы по дате, нумеровать их, добавлять префикс и автоматически сортировать по структуре папок.

Выбор папок

1. Нажмите значок папки у исходной папки, чтобы выбрать папку с файлами, которые нужно переименовать. Также можно перетащить папки из проводника на поля папок. С помощью маленькой стрелки у значка папки можно быстро снова выбрать недавно использованную папку.
2. Установите флажок «Включить подпапки», чтобы обрабатывать также файлы в подпапках.
3. Выберите папку назначения, в которую будут скопированы или перемещены переименованные файлы. Исходная папка и папка назначения могут совпадать (переименование на месте).
4. Кнопка «Поменять» меняет местами исходную папку и папку назначения. Кнопка «Обновить» заново загружает оба списка файлов.

Режимы переименования

• Только дата: присваивает файлам имена по их дате — по дате съёмки, если параметр «Использовать дату съёмки» включён и она есть у файла, иначе по дате файла (например, «2024-01-15 в 14-30-00.jpg»)
• Дата + исходное имя: вставляет дату перед исходным именем файла (например, «2024-01-15 в 14-30-00 - IMG_4523.jpg»)
• Нумерация с префиксом: нумерует файлы последовательно с выбираемым префиксом (например, «Отпуск_0001.jpg»)
• Сохранить имя файла: только сортирует файлы по структуре папок, не изменяя имя файла

При одинаковых именах файлов автоматически добавляется счётчик (например, «_1», «_2»). Символы, недопустимые в именах файлов Windows, заменяются на «_».

Структура папок

Файлы могут автоматически распределяться в подпапки по дате:
• Нет: Все файлы напрямую в выходную папку
• Сохранить: Воспроизводит структуру подпапок входной папки
• Год: напр. «2024\»
• Год/Месяц: напр. «2024\01\»
• Год/Месяц/День: напр. «2024\01\15\»

Если файлы охватывают несколько десятилетий, создаются дополнительные папки десятилетий (напр. «2011-2020\2015\…»).

При выборе «Год/Месяц» и «Год/Месяц/День» прямо под выбором структуры папок появляется опция «Полная дата в именах подпапок». Если она включена, папки месяцев и дней содержат полную дату (например, «2024\2024-01\2024-01-15\» вместо «2024\01\15\»).

Предпросмотр имён

В заголовке списка исходных файлов можно выбрать одно из трёх представлений: список, дерево и предпросмотр имён (значок глаза). В режиме предпросмотра под каждым текущим именем файла отображается запланированное новое имя вместе с целевой папкой — относительно папки назначения, то есть включая папки по датам и десятилетиям.

Для предпросмотра нужна выбранная папка назначения; он пересчитывается, как только вы меняете режим, префикс, структуру папок или параметр «Использовать дату съёмки». При большом количестве файлов он заполняется постепенно, потому что для каждого файла считывается дата съёмки.

Это запланированные имена: будет ли файл пропущен как дубликат и придётся ли при совпадении целевого имени добавить счётчик («_1»), решается только при выполнении.

Дата съемки (EXIF)

Если параметр «Использовать дату съёмки» включён, дата съёмки для фотографий считывается из данных EXIF, а для видео — из метаданных самого видео. Это точнее, чем дата файла, которая может измениться при копировании.

Поддерживается множество форматов фотографий, включая JPEG, HEIC, PNG, TIFF и распространённые форматы RAW (CR2, CR3, NEF, ARW, DNG, RAF и многие другие).

Если дата съёмки отсутствует, используется дата файла — более ранняя из даты создания и даты изменения.

Фильтр расширения файлов

С помощью раскрывающегося списка «Расширения файлов» можно фильтровать отображаемые файлы по типу:
• Доступные расширения автоматически определяются по исходной папке.
• Выберите одно или несколько расширений щелчком.
• «Все расширения файлов» сбрасывает фильтр и показывает все файлы.
• Фильтр сохраняется при смене папки, если там есть эти расширения.

обнаружение дубликатов

Если параметр «Проверять дубликаты» включён, перед копированием или перемещением выявляются дубликаты — как в исходной папке, так и в папке назначения (всё целевое дерево). Обнаружение основано на размере файла и побайтовом сравнении содержимого файла; для изображений JPEG и видео метаданные, такие как EXIF, при этом пропускаются, для других форматов учитывается каждый байт. Дата важна только при дополнительном сравнении содержимого изображений.

Найденные дубликаты отображаются в обзоре с миниатюрами. Затем вы можете решить, продолжить ли (дубликаты будут пропущены) или отменить операцию.

С дополнительным параметром «Сравнивать только содержимое изображения (медленно)» для изображений сравниваются только декодированные пиксельные данные. Метаданные, такие как ключевые слова, теги или записи EXIF, при этом игнорируются. Так обнаруживаются и идентичные изображения, метаданные которых различаются. Этот вариант значительно медленнее и действует, только если включена проверка дубликатов. Кандидатами считаются только изображения с одинаковым форматом файла и схожим размером файла — максимально допустимую разницу в размере можно настроить в параметрах (Ctrl+,) в разделе «Допуск размера при сравнении изображений» (по умолчанию: 128 КБ). Форматам RAW часто нужны большие значения, так как метаданные, например ключевые слова, могут занимать несколько десятков КБ на запись. Изображения, которые Windows не может декодировать (например, RAW без установленного расширения), при этом не распознаются как одинаковые.

Если программа переупаковала или повторно экспортировала видео, оно считается отдельным файлом — даже при одинаковых изображении и звуке. Для видео нет сравнения содержимого, как у изображений.

Копирование и перемещение

• Копировать: исходные файлы сохраняются, копии создаются в папке вывода.
• Переместить: файлы перемещаются в папку вывода.

Перед выполнением SwiftRename проверяет, достаточно ли места на целевом диске. При недостаточном месте появляется предупреждение. Вы можете продолжить процесс, несмотря на это.

Под списком ввода отображается общий размер файлов, под списком вывода — свободное место на целевом диске.

Отмена и повтор

Любую операцию можно отменить:
• Ctrl+Z: отменить последнюю операцию
• Ctrl+Y: повторить отменённую операцию

При отмене копирования скопированные файлы удаляются, если они не изменились; если за это время они были изменены, они перемещаются в корзину. При отмене перемещения файлы возвращаются на прежнее место.

Прогресс и отмена

Во время обработки отображается индикатор выполнения с процентами. Вы можете в любой момент остановить операцию кнопкой «Отмена» или клавишей Esc. Уже обработанные файлы сохраняются, и их обработку можно отменить с помощью Ctrl+Z.

Сочетания клавиш

• Ctrl+O: открыть исходную папку
• Ctrl+Shift+O: открыть папку назначения
• Ctrl+Z: отменить
• Ctrl+Y: повторить
• Ctrl+,: параметры
• F1: показать справку
• Esc: отменить текущую операцию
• Alt+F4: закрыть приложение

советы

• Перед крупными операциями по переименованию создайте резервную копию ваших файлов.
• Используйте предпросмотр имён (значок глаза над списком исходных файлов), чтобы проверить результат перед выполнением.
• Щёлкнув правой кнопкой мыши по файлу в списке, вы можете показать его в проводнике.
• В параметрах (Ctrl+,) вы можете изменить «Допуск размера при сравнении изображений». При возникновении проблем нажмите там «Сохранить журнал…», чтобы сохранить сообщения за последние семь дней в текстовый файл.
