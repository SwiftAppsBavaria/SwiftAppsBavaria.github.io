sVectorLift 手冊

概覽

sVectorLift 可打開 CorelDRAW 時代的舊向量美工圖案，並將其轉換為 SVG——即當今程式仍能使用的圖形。請在左側選擇一個資料夾，右側便會以預覽形式顯示其中的美工圖案。所選圖形可輸出到你指定的目標資料夾。

支援的格式

• CorelDRAW 文件（.cdr），版本 6 至 9
• Corel Binary Meta File（.cmx）——也包括舊的 CDRX 變體
• Windows Metafile（.wmf）
• Computer Graphics Metafile（.cgm）
• QuickDraw 3D 中繼檔（.3dm、.3dmf）——會算圖為影像
• Scalable Vector Graphics （.svg）——直接顯示

許多副檔名為 .cdr 的檔案其實根本不是 CorelDRAW 文件，而是 CMX。常見的轉換器正是在這一點上失敗——而 sVectorLift 兩者都能讀取。

sVectorLift 開啟 CorelDRAW 範本（.cdt）的方式與 CorelDRAW 文件相同。

選擇資料夾

1. 按一下「選擇資料夾 …」（或 Ctrl+O），開啟存放美工圖案收藏的資料夾。下方會顯示資料夾樹狀結構。
2. 按一下樹狀結構中的資料夾即可載入其中的美工圖案。用箭頭展開子資料夾。
3. 下次啟動時，會重新開啟上次使用的資料夾，包括上次開啟的子資料夾和標記的檔案。透過「檔案 → 最近使用的資料夾」可直接回到先前的收藏。

也可以從檔案總管開啟單一檔案（「開啟檔案」或按兩下）：如果它位於目前顯示的資料夾中，sVectorLift 會跳到該檔案；否則會單獨顯示該檔案，只有在切換到概覽時才轉到其資料夾。

用「篩選（名稱或關鍵字）」欄位可依名稱或關鍵字隱藏美工圖案。

將分隔線朝格線拖曳即可變更側邊欄寬度。用側邊欄頂端的按鈕（或 Ctrl+Shift+S）可完全隱藏側邊欄，讓美工圖案使用整個視窗寬度。

兩個資料夾按鈕旁都會顯示所選路徑。按一下可完整顯示以便複製，以滑鼠右鍵按一下可直接前往檔案總管。

若要重新整理收藏，請將標示的美工圖案拖到樹狀結構中的資料夾上：在同一磁碟機上會搬移到該處，拖到其他磁碟機則會複製。按住 Ctrl 鍵可複製，按住 Shift 鍵可搬移，與檔案總管相同。你也可以將它們拖到檔案總管中。在檔案總管中所做的變更會在「重新整理」（F5 或側邊欄頂端的圓形箭頭）之後顯示。

用 Ctrl+Z 可復原重新整理：搬移的項目會回到原本的位置，複本則由 sVectorLift 移到資源回收筒。取代了現有檔案的複本會保留。拖到檔案總管中的項目會被複製，原始檔仍保留在收藏中。如果拖曳時按住 Shift 鍵，則會搬移，sVectorLift 無法復原此動作。

檢視美工圖案

• 使用右上角的滑桿可調整縮覽圖的大小。
•「詳細檢視」（或按兩下某個美工圖案）會大幅顯示單個圖形。使用方向鍵 ← → 可瀏覽該資料夾，按兩下即可返回「概覽」。
• 縮覽圖只有在你看到它們時才會計算。因此在非常大的資料夾中會先出現佔位圖，隨後逐步填入。

選擇

選取方式與檔案總管相同：
• 按一下：選取單一美工圖案
• Ctrl+按一下：將個別美工圖案加入或移出選取範圍
• Shift+按一下：選取連續範圍
• 在空白處拖曳：拉出選取矩形
• Ctrl+A：選取資料夾中的所有美工圖案
• 按一下空白處：取消選取

輸出

1. 在「2. 輸出」下選擇目標資料夾。按一下路徑可完整顯示，必要時可前往檔案總管。
2. 「輸出所選項目」寫出標記的美工圖案，「全部輸出」寫出整個資料夾。

向量圖形儲存為 .svg。純點陣圖像和 3D 模型儲存為 .png，以免遺失任何內容。SVG 檔案已經是目標格式，因此對其停用輸出。

透過內容功能表（以滑鼠右鍵按一下美工圖案）可輸出到同一目標資料夾、在檔案總管中顯示檔案、重新命名檔案或將其移到資源回收筒。如果尚未設定目標資料夾，會詢問一次。

如果目標檔案已經存在，sVectorLift 會先詢問：「取代」、「兩者都保留」（在旁邊另存為「名稱 2.svg」）、「略過」或「取消」。檔案有多個時，用「套用至全部」就能把你的回答用於整個輸出過程。接著輸出會在側邊欄顯示進度列，你隨時都能取消。

用 Ctrl+Z 可復原重新命名，用 Ctrl+Y 可重做——前提是檔案仍在開啟的收藏中。輸出期間，重新命名和刪除會暫時鎖定：輸出使用的是開始時有效的檔案名稱。

使用「輸出為 PNG」或「輸出為 JPG」（在內容功能表和「檔案」功能表中），每個美工圖案（即使是 SVG 檔案）都會依設定中的轉譯大小計算為圖像。圖像會存入同一目標資料夾。

輸出資料夾結構

要轉換整個資料夾及其子資料夾，請使用「輸出資料夾結構」視窗。透過「檔案 → 輸出資料夾結構 …」或側邊欄中的同名按鈕開啟，在其中選擇來源資料夾和目標資料夾，然後按「全部輸出」開始。目標中會建立相同的資料夾結構；SVG 檔案原樣複製，不含支援檔案的資料夾不會建立。不會詢問任何問題：目標中已有的內容會被略過。如果同一資料夾中多個檔案同名，之後的每個檔案都會加上原本的副檔名，例如「geometry (cmx).svg」。

設定

在「檔案 → 設定 …」（Ctrl+,）中設定 3D 模型的轉譯大小。

3D 模型沒有向量形式；輸出時會計算為圖像。數值越大，PNG 越清晰，輸出所需時間也越長。允許 256 到 8192 像素，預設值為 1024。

在同一視窗中還有前往 Windows 語言設定的按鈕。

在「檔案類型」中可以看到 Windows 按兩下舊格式時使用哪個應用程式。可在 Windows 設定的「預設應用程式」中變更；按鈕會直接帶你前往。

相同的算圖尺寸也適用於「輸出為 PNG」和「輸出為 JPG」。

鍵盤快速鍵

• Ctrl+O：選擇資料夾
• Ctrl+A：選取所有美工圖案
• ← →：在詳細檢視中翻閱資料夾
• 按兩下：在概覽和詳細檢視之間切換
• Ctrl+Shift+S：顯示或隱藏側邊欄
• Ctrl+Z：復原重新命名或重新整理
• Ctrl+Y：重做重新命名或重新整理
• Ctrl+,：設定
• F1：顯示本說明
• Alt+F4：關閉視窗（詢問後結束應用程式）

語言

應用程式的語言會跟隨 Windows 顯示語言。若要更改：設定 → 時間與語言 → 語言與地區。

如果美工圖案未顯示

• 若顯示問號而非預覽，表示該檔案無法讀取——例如檔案已損壞，或包含 sVectorLift 無法辨識的格式。
• sVectorLift 專為美工圖案收藏而設計：圖畫、符號、插圖。CorelDRAW 的多頁手冊和印刷範本並非目標對象，可能顯示不完整。

動畫 SVG

對於動畫 SVG 檔案，sVectorLift 會以靜態影像顯示，動畫本身不會播放。
