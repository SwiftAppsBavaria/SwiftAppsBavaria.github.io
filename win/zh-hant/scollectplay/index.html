sCollectPlay

選擇資料夾即可播放 —— 無須匯入，無須複製

2026年11月起於 Microsoft Store 上架

選擇資料夾即可播放：音樂、有聲書、Podcast、電影和電子書自動歸類——無須匯入，無須帳號，也無須雲端。也支援 iTunes 媒體庫（XML）及其播放清單。

sCollectPlay 就在你的收藏所在之處播放它：任意資料夾、外接硬碟或網路磁碟。選擇一個資料夾，音樂、有聲書、Podcast、電影和電子書就會整整齊齊地排在一個清單裡 —— 無須匯入，無須複製，你的檔案也不會有任何改動。

24 種語言：英文、德文、捷克文、克羅埃西亞文、荷蘭文、芬蘭文、法文、匈牙利文、義大利文、日文、韓文、挪威文（書面挪威文）、波斯文、波蘭文、葡萄牙文、羅馬尼亞文、俄文、西班牙文、瑞典文、泰文、土耳其文、烏克蘭文、中文（簡體與繁體）。App 會依照 Windows 的顯示語言。

兩種來源

  • 資料夾：sCollectPlay 會掃描一個資料夾及其子資料夾，直接從檔案本身讀取標題、演出者、專輯、類型和時間長度。多個資料夾可以合併成一個清單。下次啟動時會立即顯示上次讀取的狀態，「更新已掃描的資料夾」（Ctrl+R）只讀取新增、變更或移除的檔案。
  • iTunes XML：Windows 版 iTunes 的媒體庫，包括播放清單、評分和播放次數。一首曲目是音樂、有聲書、Podcast、電影、影集還是音樂影片，App 會從 XML 中讀取。

整理，但不必你費力

資料夾不會告訴你，一個檔案是歌曲還是有聲書。因此，sCollectPlay 在掃描時依時間長度分類：音訊分為 10 分鐘以內、10–30 分鐘、30–60 分鐘和超過 60 分鐘，影片則從短片一直到超過三個半小時的電影。這樣，歌曲、廣播劇單集和有聲書就各自分開，你什麼都不用設定。電子書和 PDF 由 App 依副檔名辨識。

視窗標題列隨時顯示目前載入的是什麼：哪個資料夾、哪個 XML。

尋找

  • 依標題、演出者、專輯、類型等欄位搜尋 —— 播放清單中也可以
  • 依類型、演出者、專輯、作曲和分組瀏覽的直欄瀏覽器，每一欄都可以多選。成千上萬位藝人也不必無止境地捲動：依首字母分組
  • 自由顯示或隱藏欄位，其中包括檔案名稱、資料速率、取樣率和大小；欄寬和順序用滑鼠拖曳即可調整
  • 最近使用的資料夾和 XML 檔案都列在「檔案」選單中，下次啟動時，上一次的來源會再次出現

播放

  • 音訊播放，附佇列、隨機播放和重複播放
  • 影片在自己的視窗中播放，支援慢動作、逐格播放、選擇音軌和字幕以及全螢幕
  • 大多數格式 Windows 可以自己播放 —— MP3、AAC、FLAC、OGG、Opus、WMA，以及 MP4、MKV、AVI、WMV 和 MPG。Windows 不認識的格式，例如 AIFF、DSD 或 FLV，App 會交給 Windows 中為該檔案類型設定的程式 —— 例如 VLC
  • 自建播放清單和智慧型播放清單
  • 任何播放清單都可以連同其檔案匯出為一個附 M3U8 清單的資料夾 —— 匯出到 SD 卡、USB 隨身碟或某個資料夾，例如供 Android 裝置上的 VLC 使用

你的檔案保持原樣

sCollectPlay 不寫入標籤，不更改中繼資料，也不刪除任何東西。

在你的 PC 上，也僅在那裡

沒有帳號，沒有雲端，沒有分析，沒有廣告。App 只存取你交給它的資料夾。每一種語言都配有完整的說明文件。

sCollectPlay Lite · 免費 — sCollectPlay 的精簡版：直接開啟檔案夾、iTunes XML 或 sCollect 媒體庫，播放其中的音樂、影片、有聲書與 Podcast——支援播放列表、音軌與字幕軌、慢動作與逐格播放。每次工作階段只能使用一個來源；分欄瀏覽器、自訂播放列表與最近使用的來源僅限完整版。
