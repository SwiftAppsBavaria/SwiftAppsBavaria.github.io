sCollectPlay 手冊

開始使用

sCollectPlay 播放你的媒體——來自任意資料夾、iTunes XML 檔案和 sCollect 媒體庫。匯入、編輯中繼資料和同步不在其中；這些由 sCollect 負責。

啟動時會出現來源選擇，其中有三個按鈕：「掃描資料夾…」、「開啟 XML 媒體庫…」和「選擇 sCollect 媒體庫…」。「檔案」選單中也有相同的命令。

下次啟動時，sCollectPlay 會自動載入上次使用的來源。

如果在啟動時按住 Shift 鍵，則會改為顯示來源選擇。如果媒體庫或掃描的資料夾位於網路上，sCollectPlay 會先詢問是否載入該來源——可以在 設定 > 一般 中透過「啟動時提示網路媒體庫」關閉此詢問。如果磁碟機在 20 秒內沒有回應，sCollectPlay 會給出提示並顯示來源選擇。

在「檔案」選單中，每個命令下方會列出最近使用的資料夾、媒體庫和 XML 檔案，各最多十個。「清空列表」會清空一個清單；已無法存取的項目在按一下時會消失。

掃描資料夾

選擇任意資料夾。sCollectPlay 會在該資料夾及其子資料夾中搜尋音訊、影片、電子書和 PDF 檔案，並直接從檔案讀取標題、演出者、專輯和時長。對於某些格式——例如 WMA、OGG、AIFF 或 AVI——只會讀取時長，此時以檔案名稱作為標題。隱藏檔案不包括在內。

依內容分類：sCollectPlay 會依檔案對自身的描述為音訊分類：.m4b 檔案以及風格為 Audiobook、Audio Theatre 或 Spoken Word（也包括德文，例如 Hörbuch、Hörspiel 或 Kabarett）的項目會列在「有聲書」下，Podcast 以及風格為 Podcast 或 Speech 的項目列在「Podcast」下，其餘全部列在「音樂」下。音樂影片、電影和影集依媒體種類辨識（例如 iTunes 寫入檔案的媒體種類），影集也可依檔名中的「S01E02」辨識。註明攝影機或帶有 IMG_1234 這類相機檔名的影片會列在「攝影機」下，其餘影片列在「家庭錄影」下。電子書和 PDF 則依副檔名辨識。側邊欄只會顯示有內容的類型。

自行選擇類型：如果某個項目分類有誤，請將它從列表拖到側邊欄中的另一個類型上 – 拖移時，空的類型也會出現在那裡。sCollectPlay 會為該檔案記住這項設定，下次讀取資料夾時同樣有效；檔案本身不會變更。

如果掃描沒有找到可播放或閱讀的內容，sCollectPlay 會顯示提示。

「檔案 > 更新已掃描的資料夾」（Ctrl+R）只會讀取自上次讀取以來的變更——新增、變更和移除的檔案——並回報結果。暫時無法存取的資料夾會保留先前的狀態。

清單上方最右側的 ↻ 按鈕也能完成同樣的操作。

可以依序掃描多個資料夾；其內容會一併顯示。標題列會顯示第一個資料夾的名稱，並計算其餘資料夾的數量。

啟動時，sCollectPlay 會依上次讀取時的狀態顯示已掃描的資料夾，而不重新搜尋。如果在載入媒體庫或 XML 時掃描資料夾，先前掃描過的資料夾也會一併回來。

sCollect 媒體庫

選擇 sCollect 媒體庫的主資料夾——也就是包含 .scollect 套件的資料夾。sCollectPlay 會讀取項目、播放清單和設定。

sCollectPlay 不會更改媒體庫本身。當你為曲目評分，或把音樂、有聲書或影片播放到結束時，它會連同日期和時間把這一點記錄在媒體庫資料夾中的 rueckmeldungen.json 檔案裡 – 無論你開啟的是主媒體庫還是副本。sCollect 會在打開主媒體庫時、在投影之前以及在修復同步錯誤…之前接收這些資訊：評分以較新的為準，播放次數相加。隨後 sCollect 把評分寫入檔案，並把一切傳給所有副本。在此之前，sCollectPlay 就已經顯示它自己的評分和播放次數。

如果媒體庫是在 Mac 上建立的，其中記錄的是 Mac 路徑。sCollectPlay 會透過媒體庫資料夾尋找檔案；對於位於其外部的媒體，只要能從媒體庫推斷，就會將 Mac 路徑對應到相符的 Windows 資料夾。找不到的檔案仍會留在清單中，但無法播放。

iTunes XML

選擇 iTunes for Windows 建立的 XML 檔案（iTunes Music Library.xml——在 iTunes 的進階偏好設定中開啟共享 XML 檔案後，iTunes 會寫入此檔案），或從 Apple Music 匯出的 Library.xml。sCollectPlay 會讀取項目和播放清單——智慧型播放清單依 iTunes 最後一次儲存的內容作為固定清單——並略過「媒體庫」或「音樂」等系統清單。媒體類型來自 XML 本身：音樂、有聲書、Podcast、家庭錄影、電影、影集和音樂影片。

在 Mac 上匯出的 XML 指向 Mac 路徑；sCollectPlay 在 Windows 上找不到這些檔案。

一次只會載入一種來源。開啟媒體庫或 XML 會取代先前載入的內容。視窗標題列會顯示來源的類型和名稱，例如：資料夾「音樂」、媒體庫「sCollect」。

瀏覽媒體庫

側邊欄以摺疊面板顯示類別和媒體類型——一次只展開一個類別。在開啟的類別下方，其播放清單位於「播放清單」區域；沒有類別的播放清單位於最下方。

按一下欄標題即依該欄排序，再按一下則反轉順序。按住 Shift 可新增一個排序層級，按住 Alt 則移除一個；欄標題內容選單中的「重設排序」只保留第一層級。sCollectPlay 會為每種媒體類型記住排序。

搜尋欄位依標題、演出者、專輯、類型及其他欄位篩選——在播放清單中也可以。

評分：使用 sCollect 媒體庫時，點一下評分欄位中的星星：第一次點按設為一顆完整的星，第二次設為半顆星，第三次清除評分。若要同時為多首曲目評分，請先選取它們，然後按右鍵點選 > 評分。對於掃描的資料夾和 XML 媒體庫，星星僅供顯示。

刪除：對於掃描的資料夾，按右鍵點選 > 刪除媒體檔案 會將檔案移至資源回收筒並從清單中移除；若選取了多首曲目，則全部刪除。sCollectPlay 是否先詢問，可在 設定 > 一般 > 確認刪除 中設定。若檔案位於沒有資源回收筒的磁碟機上，例如網路或 USB 隨身碟，它一律會詢問，因為在那裡檔案會被永久刪除。只有從資源回收筒還原檔案才能復原刪除；之後使用 更新已掃描的資料夾 即可讓它重新出現在清單中。在 sCollect 媒體庫和 XML 媒體庫中，sCollectPlay 不會刪除任何內容——那裡的檔案分別歸 sCollect 和 iTunes 管理。

你可以透過欄位標題內容選單中的「自訂直欄…」選擇要顯示的欄位；其中的「最佳寬度」可將寬度調整為適當大小。用滑鼠拖曳可變更寬度和順序。sCollectPlay 會在這台電腦上記住這些設定；預設使用 sCollect 媒體庫中的欄位。

欄位瀏覽器會在項目清單上方顯示選擇欄：類型、演出者、專輯、作曲和分組。清單右上方的按鈕可開啟或關閉它；在播放清單中同樣有效。

• 按一下某個值即依其篩選，Ctrl+按一下可新增或移除一個值。同一欄中的多個值以「或」組合，不同欄之間以「且」組合。最上面一列「全部」會清除該欄的選擇。
• 如果某欄的項目非常多，sCollectPlay 會依首字母將其歸入可展開的群組。

播放

按兩下項目或按 Enter 鍵即可播放；空白鍵可開始和暫停。播放器列顯示封面、標題和演出者、用於跳轉的時間軸，以及隨機播放、上一曲、後退 10 秒、停止、播放、前進 10 秒、下一曲和重複（關閉、清單、單曲）按鈕，另有音量；播放影片時還會加入慢動作和逐格。只要你沒有選取其他內容，清單中的選取就會隨正在播放的項目移動。

影片會在獨立的影片視窗中開啟。移動滑鼠時會顯示其控制列：時間、上一曲和下一曲、後退和前進 10 秒、慢動作、逐格、音軌（有多個時）、字幕（如有）和全螢幕。F11 和「播放」選單的快速鍵在這裡同樣有效，按 Esc 可結束全螢幕。關閉影片視窗即停止播放。影片結束時視窗會保持開啟，除非已為其媒體類型開啟「結束後繼續播放」——此時會接著播放下一曲，播放到清單結尾時，視窗會自動關閉。

結束後繼續播放：一首曲目結束後是否繼續播放下一首，由你按媒體類型設定，位於設定 > 播放/播放清單 > 結束後繼續播放。預設情況下，所有音訊類型和音樂影片為開啟，電影、影集、家庭錄影和攝影機影片為關閉 – 此時影片會停在結尾（或停止標記處）。重複（單首）仍會重複播放。sCollectPlay 會記住你在這裡所做的變更；其他所有媒體類型沿用媒體庫的設定。

透過項目的內容選單，你可以立即播放、接著播放或將其加入佇列。內容選單中也有「在檔案總管中顯示」和「用預設程式開啟」。

sCollectPlay 透過 Windows 的媒體播放服務播放，它支援大多數格式——MP3、AAC/M4A、FLAC、OGG、Opus 和 WMA，以及 MP4、MKV、AVI、WMV、MPG、TS 和 VOB。Windows 本身無法播放的內容——例如 AIFF、CAF、DSD（DSF、DFF）、FLV 或受複製保護的影片——sCollectPlay 會以該檔案類型的預設應用程式開啟。書籍和 PDF 也會在預設應用程式中開啟。

播放清單

來源的播放清單列在側邊欄的「播放清單」下——一般播放清單依儲存的順序排列，智慧型播放清單依其規則計算。它們只能在 sCollect 中變更。

在「我的播放清單」下，無論載入的是哪種來源，你都可以建立自己的播放清單：

• 建立：「我的播放清單」旁的加號提供「新增播放清單…」和「新增智慧型播放清單…」。
• 加入：項目清單內容選單中的「加入播放清單」會加入選取的項目，或建立新的播放清單；在你自己的播放清單中，「從播放清單移除」可再將其移除。
• 智慧型播放清單會依規則自動組合；播放清單內容選單中的「編輯…」可變更規則。
• 播放清單的內容選單中還有「重新命名…」（適用於一般播放清單）和「刪除播放清單」。在側邊欄中，按 F2 可重新命名所選播放清單；按 Delete 會在確認後刪除，按 Ctrl+Delete 則與內容選單中的「刪除播放清單」一樣不經確認直接刪除。「編輯」>「還原」（Ctrl+Z）可救回已刪除的播放清單。

sCollectPlay 會將你自己的播放清單儲存在這台電腦上，絕不會儲存於媒體庫或 XML。即使重新掃描，它也會依檔案路徑重新找到其中的項目。

播放清單內容選單中的「匯出至 VLC/裝置…」——或「檔案 > 將播放清單匯出至 VLC/裝置…」——會將整個播放清單的音訊和影片檔案（即使搜尋目前正在篩選）複製到你選擇的資料夾，例如 SD 卡或 USB 隨身碟。其中會建立一個以播放清單命名的子資料夾，依演出者和專輯整理，並附上使用相對路徑的 .m3u8 播放清單檔案。書籍和其他項目會略過並計數。

• 如果你再次將同一播放清單匯出至同一位置，sCollectPlay 只會複製新增或大小不同的內容，並重新寫入清單。你從播放清單移除的項目仍會以檔案形式留在資料夾中。
• 「取消」會結束匯出；此時清單包含到那時為止已複製的項目。

切勿拆散匯出的資料夾——清單只能相對於自身所在位置找到其中的項目。這樣，VLC 和任何能讀取 M3U8 清單的播放器都會顯示該播放清單。

設定

「檔案 > 設定…」（Ctrl+,）會開啟設定。以灰色顯示的值來自已載入的 sCollect 媒體庫（未載入媒體庫時為預設值），只能在 sCollect 中變更。

• 一般：語言（跟隨 Windows），以及——對於在 Mac 上建立的媒體庫——媒體資料夾。你可以在那裡為媒體庫的每個 Mac 資料夾指定其檔案在這台電腦上所在的 Windows 資料夾；仍缺少的會以紅色顯示，並附上項目數。
• 媒體庫：三種來源類型。按一下另一個圓圈即可切換來源。對於已掃描的資料夾，每個資料夾都會顯示其項目數和讀取時間；「更新」只會讀取變更的內容。
• 播放/播放清單：「影片視窗始終在最前」和「縮到最細時暫停影片」。
• 類別標籤、欄位標籤和統計會顯示已載入來源的名稱和數量。

在完整版中，你還可以在那裡移除個別資料夾、用「全部更新」一次更新所有資料夾，以及載入最近使用的媒體庫之一。按一下某個圓圈會開啟該類型最近使用的來源。

鍵盤快速鍵

空白鍵 – 播放 / 暫停
Enter – 播放選取的項目
Ctrl+→ – 下一曲
Ctrl+← – 上一曲
Ctrl+↑ – 增大音量
Ctrl+↓ – 減小音量
F11 – 影片全螢幕開/關
Esc – 結束影片全螢幕
Ctrl+R – 更新已掃描的資料夾
Ctrl+Shift+O – 選擇 sCollect 媒體庫…
Ctrl+, – 設定
F1 – 說明
Alt+F4 – 結束
