Manual do sVectorLift

Visão Geral

O sVectorLift abre cliparts vetoriais antigos da era do CorelDRAW e os converte em SVG — imagens que os programas atuais voltam a conseguir usar. À esquerda você escolhe uma pasta; à direita, os cliparts aparecem como miniaturas. Você exporta as imagens selecionadas para uma pasta de destino de sua escolha.

Formatos compatíveis

• Documentos do CorelDRAW (.cdr), versões 6 a 9
• Corel Binary Meta File (.cmx) — também a antiga variante CDRX
• Windows Metafile (.wmf)
• Computer Graphics Metafile (.cgm)
• Metarquivos QuickDraw 3D (.3dm, .3dmf) — são renderizados como imagem
• Scalable Vector Graphics (.svg) — são exibidos diretamente

Muitos arquivos com a extensão .cdr, na verdade, não são documentos do CorelDRAW, mas sim CMX. É exatamente aí que os conversores comuns falham — o sVectorLift lê os dois.

O sVectorLift abre modelos do CorelDRAW (.cdt) da mesma forma que documentos do CorelDRAW.

Escolher Pasta

1. Clique em “Escolher Pasta…” (ou Ctrl+O) para abrir a pasta da sua coleção de cliparts. Abaixo aparece a árvore de pastas.
2. Um clique em uma pasta da árvore carrega os cliparts dela. As subpastas são expandidas com a seta.
3. Na próxima vez que você iniciar o app, a última pasta usada será aberta novamente — com a última subpasta aberta e o arquivo marcado. Em “Arquivo → Pastas Recentes” você volta diretamente a uma coleção anterior.

Você também pode abrir um único arquivo pelo Explorador de Arquivos (“Abrir com” ou clique duplo): se ele estiver na pasta exibida, o sVectorLift vai até ele; caso contrário, mostra o arquivo sozinho e só muda para a pasta dele quando você passar para a Visão Geral.

Com o campo “Filtrar (nome ou palavra-chave)” você oculta cliparts por nome ou palavra-chave.

Para mudar a largura da barra lateral, arraste o divisor em direção à grade. Com o botão no topo da barra — ou Ctrl+Shift+S — você a oculta por completo para que os cliparts usem toda a largura da janela.

Ao lado dos dois botões de pasta aparece o caminho escolhido. Um clique o mostra por inteiro para copiar; um clique com o botão direito leva direto ao Explorador de Arquivos.

Para reorganizar sua coleção, arraste os cliparts marcados para uma pasta da árvore: na mesma unidade eles são movidos para lá; para outra unidade, são copiados. Com a tecla Ctrl pressionada você copia, com Shift você move — como no Explorador de Arquivos. Você também pode arrastá-los para o Explorador de Arquivos. As alterações feitas no Explorador de Arquivos aparecem após “Atualizar” (F5 ou a seta circular no topo da barra lateral).

Com Ctrl+Z você desfaz a reorganização: o que foi movido volta ao local anterior, e o sVectorLift move as cópias para a Lixeira. Uma cópia que substituiu um arquivo existente permanece. O que você arrastar para o Explorador de Arquivos é copiado; o original permanece na coleção. Se você mantiver a tecla Shift pressionada, ele é movido — o sVectorLift não pode desfazer isso.

Ver Cliparts

• Com o controle deslizante no canto superior direito, você ajusta o tamanho das miniaturas.
• A “Visualização Detalhada” (ou um clique duplo em um clipart) mostra uma única imagem em tamanho grande. Com as teclas de seta ← → você percorre a pasta; um clique duplo volta para a Visão Geral.
• As miniaturas só são calculadas quando você as vê. Por isso, em pastas muito grandes aparecem primeiro espaços reservados, que vão sendo preenchidos aos poucos.

Selecionar

A seleção funciona como no Explorador de Arquivos:
• Clique: selecionar um único clipart
• Ctrl+clique: adicionar cliparts individuais à seleção ou removê-los
• Shift+clique: selecionar um intervalo contínuo
• Arrastar em área vazia: desenhar um retângulo de seleção
• Ctrl+A: selecionar todos os cliparts da pasta
• Clique em área vazia: cancelar a seleção

Exportar

1. Escolha uma pasta de destino em “2. Exportação”. Um clique no caminho o mostra por inteiro e, se necessário, leva ao Explorador de Arquivos.
2. “Exportar Seleção” grava os cliparts marcados; “Exportar Tudo”, a pasta inteira.

Gráficos vetoriais são salvos como .svg. Imagens puramente rasterizadas — e modelos 3D — são salvas como .png para que nada se perca. Arquivos SVG já estão no formato de destino; para eles a exportação fica desativada.

Pelo menu de contexto (clique com o botão direito em um clipart) você exporta para a mesma pasta de destino, mostra o arquivo no Explorador de Arquivos, renomeia-o ou o move para a Lixeira. Se ainda não houver uma pasta de destino, ela será solicitada uma vez.

Se um arquivo de destino já existir, o sVectorLift pergunta antes: “Substituir”, “Manter Ambos” (grava ao lado, como “Nome 2.svg”), “Pular” ou “Cancelar”. Com vários arquivos, você aplica sua resposta à operação inteira com “Aplicar a todos”. Em seguida, a exportação é executada com uma barra de progresso na barra lateral, que você pode cancelar a qualquer momento.

Para desfazer uma renomeação use Ctrl+Z, e para refazê-la, Ctrl+Y — enquanto o arquivo ainda estiver na coleção aberta. Durante uma exportação, renomear e excluir ficam bloqueados por um instante: a exportação trabalha com os nomes de arquivo válidos no início.

Com “Exportar como PNG” ou “Exportar como JPG” — no menu de contexto e no menu “Arquivo” — cada clipart é calculado como imagem, até mesmo um arquivo SVG, no tamanho de renderização das configurações. As imagens vão para a mesma pasta de destino.

Exportar Estrutura de Pastas

Para converter uma pasta inteira com suas subpastas, use a janela “Exportar Estrutura de Pastas”. Abra-a em “Arquivo → Exportar Estrutura de Pastas…” ou pelo botão de mesmo nome na barra lateral, escolha ali as pastas de origem e de destino e inicie com “Exportar Tudo”. No destino é criada a mesma estrutura de pastas; arquivos SVG são copiados sem alterações e pastas sem arquivos compatíveis não são criadas. Nada é perguntado: o que já existe no destino é pulado. Se vários arquivos de uma pasta tiverem o mesmo nome, cada um adicional recebe sua extensão original, por exemplo “geometry (cmx).svg”.

Configurações

Em “Arquivo → Configurações…” (Ctrl+,) você define o tamanho de renderização dos modelos 3D.

Modelos 3D não têm forma vetorial; na exportação são calculados como imagem. Quanto maior o valor, mais nítido o PNG — e mais demora a exportação. São permitidos de 256 a 8192 pixels; o padrão é 1024.

Na mesma janela você encontra também o botão para as configurações de idioma do Windows.

Em “Tipos de Arquivo” você vê com qual app o Windows abre os formatos antigos com clique duplo. Isso se altera em “Aplicativos padrão” nas Configurações do Windows; o botão leva direto até lá.

O mesmo tamanho de renderização vale para “Exportar como PNG” e “Exportar como JPG”.

Atalhos de teclado

• Ctrl+O: escolher pasta
• Ctrl+A: selecionar todos os cliparts
• ← →: percorrer a pasta na visualização detalhada
• Clique duplo: alternar entre visão geral e visualização detalhada
• Ctrl+Shift+S: mostrar ou ocultar a barra lateral
• Ctrl+Z: desfazer a renomeação ou a reorganização
• Ctrl+Y: refazer a renomeação ou a reorganização
• Ctrl+,: configurações
• F1: mostrar esta ajuda
• Alt+F4: fechar a janela (encerra o app após confirmação)

Idioma

O idioma do app segue o idioma de exibição do Windows. Para alterá-lo: Configurações → Hora e idioma → Idioma e região.

Se um clipart não aparecer

• Um ponto de interrogação em vez de uma pré-visualização significa que não foi possível ler o arquivo — por exemplo, porque ele está danificado ou contém um formato que o sVectorLift não conhece.
• O sVectorLift foi feito para coleções de cliparts: desenhos, símbolos, ilustrações. Folhetos de várias páginas e modelos de impressão do CorelDRAW não são o objetivo e podem parecer incompletos.

SVGs animados

O sVectorLift mostra arquivos SVG animados como imagem estática – o movimento em si não é reproduzido.
