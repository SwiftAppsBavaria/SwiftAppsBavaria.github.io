sVectorLift Help

Overview

sVectorLift opens old vector clipart from the CorelDRAW era and converts it to SVG — graphics that today’s programs can work with again. Choose a folder on the left, and the cliparts appear as previews on the right. You can export the graphics you select to a destination folder of your choice.

Supported Formats

• CorelDRAW documents (.cdr), versions 6 to 9
• Corel Binary Meta File (.cmx) — including the old CDRX variant
• Windows Metafile (.wmf)
• Computer Graphics Metafile (.cgm)
• QuickDraw 3D metafiles (.3dm, .3dmf) — rendered as an image
• Scalable Vector Graphics (.svg) — displayed directly

Many files with the .cdr extension are in fact not CorelDRAW documents at all, but CMX. This is exactly where the usual converters fail — sVectorLift reads both.

Choose Folder

1. Click “Choose Folder…” (or ⌘O) to open the folder containing your clipart collection. The folder tree appears below it.
2. Clicking a folder in the tree loads its cliparts. Use the triangle to expand subfolders.
3. The next time you start the app, the folder you last used opens again — including the subfolder you last opened and the selected file. Via “File → Recent Folders” you can jump straight back to an earlier collection.

You can also open a single file from the Finder (“Open With” or double-click): if it is in your collection, sVectorLift jumps to it; if it is outside, it shows the file on its own and only asks for folder access when you switch to the Overview.

Use the “Filter (name or keyword)” field to hide cliparts by name or keyword.

You can change the width of the sidebar by dragging the divider toward the grid. The button at the top of the sidebar — or ⌃⌘S — hides it completely, so the cliparts use the full window width.

The chosen path is shown next to both folder buttons. Clicking it shows the path in full for copying, right-clicking takes you straight to the Finder.

Viewing Cliparts

• Use the slider in the top right to set the size of the previews.
• “Detail View” (or a double-click on a clipart) shows a single graphic at a large size. Use the ← → arrow keys to page through the folder; a double-click takes you back to the Overview.
• The previews are only computed once you see them. In very large folders, placeholders therefore appear first and fill in gradually.

Selecting

Selecting works just like in the Photos app:
• Click: select a single clipart
• ⌘-click: add individual cliparts to the selection or remove them
• ⇧-click: select a contiguous range
• Drag in empty space: draw a selection rectangle (rubber band)
• ⌘A: select all cliparts in the folder
• Click in empty space: deselect

Export

1. Choose a destination folder under “2. Export”. Clicking the path shows it in full and, if needed, takes you to the Finder.
2. “Export Selection” writes the selected cliparts, “Export All” the entire (filtered) folder.

Vector graphics are saved as .svg. Pure raster images — and 3D models — are saved as .png so that nothing is lost. SVG files are already the target format; export is disabled for them.

Using the contextual menu (right-click on a clipart), you export to the same destination folder, show the file in the Finder, rename it, or move it to the Trash. If no destination folder has been set yet, you are asked for one once.

If a target file already exists, sVectorLift asks first: “Replace”, “Keep Both” (writes alongside it, as “Name 2.svg”), “Skip” or “Cancel”. With several files you can apply your answer to the whole run using “Apply to all”. The export then runs with a progress bar in the sidebar, which you can cancel at any time.

You can undo a rename with ⌘Z and redo it with ⇧⌘Z — as long as the file is still in the open collection. While an export is running, Rename and Delete are briefly locked: the run works with the file names that applied when it started.

Export Folder Structure

To convert an entire folder along with its subfolders, use the “Export Folder Structure” window. You open it via “File → Export Folder Structure…” or the button of the same name in the sidebar, choose the source and destination folders there, and click “Export All” to start. The same folder structure is created in the destination; SVG files are copied unchanged, and folders without supported files are not created. You won’t be asked anything: anything already in the destination is skipped. If several files in a folder have the same name, each additional one gets its original extension, e.g. “geometry (cmx).svg”.

Settings

Under “sVectorLift → Settings…” (⌘,) you set the render size for 3D models.

3D models have no vector form; for export they are computed as an image. The larger the value, the sharper the PNG — and the longer the export takes. Values from 256 to 8192 pixels are allowed, the default is 1024.

In the same window you’ll also find the button for choosing the language.

Keyboard Shortcuts

• ⌘O: choose folder
• ⌘A: select all cliparts
• ← →: page through the folder in Detail View
• Double-click: switch between Overview and Detail View
• ⌃⌘S: show or hide the sidebar
• ⌘/: show this help
• ⌘W: close the window (quits the app after a prompt)
• ⌘Q: quit the app
• ⌘Z: undo rename
• ⇧⌘Z: redo rename

Language

sVectorLift uses your system’s language. If you would like to use the app in a different language, you can set this in System Settings:

System Settings → General → Language & Region → scroll down to the “Applications” section → “+” → sVectorLift → desired language

This setting applies only to sVectorLift; the rest of the system is unaffected.

If a Clipart Doesn’t Appear

• A question mark instead of a preview means the file could not be read — for example because it is damaged or contains a format that sVectorLift does not recognize.
• sVectorLift is made for clipart collections: drawings, symbols, illustrations. Multi-page brochures and print templates from CorelDRAW are not its purpose and may look incomplete.

Animated SVGs

sVectorLift shows animated SVG files as a still image – the motion itself isn't played.
