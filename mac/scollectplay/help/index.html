1. Getting Started

What is sCollectPlay?

sCollectPlay is a companion app to sCollect. It focuses purely on playback: no importing, no metadata editing, no synchronization. In return, it reads from three sources: folders, iTunes/Apple Music XML, and sCollect libraries.

First Launch

On first launch, sCollectPlay shows a welcome dialog with notes on playing special formats (see section 4). Afterwards, the source picker appears, where you can choose a library.

Tip: sCollectPlay requires macOS 14.0 or newer and is available in 24 languages.

2. Choosing a Source

sCollectPlay supports three source types, available at startup or later via the File menu:

Scan a Folder

Pick any folder – sCollectPlay scans it recursively for media files and reads metadata directly from the files (AVFoundation for audio/video, EbookTagKit for EPUB/PDF). This is the easiest way to get started without a sCollect library.

  • Accumulating: You can add multiple folders one after another – their contents are merged. On the next app launch, all previously scanned folders appear as they were last read, without being scanned again.
  • MKV detection: Files with an .mp4 extension that are actually MKV are detected by their EBML signature and tagged accordingly.
  • Classification by content: sCollectPlay sorts audio by what the file says about itself: .m4b files and titles with the genre Audiobook, Audio Theatre or Spoken Word (also in German, such as Hörbuch, Hörspiel or Kabarett) appear under “Audiobook”, podcasts and titles with the genre Podcast or Speech under “Podcast”, everything else under “Music”. It recognizes music videos, feature films and series by the media kind that iTunes, for example, writes into the file, and series also by “S01E02” in the file name. Movies that name a camera or carry a camera file name such as IMG_1234 appear under “Camera”, all others under “Home Video”. E-books and PDFs are recognized by their file extension. The sidebar shows only types that contain something.
  • Choosing the type yourself: If a title is in the wrong place, drag it from the list onto another type in the sidebar – while you drag, the empty types appear there as well. sCollectPlay remembers this for that file, including the next time it reads the folder; the file itself is not changed.

Under Settings > Library > Scanned Folders, Refresh reads in only what has changed since the last read: new, modified and removed files. Use Remove to take a folder out again together with its tracks. Faster: File > Refresh Scanned Folders (⌘R) or the ↻ button to the right of the search field. Both refresh all folders one after another; in Settings, Refresh All does the same. At the end, a message tells you what is new, changed or removed.

sCollect Library

Choose the main folder of a sCollect library (the folder that contains the .scollect bundle; for older libraries, the folder with settings.json). sCollectPlay reads the library files, playlists, and settings directly – including configurable field labels and smart playlists. Selecting a sCollect library replaces an active folder scan. You can also double-click the .scollect bundle in the Finder to open the library.

sCollectPlay changes nothing in the library itself. When you rate a track or play music, an audiobook or a film to the end, it notes this with date and time in the file rueckmeldungen.json in the library folder – whether you opened the master or a copy. sCollect takes it over when the master is opened, before Project, and before Resolve Sync Errors…: for the rating the newer one wins, plays are added up. sCollect then writes the rating into the file and passes everything on to all copies. Until then, sCollectPlay already shows its own ratings and plays.

iTunes/Apple Music XML

Choose a Library.xml file or a .musiclibrary bundle. sCollectPlay parses tracks and playlists (standard and smart). System playlists (Master, Distinguished Kind) are skipped. sCollectPlay takes the media types from the XML itself: Music, Audiobook, Podcast, Home Video, Feature Film, Series and Music Video. On open, you’re asked once for access to the corresponding media folder so sCollectPlay can reach the files.

Note: Exactly one kind of source is loaded at a time. A folder scan can be extended with more folders; opening a library or an XML, on the other hand, replaces the current contents. The scanned folders remain saved and can be reactivated with a single click under Settings > Library. The window’s title bar shows the kind and name of the source, e.g. Folder “Music” or Library “sCollect”; point to the title to see the full path.

Recently Used Sources

In the File menu, each command is followed by the most recently used sources of that kind: Recent Folders, Recent Libraries, and Recent XML Libraries, up to ten each. A click opens the source again; if it can no longer be reached, it disappears from the list. Clear List empties a list. On the next launch, sCollectPlay loads the most recently used source by itself. If it is on a network volume, the app asks first – you can turn this off under Settings > General > Warn about network library at startup. Settings > Library shows the same lists, with Load for each entry.

3. Browsing Your Library

Sidebar

The sidebar shows categories and media types as a two-level accordion (e.g. Audio > Music / Audiobook / Podcast); next to each media type is the number of its items. The playlists of an sCollect library appear with their category under Playlists, and folders can be expanded. Playlists without a category – and all playlists from a scanned folder or an XML library – appear in the Playlists section below. Switching between media types or playlists updates the track list on the right; the window title shows how many tracks it currently contains and, for a selection, their number and total duration.

Track List

  • Customize columns: Right-click a column header > Customize Columns… to choose the visible columns. Visibility, order, and widths apply per media type or playlist; with a sCollect library, sCollectPlay takes the columns from there as a starting point and remembers your changes on this Mac.
  • Sort: Click a column header to sort by that column; click again to reverse the order. Hold Shift to add another column as a secondary sort – active columns show an arrow and an order number (e.g. Album↓1, Artist↑2). Option-click an active column header to remove that column from the sort again. Right-clicking a column header offers Reset Sorting to sort by the main column only. Each playlist sorts on its own; its No. column – the position in the playlist – returns to the original order.
  • Current track: A speaker in front of the title shows what is playing. The selection moves along when the next track starts, as long as it was on the playing track.
  • Column width: Drag the divider in the column header. Right-click a column header > Optimal Width fits all text columns to their content.
  • Rating: With a sCollect library, click a star in the Rating column: the first click sets a full star, the second a half star, the third clears the rating. To rate several tracks at once, select them, then right-click > Rating. With scanned folders and XML libraries the stars only show the rating.
  • Column order: Drag a column header to a different position.
  • Linked: This optional column – its header shows a chain symbol – marks with a checkmark the items whose file lies outside the media folders of the sCollect library; in sCollect those are the files imported with Leave in Place. For scanned folders and XML libraries the column stays empty, because there are no media folders there.

Column Browser

The column browser adds several selection columns above the track list – similar to the column browser in Apple Music. The button with the three columns on the right of the toolbar shows and hides it. It is available in the media type views and in playlists; in a playlist it shows the values of its tracks.

  • Columns: Genre, artist, album, composer, and grouping. Which of them are shown is taken from the settings of the sCollect library – change it in sCollect.
  • Selecting: Clicking a value filters by it, ⌘-click adds a value to the selection or removes it. Within one column several values act as «or», between columns as «and». The topmost row All clears that column's selection again.
  • Groups: If a column holds a great many entries, sCollectPlay groups them by initial letters into expandable groups. A click opens one group and closes the previous one, ⌘-click keeps several open at once.
  • Keyboard: ↑ and ↓ move the cursor through the list – the value under the cursor is applied after one second, ⏎ applies it right away. → opens a group or steps into it, ← closes it or jumps to the parent row.
  • Size: The dividers between the columns and the bottom edge of the browser can be dragged.

Selection, column widths, and height are remembered by sCollectPlay on this Mac. The sCollect library is left untouched – sCollectPlay never writes to its settings.

Search

The search field in the toolbar filters by title, artist, album artist, album, composer, genre, comment, grouping, work, movement name, and year. In playlists, the search additionally applies to the playlist contents.

4. Playback

Playing Audio

Select an audio entry and press Space or the play button in the player bar. The player bar shows:

  • Cover art, title, and artist
  • Timeline for scrubbing forward and backward
  • Volume control
  • Shuffle and repeat modes
  • For videos additionally: slow motion and frame-step controls

Playing Video

Movies open in a separate video window; at the end of a movie, playback continues with the next track, provided Continue playing at end is turned on for its media type. Audio tracks and subtitles can be switched in the Playback menu. Use ⌘⌃F to toggle full-screen mode.

External Playback

Some formats are not natively supported by macOS / AVFoundation. sCollectPlay detects this and opens these files automatically in an external player:

  • Special video formats: MKV, AVI, FLV, MPG, MPEG, VOB, DivX
  • Modern codecs: AV1 in MP4 (on older Macs without a hardware decoder)
  • High-resolution audio: DSD (DFF, DSF), WavPack (WV)
  • Other audio formats: OGG Vorbis, WMA

The preferred player is detected automatically: VLC, IINA, or MPV (in that order). You can override the choice in Settings > Playback/Playlist > External player for unsupported codecs. If none of these players are installed, the default app for the format is used – we recommend VLC Media Player (free, open source).

Playback Modes

  • Shuffle: Plays the current list in random order.
  • Repeat (List): Repeats the entire list after the last track.
  • Repeat (Track): Repeats the current track endlessly.

Continue playing at end

Whether playback continues with the next track after one ends is set per media type under Settings > Playback/Playlist > Continue playing at end. By default it is on for all audio types and for music videos, and off for feature films, series, home videos and camera videos – a movie then stops at its end (or at its stop marker). Repeat (Track) repeats regardless. sCollectPlay remembers what you change here; for all other media types, the library’s setting applies.

Apple Music Export

Playlists or a selection of tracks can be sent to Apple Music:

  • Sidebar context menu: Right-click a playlist > Send Playlist to Apple Music.
  • Track context menu: Send as Playlist to Apple Music (selected tracks as «Selection»).
  • File menu: Send Playlist to Apple Music… (active when a playlist is selected).

sCollectPlay creates the playlist in Apple Music and adds the tracks. Tracks in formats Apple Music does not accept are not sent and are listed in a message. If you have sent the playlist before and it still exists in Apple Music, sCollectPlay asks whether to update it or create a new one; with «Don’t ask again» or the Apple Music export setting (see Settings) it is updated without asking.

5. Playlists

sCollectPlay shows all playlists from the loaded library – both standard and smart playlists. Smart playlists are re-evaluated against their stored criteria whenever the item set changes; a smart playlist created in sCollect under a category only evaluates that category’s tracks. They can only be changed in sCollect; in addition, you can create your own playlists.

When loading an XML library, both standard and smart playlists are imported. System playlists (Master, Distinguished Kind) are skipped.

My Playlists

Under My Playlists in the sidebar, you create your own playlists – regardless of whether a folder, an XML, or a library is loaded:

  • Create: The plus button next to My Playlists offers New Playlist… and New Smart Playlist….
  • Fill: Add to Playlist in the track list’s context menu adds the selected tracks to a playlist or creates a new one; in one of your own playlists, Remove from Playlist takes them out again.
  • Smart playlists assemble themselves according to rules; Edit in the context menu changes the rules.
  • Rename, delete, send to Apple Music, export for VLC: via the playlist’s context menu.

sCollectPlay stores your own playlists on this Mac, never in the library or the XML; it finds their tracks again by file path, even after a new scan.

Playlists on iPhone or iPod

sCollectPlay does not transfer anything to a device directly. The way leads through Apple Music and the Finder:

  1. Send to Apple Music: Right-click the playlist in the sidebar and choose Send Playlist to Apple Music, or select it and choose File > Send Playlist to Apple Music… To send selected tracks, choose Send as Playlist to Apple Music from the track list's context menu.
  2. Connect the device: Connect your iPhone, iPad or iPod to the Mac with a cable and select it in the Finder sidebar under «Locations».
  3. Tick the playlist: In the «Music» tab, turn on «Sync music onto [device]», choose «Selected artists, albums, genres, and playlists» and tick the list under «Playlists».
  4. Click «Apply».

Apple Music accepts MP3, AAC and ALAC (.m4a), AIFF and WAV. sCollectPlay does not send tracks in other formats (such as FLAC, OGG/Opus, raw .aac or MKV) and lists them in a message – they need to be converted first, for example with «Convert Format» in sCollect.

If the playlist changes, send it again: sCollectPlay asks whether to update the existing list in Apple Music or create a new one. Then sync again in the Finder.

Note: If «Sync Library» (iCloud) is turned on on the iPhone, the Finder does not transfer music. The playlist then reaches the device through iCloud, provided «Sync Library» is also turned on in Apple Music on the Mac – this requires an Apple Music or iTunes Match subscription.

Playlists on Android (VLC)

Right-click the playlist in the sidebar and choose Export for VLC/Device…, or select it and choose File > Export Playlist for VLC/Device… This works with every playlist, including those under My Playlists. As the destination, choose an SD card, a USB stick or any folder. sCollectPlay creates a folder named after the playlist there, containing the files, sorted by artist and album, and the playlist as an .m3u8 file with relative paths.

  • The whole playlist is exported, even while the search field is filtering it – its audio and video files; books and miscellaneous items are skipped and counted in the final message.
  • If you export the same playlist to the same place again, sCollectPlay copies only what is new or has changed and rewrites the list. Tracks you removed from the playlist are no longer in the list, but their files stay in the folder.
  • While exporting, a bar appears below the track list; the cross next to it cancels. The list then contains the tracks copied up to that point.

Then move the whole folder to the Android device: insert the card or stick, or copy it over a cable with an MTP app (macOS does not show an Android phone as a drive). Do not split the folder up – the list finds its tracks only relative to its own location. VLC shows the playlist among its playlists once it has scanned the storage; if the folder lies outside the scanned locations, add it to the media library in VLC.

The folder also works with VLC on another Mac or PC and with any player that reads M3U8 lists.

6. Deleting Media Files

The track context menu has a Delete media file entry. By default, a confirmation dialog appears beforehand (can be disabled in Settings). The file is moved to the Trash, and the entry is removed from the library.

With Edit > Undo (⌘Z) you bring the file back from the Trash, together with its entry; Edit > Redo (⇧⌘Z) deletes it again.

Network shares: SMB and NFS shares typically have no Trash. sCollectPlay detects this and asks you to confirm before deleting – the file is removed permanently and cannot be restored. You can cancel; in that case, both entry and file remain unchanged.

7. Settings

Open Preferences via sCollectPlay > Settings… (⌘,). They are organized into several tabs; some fields are read-only (showing values from the loaded sCollect library or defaults) – they indicate what would be available in sCollect.

General

  • Confirm deletion: Ask before moving files to the Trash.
  • Warn about network library at startup: Asks at startup before a source on a network volume is loaded.
  • Language: The app follows the system language. The Open language settings in System Settings button takes you to General > Language & Region; in the «Applications» section there you choose a separate language for sCollectPlay.
  • Artwork folder: Cover images normally sit in a folder «Artworks» inside the library. With Choose… you specify another folder; it applies only to the loaded library, and Remove detaches it again.
  • Media Folder: appears only if the library uses folders outside its own folder. For each folder, Choose grants access and Remove withdraws it.

Below these, grayed out, are the settings that only sCollect can change (such as album covers, books & PDFs, multiple values, duplicates).

Library

At the top, the three sources are listed one below the other: Scanned Folders, XML Library, and sCollect Library. Only one is active at a time – its circle is filled. Clicking another circle switches to the most recently used source of that kind; scanned folders come back with their saved state, without a new scan. If there is none yet, the selection dialog opens.

  • Scanned Folders: the path, number of tracks and time of the last read for each folder, plus Refresh and Remove.
  • XML Library and sCollect Library: the most recently used entries, each with Load. For the sCollect library, the Storage location of the loaded library is also shown, with Change….

Below these, grayed out, are the fields that only sCollect offers (Import, Media Folder, Actions).

Playback/Playlist

  • Apple Music export: Always update existing playlist (don’t ask).
  • Video window always on top: The video window always stays above all other windows.
  • Pause video when minimized: Pauses playback while the video window is minimized and resumes it when the window is restored.
  • Volume during slow motion / frame step: Volume reduction in dB during slow-motion and single-frame mode.
  • External player for unsupported codecs: Preferred player for codecs that AVFoundation cannot decode (see section 4). Detected: VLC, IINA, and MPV.

Category Labels and Field Labels

These two tabs show the names of the categories and media types, and of the fields, as the loaded sCollect library defines them. They can only be changed in sCollect.

Statistics

The number of tracks per media type and of playlists per category, plus the total number of tracks.

Note: Disabled fields show settings that are available in sCollect (the main app) but not in sCollectPlay – for example tag editing, import modes, or sync options.
