sVectorLift 설명서

개요

sVectorLift는 CorelDRAW 시대의 오래된 벡터 클립아트를 열어 SVG로 변환합니다. 덕분에 오늘날의 프로그램에서도 다시 사용할 수 있는 그래픽이 됩니다. 왼쪽에서 폴더를 선택하면 오른쪽에 클립아트가 미리보기로 나타납니다. 선택한 그래픽은 원하는 대상 폴더로 내보낼 수 있습니다.

지원되는 포맷

• CorelDRAW 도큐멘트(.cdr), 버전 6 ~ 9
• Corel Binary Meta File(.cmx) — 오래된 CDRX 방식도 지원
• Windows Metafile(.wmf)
• Computer Graphics Metafile(.cgm)
• QuickDraw 3D 메타파일(.3dm, .3dmf) — 이미지로 렌더링됩니다
• Scalable Vector Graphics (.svg) — 바로 표시됩니다

확장자가 .cdr인 파일 중 상당수는 실제로는 CorelDRAW 도큐멘트가 아니라 CMX입니다. 일반적인 변환기는 바로 이 지점에서 실패하지만, sVectorLift는 두 가지 모두를 읽습니다.

폴더 선택

1. “폴더 선택 …”(또는 ⌘O)을 클릭하여 클립아트 모음이 들어 있는 폴더를 여십시오. 그 아래에 폴더 트리가 나타납니다.
2. 트리에서 폴더를 클릭하면 해당 클립아트가 로드됩니다. 하위 폴더는 삼각형을 클릭하여 펼칩니다.
3. 다음 실행 시 마지막으로 사용한 폴더가 다시 열립니다 — 마지막으로 연 하위 폴더와 선택했던 파일까지 함께. “파일 → 최근 사용한 폴더”를 통해 이전 모음으로 곧바로 돌아갈 수 있습니다.

파일 하나만 Finder에서 열 수도 있습니다(“다음으로 열기” 또는 이중 클릭). 그 파일이 모음 안에 있으면 sVectorLift가 그곳으로 이동하고, 밖에 있으면 단독으로 표시하며, 개요로 전환할 때에야 비로소 폴더 접근 권한을 묻습니다.

“필터(이름 또는 키워드)” 필드를 사용하면 이름이나 키워드로 클립아트를 걸러낼 수 있습니다.

사이드바의 너비는 격자와의 경계선을 끌어서 조절합니다. 사이드바 상단의 버튼 또는 ⌃⌘S를 사용하면 사이드바를 완전히 가려 클립아트가 윈도우의 전체 너비를 사용하도록 할 수 있습니다.

두 폴더 버튼 옆에는 선택한 경로가 표시됩니다. 경로를 클릭하면 전체 경로가 복사할 수 있는 형태로 나타나고, 오른쪽 버튼으로 클릭하면 곧바로 Finder로 이동합니다.

클립아트 보기

• 오른쪽 상단의 슬라이더로 미리보기 이미지의 크기를 조절합니다.
• “상세 보기”(또는 클립아트를 이중 클릭)를 사용하면 하나의 그래픽이 크게 표시됩니다. 화살표 키 ← → 로 폴더 안을 넘겨볼 수 있고, 이중 클릭하면 “개요”로 돌아갑니다.
• 미리보기 이미지는 화면에 보일 때 비로소 계산됩니다. 따라서 아주 큰 폴더에서는 먼저 자리 표시자가 나타났다가 차례로 채워집니다.

선택

선택 방식은 “사진” 앱과 동일합니다:
• 클릭: 클립아트 하나를 선택합니다
• ⌘-클릭: 개별 클립아트를 선택에 추가하거나 선택에서 제외합니다
• ⇧-클릭: 연속된 범위를 선택합니다
• 빈 곳에서 드래그: 선택 사각형(고무줄)을 만듭니다
• ⌘A: 폴더의 모든 클립아트를 선택합니다
• 빈 곳 클릭: 선택을 해제합니다

내보내기

1. “2. 내보내기”에서 “대상 폴더 …”를 선택하십시오. 경로를 클릭하면 전체 경로가 표시되고, 필요하면 Finder로 이동합니다.
2. “선택 항목 내보내기”는 선택한 클립아트를, “모두 내보내기”는 (필터가 적용된) 폴더 전체를 내보냅니다.

벡터 그래픽은 .svg로 저장됩니다. 순수 래스터 이미지와 3D 모델은 내용이 손실되지 않도록 .png로 저장됩니다. SVG 파일은 이미 대상 형식이므로 이러한 파일은 내보내기가 비활성화됩니다.

단축 메뉴(클립아트에서 오른쪽 클릭)를 통해 같은 대상 폴더로 내보내거나, 파일을 “Finder에서 보기 …”하거나, 이름을 변경하거나, “휴지통으로 이동”할 수 있습니다. 대상 폴더가 아직 설정되지 않았으면 한 번 묻습니다.

대상 파일이 이미 있으면 sVectorLift가 먼저 물어봅니다: “대치”, “둘 다 유지”(옆에 “이름 2.svg”로 저장), “건너뛰기” 또는 “취소”. 여러 파일을 내보낼 때는 “모두에 적용”으로 답변을 전체 작업에 적용할 수 있습니다. 그다음 내보내기는 사이드바의 진행 막대와 함께 진행되며, 언제든지 중단할 수 있습니다.

이름 변경은 ⌘Z로 실행 취소하고 ⇧⌘Z로 다시 실행할 수 있습니다. 다만 해당 파일이 아직 열려 있는 모음 안에 있을 때까지만 가능합니다. 내보내기가 진행되는 동안에는 이름 변경과 삭제가 잠시 잠깁니다. 내보내기는 시작할 때 유효했던 파일 이름으로 작업하기 때문입니다.

폴더 구조 내보내기

하위 폴더를 포함한 폴더 전체를 변환하려면 “폴더 구조 내보내기” 윈도우를 사용합니다. 이 윈도우는 “파일 → 폴더 구조 내보내기 …” 또는 사이드바에 있는 같은 이름의 버튼으로 엽니다. 여기서 소스 폴더와 대상 폴더를 선택하고 “모두 내보내기”로 시작합니다. 대상 폴더에는 동일한 폴더 구조가 만들어집니다. 이때 SVG 파일은 변경 없이 복사되며, 지원되는 파일이 없는 폴더는 만들어지지 않습니다. 별도로 묻지 않으며, 대상 폴더에 이미 있는 항목은 건너뜁니다. 한 폴더에 같은 이름의 파일이 여러 개 있으면 두 번째 파일부터 원래 확장자가 붙습니다(예: “geometry (cmx).svg”).

설정

“sVectorLift → 설정 …”(⌘,)에서 3D 모델 렌더링 크기를 설정합니다.

3D 모델에는 벡터 형태가 없어서 내보낼 때 이미지로 계산됩니다. 값이 클수록 PNG가 선명해지고, 그만큼 내보내기에 시간이 더 걸립니다. 256에서 8192픽셀까지 지정할 수 있으며, 기본값은 1024입니다.

같은 윈도우에서 언어 선택 버튼도 찾을 수 있습니다.

키보드 단축키

• ⌘O: 폴더를 선택합니다
• ⌘A: 모든 클립아트를 선택합니다
• ← →: 상세 보기에서 폴더 안을 넘겨봅니다
• 이중 클릭: 개요와 상세 보기를 전환합니다
• ⌃⌘S: 사이드바를 표시하거나 가립니다
• ⌘/: 이 도움말을 표시합니다
• ⌘W: 윈도우를 닫습니다(확인 후 앱을 종료합니다)
• ⌘Q: 앱을 종료합니다
• ⌘Z: 이름 변경을 실행 취소합니다
• ⇧⌘Z: 이름 변경을 다시 실행합니다

언어

sVectorLift는 시스템의 언어를 따릅니다. 앱을 다른 언어로 사용하려면 시스템 설정에서 지정하십시오:

시스템 설정 → 일반 → 언어 및 지역 → 맨 아래로 스크롤하여 “응용 프로그램” 섹션 → “+” → sVectorLift → 원하는 언어

이 설정은 sVectorLift에만 적용되며, 시스템의 나머지 부분에는 영향을 주지 않습니다.

클립아트가 나타나지 않는 경우

• 미리보기 대신 물음표가 표시되면 해당 파일을 읽을 수 없었다는 뜻입니다. 파일이 손상되었거나 sVectorLift가 알지 못하는 포맷이 포함되어 있을 수 있습니다.
• sVectorLift는 클립아트 모음(그림, 심볼, 일러스트레이션)을 위해 만들어졌습니다. CorelDRAW의 여러 페이지짜리 브로슈어나 인쇄용 템플릿은 대상이 아니며 불완전하게 보일 수 있습니다.

애니메이션 SVG

애니메이션 SVG 파일은 sVectorLift에서 정지 이미지로 표시되며, 움직임 자체는 재생되지 않습니다.
