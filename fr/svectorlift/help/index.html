Manuel de sVectorLift

Vue d’ensemble

sVectorLift ouvre les anciens cliparts vectoriels de l’époque CorelDRAW et les convertit en SVG — des images que les programmes actuels peuvent de nouveau exploiter. Choisissez un dossier à gauche : les cliparts apparaissent à droite sous forme d’aperçus. Vous exportez les images sélectionnées dans un dossier de destination de votre choix.

Formats pris en charge

• Documents CorelDRAW (.cdr), versions 6 à 9
• Corel Binary Meta File (.cmx) — y compris l’ancienne variante CDRX
• Windows Metafile (.wmf)
• Computer Graphics Metafile (.cgm)
• Métafichiers QuickDraw 3D (.3dm, .3dmf) — rendus sous forme d’image
• Scalable Vector Graphics (.svg) — s’affichent directement

De nombreux fichiers portant l’extension .cdr ne sont en réalité pas des documents CorelDRAW, mais des CMX. C’est précisément là que les convertisseurs habituels échouent — sVectorLift lit les deux.

Choisir un dossier

1. Cliquez sur « Choisir un dossier… » (ou ⌘O) pour ouvrir le dossier contenant votre collection de cliparts. L’arborescence des dossiers apparaît en dessous.
2. Un clic sur un dossier dans l’arborescence charge ses cliparts. Le triangle permet de déplier les sous-dossiers.
3. Au prochain démarrage, le dernier dossier utilisé se rouvre — avec le dernier sous-dossier ouvert et le fichier sélectionné. Via « Fichier → Dossiers récents », vous revenez directement à une collection antérieure.

Vous pouvez aussi ouvrir un fichier isolé depuis le Finder (« Ouvrir avec » ou double-clic) : s’il se trouve dans votre collection, sVectorLift y accède ; s’il est à l’extérieur, il l’affiche seul et ne demande l’accès au dossier que lorsque vous passez à la Vue d’ensemble.

Le champ « Filtrer (nom ou mot-clé) » permet de masquer des cliparts selon leur nom ou un mot-clé.

Vous modifiez la largeur de la barre latérale en faisant glisser le séparateur vers la grille. Le bouton en haut de la barre — ou ⌃⌘S — la masque complètement, afin que les cliparts occupent toute la largeur de la fenêtre.

À côté des deux boutons de dossier figure le chemin choisi. Un clic l’affiche en entier pour que vous puissiez le copier, un clic droit vous emmène directement dans le Finder.

Consulter les cliparts

• Le curseur en haut à droite permet de régler la taille des aperçus.
• « Vue détaillée » (ou un double-clic sur un clipart) affiche une image en grand. Les touches fléchées ← → permettent de parcourir le dossier ; un double-clic ramène à la Vue d’ensemble.
• Les aperçus ne sont calculés qu’au moment où vous les voyez. Dans les dossiers très volumineux, des espaces réservés apparaissent donc d’abord, puis se remplissent progressivement.

Sélectionner

La sélection fonctionne comme dans l’app Photos :
• Clic : sélectionner un clipart
• ⌘-clic : ajouter ou retirer des cliparts de la sélection
• ⇧-clic : sélectionner une plage continue
• Glisser dans une zone vide : tracer un rectangle de sélection (lasso élastique)
• ⌘A : sélectionner tous les cliparts du dossier
• Clic dans une zone vide : désélectionner

Exporter

1. Choisissez un dossier de destination sous « 2. Exportation ». Un clic sur le chemin l’affiche en entier et permet, si nécessaire, d’accéder au Finder.
2. « Exporter la sélection » enregistre les cliparts sélectionnés, « Tout exporter » l’intégralité du dossier (filtré).

Les images vectorielles sont enregistrées au format .svg. Les images matricielles — ainsi que les modèles 3D — sont enregistrées au format .png afin que rien ne soit perdu. Les fichiers SVG sont déjà au format cible ; pour eux, l’exportation est désactivée.

Le menu contextuel (clic droit sur un clipart) permet d’exporter vers le même dossier de destination, d’afficher le fichier dans le Finder, de le renommer ou de le placer dans la corbeille. Si aucun dossier de destination n’a encore été défini, il vous est demandé une fois.

Si un fichier de destination existe déjà, sVectorLift vous demande d’abord quoi faire : « Remplacer », « Conserver les deux » (écrit à côté, sous la forme « Nom 2.svg »), « Ignorer » ou « Annuler ». Pour plusieurs fichiers, « Appliquer à tout » reprend votre réponse pour toute la série. L’exportation se déroule ensuite avec une barre de progression dans la barre latérale, et vous pouvez l’arrêter à tout moment.

Vous annulez un renommage avec ⌘Z et le rétablissez avec ⇧⌘Z — tant que le fichier se trouve encore dans la collection ouverte. Pendant un export, les commandes Renommer et Supprimer sont brièvement désactivées : l’export travaille avec les noms de fichiers qui étaient valables à son démarrage.

Exporter la structure de dossiers

Pour convertir un dossier entier avec ses sous-dossiers, utilisez la fenêtre « Exporter la structure de dossiers ». Vous l’ouvrez via « Fichier → Exporter la structure de dossiers… » ou avec le bouton du même nom dans la barre latérale, vous y choisissez le dossier source et le dossier de destination, puis vous lancez l’opération avec « Tout exporter ». La même structure de dossiers est créée dans la destination ; les fichiers SVG sont copiés tels quels, et les dossiers sans fichiers pris en charge ne sont pas créés. Aucune question n’est posée : ce qui se trouve déjà dans la destination est ignoré. Si plusieurs fichiers d’un même dossier portent le même nom, chacun des suivants reçoit son extension d’origine, par exemple « geometry (cmx).svg ».

Réglages

Sous « sVectorLift → Réglages… » (⌘,), vous définissez la taille de rendu des modèles 3D.

Les modèles 3D n’ont pas de forme vectorielle ; pour l’exportation, ils sont calculés sous forme d’image. Plus la valeur est élevée, plus le PNG est net — et plus l’exportation est longue. Les valeurs autorisées vont de 256 à 8192 pixels, la valeur par défaut est 1024.

Dans la même fenêtre se trouve aussi le bouton pour le choix de la langue.

Raccourcis clavier

• ⌘O : choisir un dossier
• ⌘A : sélectionner tous les cliparts
• ← → : parcourir le dossier dans la Vue détaillée
• Double-clic : basculer entre la Vue d’ensemble et la Vue détaillée
• ⌃⌘S : afficher ou masquer la barre latérale
• ⌘/ : afficher cette aide
• ⌘W : fermer la fenêtre (quitte l’app après confirmation)
• ⌘Q : quitter l’app
• ⌘Z : annuler le renommage
• ⇧⌘Z : rétablir le renommage

Langue

sVectorLift reprend la langue de votre système. Si vous souhaitez utiliser l’app dans une autre langue, réglez cela dans les Réglages Système :

Réglages Système → Général → Langue et région → faites défiler jusqu’à la section « Applications » → « + » → sVectorLift → langue souhaitée

Ce réglage ne s’applique qu’à sVectorLift ; le reste du système n’est pas modifié.

Si un clipart n’apparaît pas

• Un point d’interrogation à la place d’un aperçu signifie que le fichier n’a pas pu être lu — par exemple parce qu’il est endommagé ou qu’il contient un format que sVectorLift ne connaît pas.
• sVectorLift est conçu pour les collections de cliparts : dessins, symboles, illustrations. Les brochures de plusieurs pages et les modèles d’impression CorelDRAW ne sont pas son objectif et peuvent apparaître incomplets.

SVG animés

sVectorLift affiche les fichiers SVG animés sous forme d’image fixe – l’animation elle-même n’est pas lue.
