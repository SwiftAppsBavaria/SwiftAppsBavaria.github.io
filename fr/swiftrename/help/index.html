Aide SwiftRename

Aperçu

SwiftRename est un outil permettant de renommer et d'organiser plusieurs fichiers simultanément. Vous pouvez renommer des fichiers par date, les numéroter, leur attribuer un préfixe et les classer automatiquement dans une structure de dossiers.

Sélectionner les dossiers

1. Cliquez sur l'icône de dossier dans le dossier d'entrée pour sélectionner le dossier contenant les fichiers à renommer. Vous pouvez également faire glisser les dossiers depuis le Finder vers les champs de dossier. À l'aide de la petite flèche sur l'icône de dossier, vous sélectionnez à nouveau rapidement un dossier récemment utilisé.
2. Activez « Inclure les sous-dossiers » pour traiter également les fichiers contenus dans les sous-dossiers.
3. Sélectionnez un dossier de sortie dans lequel les fichiers renommés seront copiés ou déplacés. Les dossiers d'entrée et de sortie peuvent être identiques (renommage au même emplacement).
4. Avec « Inverser », vous échangez les dossiers d'entrée et de sortie. Avec « Actualiser », vous rechargez les deux listes de fichiers.

Modes de renommage

• Date uniquement : nomme les fichiers en fonction de leur date de création (par exemple « 2024-01-15 à 14-30-00.jpg »)
• Date + nom original : ajoute la date avant le nom de fichier d'origine (par exemple « 2024-01-15 à 14-30-00 - IMG_4523.jpg »)
• Numérotation avec préfixe : numérote les fichiers de manière consécutive avec un préfixe sélectionnable (par exemple « Vacances_0001.jpg »)
• Conserver le nom d'origine : trie les fichiers dans la structure de dossiers sans modifier le nom des fichiers

Si les noms de fichiers sont identiques, un compteur est automatiquement ajouté (par exemple « _1 », « _2 »).

Structure des dossiers

Les fichiers peuvent être automatiquement classés dans des sous-dossiers par date :
• Aucune : Tous les fichiers directement dans le dossier de sortie
• Conserver : Reproduit la structure des sous-dossiers du dossier d’entrée
• Année : p. ex. « 2024/ »
• Année/Mois : p. ex. « 2024/01/ »
• Année/Mois/Jour : p. ex. « 2024/01/15/ »

Si les fichiers couvrent plusieurs décennies, des dossiers de décennie supplémentaires sont créés (p. ex. « 2011-2020/2015/… »).

Pour « Année/Mois » et « Année/Mois/Jour », l’option « Date complète dans les noms de sous-dossiers » apparaît directement sous le sélecteur de structure de dossiers. Une fois activée, les dossiers de mois et de jour contiennent la date complète (par ex. « 2024/2024-01/2024-01-15/ » au lieu de « 2024/01/15/ »).

Aperçu des noms

En haut de la liste d'entrée, trois vues sont proposées : liste, arborescence et aperçu des noms (icône en forme d'œil). Dans l'aperçu, le nouveau nom prévu et son dossier de destination apparaissent sous chaque nom de fichier actuel – par rapport au dossier de sortie, donc y compris les dossiers d'année et de décennie.

L'aperçu nécessite un dossier de sortie sélectionné et se recalcule dès que vous modifiez le mode, le préfixe, la structure des dossiers ou l'option « Utiliser la date de prise de vue ». Avec beaucoup de fichiers, il se remplit progressivement, car la date de prise de vue doit être lue pour chaque fichier.

Ce sont des noms prévus : le fait qu'un fichier soit ignoré comme doublon ou qu'un compteur (« _1 ») doive être ajouté en cas de noms identiques ne se décide qu'à l'exécution.

Date de la caméra (EXIF)

Lorsque l'option « Utiliser la date de prise de vue » est activée, la date de prise de vue est lue à partir des données EXIF pour les photos et les vidéos. Cette date est plus précise que la date de création du fichier, qui peut changer lors de la copie.

De nombreux formats photo sont pris en charge, notamment JPEG, HEIC, PNG, TIFF et les formats RAW courants (CR2, CR3, NEF, ARW, DNG, RAF, etc.).

Si aucune date EXIF n'est disponible, la date de création du fichier est automatiquement utilisée.

Filtre d'extension de fichier

Utilisez le menu déroulant « Extensions de fichiers » pour filtrer les fichiers affichés par type :
• Les extensions disponibles sont détectées automatiquement depuis le dossier d’entrée.
• Sélectionnez une ou plusieurs extensions en cliquant (⌘-clic pour basculer, ⇧-clic pour une plage).
• « Toutes les extensions » réinitialise le filtre et affiche tous les fichiers.
• Le filtre est conservé lors du changement de dossier, tant que les extensions y existent.

Détection des doublons

Lorsque l'option « Vérifier les doublons » est activée, les doublons sont détectés avant la copie ou le déplacement, tant dans le dossier source que dans le dossier de destination (toute l'arborescence de destination). La détection est basée sur la taille du fichier et une comparaison octet par octet du contenu du fichier ; pour les images et les vidéos, les métadonnées telles que l'EXIF sont ignorées. La date n'intervient que pour la comparaison supplémentaire du contenu des images.

Les doublons trouvés sont affichés dans un aperçu avec des images miniatures. Vous pouvez alors décider de continuer (les doublons sont ignorés) ou d'annuler l'opération.

Avec l'option supplémentaire « Comparer uniquement le contenu de l'image (lent) », seules les données de pixels décodées des images sont comparées. Les métadonnées telles que les mots-clés, les balises ou les entrées EXIF sont ignorées. Cela permet également de détecter des images identiques qui ont été recompressées lors de l'enregistrement des mots-clés. Cette variante est nettement plus lente et n'est active que lorsque la vérification des doublons est activée. Seules les images avec le même format de fichier et une taille de fichier similaire sont considérées comme candidates. La différence de taille maximale autorisée peut être ajustée dans les Réglages (⌘,) sous « Tolérance de taille pour la comparaison d'images » (par défaut : 128 Ko). Les formats RAW nécessitent souvent des valeurs plus élevées, car les métadonnées telles que les mots-clés peuvent occuper plusieurs dizaines de Ko par entrée.

Si un programme a réencapsulé ou réexporté une vidéo, celle-ci est considérée comme un fichier distinct, même si l’image et le son sont identiques. Les vidéos ne disposent pas d’une comparaison du contenu comme les images.

Copier et déplacer

• Copier : les fichiers originaux sont conservés, des copies sont créées dans le dossier de sortie.
• Déplacer : les fichiers sont déplacés vers le dossier de sortie.

Avant l'exécution, SwiftRename vérifie si l'espace disponible sur le lecteur cible est suffisant. Si l'espace est insuffisant, un avertissement s'affiche. Vous pouvez néanmoins poursuivre l'opération.

La taille totale des fichiers s'affiche sous la liste d'entrée, tandis que l'espace disponible sur le lecteur cible s'affiche sous la liste de sortie.

Annuler et répéter

Chaque opération sur un fichier peut être annulée :
• ⌘Z : annuler la dernière opération
• ⌘⇧Z : répéter l'opération annulée

Lorsque vous annulez une copie, les fichiers copiés sont déplacés vers la corbeille. Lorsque vous annulez un déplacement, les fichiers sont replacés à leur emplacement d'origine.

Avancement et annulation

Une barre de progression avec affichage en pourcentage s'affiche pendant le traitement. Vous pouvez interrompre le processus à tout moment en cliquant sur « Annuler ». Les fichiers déjà traités sont conservés et peuvent être annulés à l'aide de la touche ⌘Z.

Raccourcis clavier

• ⌘O : sélectionner le dossier d'entrée
• ⌘⇧O : sélectionner le dossier de sortie
• ⌘Z : annuler
• ⌘⇧Z : rétablir
• ⌘, : réglages
• ⌘/ : afficher l'aide
• ⌘Q : quitter l'application

Conseils

• Avant toute opération de renommage importante, effectuez une sauvegarde de vos fichiers.
• Utilisez l'aperçu dans la zone de gauche pour vérifier le résultat du renommage avant de l'exécuter.
• Un clic droit sur un fichier dans la liste vous permet de l'afficher dans le Finder.
• Dans les Réglages (⌘,), vous pouvez ajuster la « Tolérance de taille pour la comparaison d'images ». En cas de problème, cliquez à cet endroit sur « Enregistrer le journal… » pour sauvegarder les messages des sept derniers jours dans un fichier texte.
