Manuale di SwiftRename

Panoramica

SwiftRename è uno strumento che consente di rinominare e organizzare più file contemporaneamente. È possibile rinominare i file in base alla data, numerarli in ordine progressivo, aggiungere un prefisso e ordinarli automaticamente in una struttura di cartelle.

Seleziona cartelle

1. Clicca sull'icona della cartella nella cartella di input per selezionare la cartella contenente i file da rinominare. In alternativa, puoi trascinare le cartelle dal Finder ai campi delle cartelle. Tramite la piccola freccia sull'icona della cartella puoi riselezionare rapidamente una cartella usata di recente.
2. Attiva “Includi sottocartelle” per elaborare anche i file nelle sottocartelle.
3. Seleziona una cartella di output in cui copiare o spostare i file rinominati. Le cartelle di input e output possono essere identiche (rinominazione nella stessa posizione).
4. Con “Scambia” è possibile scambiare le cartelle di input e output. Con “Aggiorna” è possibile ricaricare entrambi gli elenchi di file.

Modalità di rinomina

• Solo data: rinomina i file in base alla data di creazione (ad es. “2024-01-15 alle 14-30-00.jpg”)
• Data + nome originale: inserisce la data prima del nome originale del file (ad es. “2024-01-15 alle 14-30-00 - IMG_4523.jpg”)
• Numerazione con prefisso: numera i file in modo progressivo con un prefisso selezionabile (ad es. “Vacanze_0001.jpg”)
• Mantieni nome originale: ordina i file nella struttura delle cartelle senza modificare il nome del file

In caso di nomi di file identici, viene automaticamente aggiunto un contatore (ad es. “_1”, “_2”).

Struttura cartelle

I file possono essere automaticamente ordinati in sottocartelle per data:
• Nessuna: Tutti i file direttamente nella cartella di output
• Mantieni: Riproduce la struttura delle sottocartelle della cartella di input
• Anno: es. “2024/”
• Anno/Mese: es. “2024/01/”
• Anno/Mese/Giorno: es. “2024/01/15/”

Se i file coprono più decenni, vengono create cartelle aggiuntive per decennio (es. “2011-2020/2015/…”).

Per “Anno/Mese” e “Anno/Mese/Giorno” appare direttamente sotto il selettore della struttura delle cartelle l’opzione “Data completa nei nomi delle sottocartelle”. Se attivata, le cartelle di mese e giorno contengono la data completa (es. “2024/2024-01/2024-01-15/” invece di “2024/01/15/”).

Anteprima dei nomi

In cima all'elenco di input puoi scegliere tra tre viste: elenco, albero e anteprima dei nomi (icona a forma di occhio). Nell'anteprima, sotto ogni nome di file attuale compare il nuovo nome previsto con la relativa cartella di destinazione, rispetto alla cartella di output, quindi comprese le cartelle di data e di decennio.

L'anteprima richiede una cartella di output selezionata e viene ricalcolata non appena modifichi la modalità, il prefisso, la struttura cartelle o l'opzione “Usa data fotocamera”. Con molti file si riempie gradualmente, perché per ogni file va letta la data di scatto.

Sono nomi previsti: se un file viene saltato come duplicato e se, in caso di nome di destinazione uguale, occorre aggiungere un contatore (“_1”) si decide solo durante l'esecuzione.

Data della fotocamera (EXIF)

Se l'opzione “Usa data fotocamera” è attivata, per foto e video viene letta la data di registrazione dai dati EXIF. Questa è più precisa della data di creazione del file, che può cambiare durante la copia.

Sono supportati molti formati fotografici, tra cui JPEG, HEIC, PNG, TIFF e i formati RAW più comuni (CR2, CR3, NEF, ARW, DNG, RAF e molti altri).

Se non è disponibile una data EXIF, viene utilizzata automaticamente la data di creazione del file.

Filtro estensione file

Usa il menu a tendina “Estensioni file” per filtrare i file visualizzati per tipo:
• Le estensioni disponibili vengono rilevate automaticamente dalla cartella di input.
• Seleziona una o più estensioni cliccando (⌘-clic per alternare, ⇧-clic per un intervallo).
• “Tutte le estensioni” reimposta il filtro e mostra tutti i file.
• Il filtro viene mantenuto al cambio di cartella, a condizione che le estensioni siano presenti.

Rilevamento dei duplicati

Se l'opzione “Verifica duplicati” è attivata, prima di copiare o spostare i file vengono rilevati i duplicati, sia nella cartella di origine che in quella di destinazione (l'intero albero di destinazione). Il rilevamento si basa sulla dimensione del file e su un confronto byte per byte del contenuto del file; per immagini e video i metadati come l'EXIF vengono ignorati. La data è rilevante solo per il confronto aggiuntivo del contenuto delle immagini.

I duplicati trovati vengono visualizzati in una panoramica con immagini di anteprima. È quindi possibile decidere se continuare (i duplicati vengono ignorati) o interrompere il processo.

Con l'opzione aggiuntiva “Confronta solo il contenuto dell'immagine (lento)”, per le immagini vengono confrontati solo i dati dei pixel decodificati. I metadati come parole chiave, tag o voci EXIF vengono ignorati. In questo modo vengono riconosciute anche immagini identiche che sono state ricompresse durante il salvataggio delle parole chiave. Questa variante è notevolmente più lenta ed è attiva solo quando è abilitato il controllo dei duplicati. Come candidate vengono considerate solo le immagini con lo stesso formato di file e una dimensione di file simile. La differenza di dimensione massima consentita può essere regolata nelle Impostazioni (⌘,) alla voce “Tolleranza di dimensione per il confronto delle immagini” (predefinito: 128 KB). I formati RAW richiedono spesso valori più grandi, poiché i metadati come le parole chiave possono occupare diverse decine di KB per voce.

Se un programma ha reimpacchettato o riesportato un video, questo viene considerato un file a sé stante, anche a parità di immagine e audio. Per i video non esiste un confronto del contenuto come per le immagini.

Copiare e spostare

• Copia: i file originali vengono conservati, le copie vengono create nella cartella di destinazione.
• Sposta: i file vengono spostati nella cartella di destinazione.

Prima dell'esecuzione, SwiftRename verifica se sullo spazio di destinazione è disponibile spazio sufficiente. Se lo spazio è insufficiente, viene visualizzato un avviso. È comunque possibile continuare con l'operazione.

Sotto l'elenco di input viene visualizzata la dimensione totale dei file, sotto l'elenco di output lo spazio libero sullo spazio di destinazione.

Annulla e Ripeti

Ogni operazione sui file può essere annullata:
• ⌘Z: annulla l'ultima operazione
• ⌘⇧Z: ripete l'operazione annullata

Quando si annulla una copia, i file copiati vengono spostati nel cestino. Quando si annulla uno spostamento, i file vengono riportati nella loro posizione originale.

Avanti e Annulla

Durante l'elaborazione viene visualizzata una barra di avanzamento con indicazione della percentuale. È possibile interrompere il processo in qualsiasi momento con “Annulla”. I file già elaborati rimangono invariati e possono essere annullati con ⌘Z.

Scorciatoie da tastiera

• ⌘O: seleziona cartella di input
• ⌘⇧O: seleziona cartella di output
• ⌘Z: annulla
• ⌘⇧Z: ripristina
• ⌘,: impostazioni
• ⌘/: mostra aiuto
• ⌘Q: chiudi app

Consigli

• Prima di eseguire operazioni di rinominazione di grandi dimensioni, esegui un backup dei tuoi file.
• Usa l'anteprima nell'area a sinistra per verificare il risultato della rinominazione prima di eseguire l'operazione.
• Cliccando con il tasto destro del mouse su un file nell'elenco, è possibile visualizzarlo nel Finder.
• Nelle Impostazioni (⌘,) puoi regolare la “Tolleranza di dimensione per il confronto delle immagini”. In caso di problemi, usa lì “Salva registro…” per salvare i messaggi degli ultimi sette giorni in un file di testo.
