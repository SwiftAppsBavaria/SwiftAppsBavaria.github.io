Manuale di sName2Date

Cosa fa l'app

sName2Date cerca una data nel nome del file e la scrive come data di scatto nel file di immagine, di filmato o audio. Un'eventuale data di scatto già presente viene sovrascritta — è proprio a questo che serve l'app, perché un'esportazione o una digitalizzazione porta di solito la data sbagliata.

Se i file che hanno già una data di scatto devono restare intatti, è possibile cambiarlo nelle impostazioni.

Le due caselle in alto nella finestra

In alto nella finestra ci sono due caselle che non si escludono a vicenda. Scrivi la data nel file mette la data trovata come data di scatto nel file stesso; dove il formato non ne accetta alcuna — un PDF per esempio o un file di testo — l'app imposta invece la data di creazione e di modifica del file, e il segno di spunta nella riga è allora arancione invece che verde. Converti i nomi dei file porta il nome alla notazione ISO. Entrambe insieme sono il caso normale; se è attiva solo la seconda, non viene aperto alcun file e si procede solo alla ridenominazione.

La terza casella, Data all'inizio, appartiene alla ridenominazione: mette l'indicazione all'inizio del nome invece di sostituirla nel punto in cui è stata trovata. È in grigio finché non si rinomina.

Caricare i file

I file arrivano nell'elenco in tre modi: con i pulsanti in alto nella finestra, trascinandoli sulla finestra oppure dal menu Archivio — ⌘O sceglie i file, ⌘⇧O una cartella. La riga sotto i pulsanti indica quale cartella è attualmente caricata.

Se scegli una cartella, vengono incluse anche le sottocartelle, finché l'opzione accanto è attiva.

Formati riconosciuti

Vengono riconosciute data e ora nelle forme più diffuse, per esempio 2024-01-15 10-30-00, IMG_20240115_103000, 2024-01-15, 2024 01 15, 15.01.2024 e 15-01-2024. Gli anni a due cifre vengono completati. Vengono letti anche i nomi assegnati da SwiftRename.

Se un nome contiene più date, vince la prima — in IMG_20240115_bearbeitet_2019-03-02 quindi lo scatto e non l'annotazione successiva. Un'indicazione con l'ora ha sempre la precedenza su una senza.

Quando nel nome ci sono solo mese e anno

Se il nome contiene solo anno e mese, ad esempio 2016 04 Blomberg, viene letto aprile 2016 e si presume il primo giorno del mese. Nella riga compare allora «(giorno presunto)»; il giorno esatto si può aggiungere nel campo a destra.

Il mese deve perciò essere scritto con due cifre. In un nome come Bild 2 2016 si tratta per lo più di un numero progressivo — e una data letta male sarebbe peggio di una data non letta.

Prima il giorno o il mese?

In italiano il 3 aprile si scrive 3/4, in inglese 4/3 — le stesse due cifre, significato opposto. Con 15-03-2024 questo non ha conseguenze: un mese 15 non esiste, l'indicazione è univoca e viene sempre letta correttamente. Solo quando entrambi i numeri possono valere come mese, per esempio in 03-05-2024, occorre decidere.

Se nell'elenco c'è un file di questo tipo, sopra di esso compare una barra arancione con la scelta tra le due letture; le righe interessate sono contrassegnate in modo apposito. È preimpostata la notazione della regione del tuo sistema. Finché nessun file è ambiguo non c'è nulla da scegliere — per questo la barra non compare.

Ora

Se il nome contiene solo una data, viene presunta un'ora. È possibile modificarla nelle impostazioni.

Sono preimpostate le 12 di mezzogiorno. Ciò evita che il giorno cambi se il file passa in seguito in un altro fuso orario. Se viene modificato anche il nome del file, l'ora presunta compare anche lì — nome e data di scatto dicono sempre la stessa cosa.

Impostare la data manualmente

A destra di ogni riga si trova un campo con data e ora. Ciò che viene inserito lì ha la precedenza sulla data ricavata dal nome del file. In questo modo si possono elaborare anche file nel cui nome non compare alcuna data.

La freccia accanto al campo riporta la riga al valore ricavato dal nome del file.

Una seconda data: quando è nato il contenuto

Accanto alla data di scatto si può annotare quando è nato il soggetto stesso: nella fotografia di un dipinto del 1650 quindi 1650 e non il giorno della ripresa. L'interruttore «Data del contenuto» in alto nella finestra mostra a tal fine la colonna «Datato al». È nascosta per impostazione predefinita, perché la maggior parte dei file non ne ha bisogno.

Questo si può memorizzare solo in JPEG, TIFF e HEIC. PNG e GIF accolgono soltanto la data di scatto, e così i filmati; lì nella colonna compare un'indicazione invece di un campo. La data di scatto stessa viene scritta in tutti questi formati.

Uniformare i nomi dei file

Se lo desideri, l'app sostituisce la data nel nome del file con la notazione ISO comprensiva di ora: da 15.03.2024 Urlaub.jpg si ottiene 2024-03-15 10-30-00 Urlaub.jpg. Così nel Finder i file si ordinano per momento di scatto. Si attiva con la casella Converti i nomi dei file in alto nella finestra; nell'elenco il nuovo nome compare poi sotto quello vecchio.

Se nel nome non compare alcuna data, viene anteposta quella impostata manualmente. Se il nuovo nome è già in uso, viene aggiunto un numero progressivo. Anche la ridenominazione viene annullata con ⌘Z.

Annullare

Con ⌘Z è possibile annullare un'esecuzione: la data di scatto e le date di creazione e di modifica tornano poi ai valori precedenti. ⌘⇧Z la ripristina.

Se l'elenco viene svuotato o viene scelta un'altra cartella, l'annullamento non è più possibile — l'app non ha più il diritto di accesso ai file precedenti.

Cosa viene modificato

Vengono scritti EXIF DateTimeOriginal e DateTimeDigitized nonché TIFF DateTime, nei filmati e nelle registrazioni audio la data di creazione contenuta nel contenitore. I dati dell'immagine restano intatti — un JPEG non viene ricompresso.

Crea comunque una copia di sicurezza prima di elaborare una raccolta di grandi dimensioni.

Quando una riga non diventa verde

Un segno di spunta arancione significa: non è stato possibile scrivere la data di scatto, in compenso ora sono la data di creazione e di modifica del file a portare il valore — l'informazione è quindi conservata, solo in un altro punto. La riga ne indica il motivo. Un triangolo rosso significa che non è stato possibile scrivere nulla.

Se è stato scelto un singolo file, l'app può lavorare solo su quel file e non nella sua cartella — per questo la ridenominazione può non riuscire; in tal caso la riga lo indica. Rimedio: scegliere la cartella anziché il singolo file. Se qualcosa resta poco chiaro, il pulsante nelle impostazioni, alla voce Diagnostica, salva un registro degli ultimi sette giorni.
