Manuale di sVectorLift

Panoramica

sVectorLift apre le vecchie clipart vettoriali dell’era CorelDRAW e le converte in SVG: immagini che i programmi di oggi possono di nuovo utilizzare. A sinistra scegli una cartella, a destra compaiono le clipart come anteprime. Le immagini selezionate si esportano in una cartella di destinazione a tua scelta.

Formati supportati

• Documenti CorelDRAW (.cdr), dalla versione 6 alla 9
• Corel Binary Meta File (.cmx) — anche la vecchia variante CDRX
• Windows Metafile (.wmf)
• Computer Graphics Metafile (.cgm)
• Metafile QuickDraw 3D (.3dm, .3dmf) — vengono resi come immagine
• Scalable Vector Graphics (.svg) — vengono visualizzati direttamente

Molti file con estensione .cdr in realtà non sono affatto documenti CorelDRAW, ma CMX. È proprio qui che i convertitori abituali falliscono: sVectorLift legge entrambi.

Scegli cartella

1. Fai clic su «Scegli cartella…» (o ⌘O) per aprire la cartella con la tua raccolta di clipart. Sotto compare l’albero delle cartelle.
2. Un clic su una cartella nell’albero carica le sue clipart. Le sottocartelle si aprono con il triangolo.
3. All’avvio successivo si riapre l’ultima cartella usata — insieme all’ultima sottocartella aperta e al file selezionato. Con «File → Cartelle recenti» torni direttamente a una raccolta precedente.

Puoi aprire un singolo file anche dal Finder («Apri con» o doppio clic): se si trova nella tua raccolta, sVectorLift ci va; se è all’esterno, lo mostra da solo e chiede l’accesso alla cartella solo quando passi alla Panoramica.

Con il campo «Filtra (nome o parola chiave)» puoi nascondere le clipart per nome o parola chiave.

Per modificare la larghezza della barra laterale trascina il separatore verso la griglia. Con il pulsante in alto nella barra — o con ⌃⌘S — puoi nasconderla del tutto, in modo che le clipart usino tutta la larghezza della finestra.

Accanto a entrambi i pulsanti delle cartelle è indicato il percorso scelto. Un clic lo mostra per intero, pronto da copiare; un clic destro porta direttamente nel Finder.

Visualizzare le clipart

• Con il cursore in alto a destra imposti la dimensione delle anteprime.
• «Vista dettagliata» (o un doppio clic su una clipart) mostra una singola immagine in grande. Con i tasti freccia ← → scorri la cartella, un doppio clic riporta alla Panoramica.
• Le anteprime vengono calcolate solo quando le vedi. Nelle cartelle molto grandi compaiono quindi dapprima dei segnaposto, che si riempiono man mano.

Seleziona

La selezione funziona come nell’app Foto:
• Clic: selezionare una singola clipart
• ⌘-clic: aggiungere singole clipart alla selezione o rimuoverle
• ⇧-clic: selezionare un intervallo continuo
• Trascinare in un’area vuota: tracciare un rettangolo di selezione (elastico)
• ⌘A: selezionare tutte le clipart della cartella
• Clic in un’area vuota: annullare la selezione

Esporta

1. Scegli una cartella di destinazione sotto «2. Esportazione». Un clic sul percorso lo mostra per intero e, se necessario, porta al Finder.
2. «Esporta selezione» salva le clipart selezionate, «Esporta tutto» l’intera cartella (filtrata).

Le immagini vettoriali vengono salvate come .svg. Le immagini puramente raster — e i modelli 3D — vengono salvati come .png, così non va perso nulla. I file SVG sono già il formato di destinazione; per loro l’esportazione è disattivata.

Dal menu contestuale (clic destro su una clipart) esporti nella stessa cartella di destinazione, mostri il file nel Finder, lo rinomini o lo sposti nel cestino. Se non è ancora impostata una cartella di destinazione, ti viene chiesta una volta.

Se il file di destinazione esiste già, sVectorLift te lo chiede prima: «Sostituisci», «Tieni entrambi» (scrive accanto, come «Nome 2.svg»), «Ignora» o «Annulla». Con più file, «Applica a tutti» estende la tua risposta all’intera operazione. L’esportazione prosegue poi con una barra di avanzamento nella barra laterale, e puoi interromperla in qualsiasi momento.

Una rinomina la annulli con ⌘Z e la ripristini con ⇧⌘Z — finché il file si trova ancora nella raccolta aperta. Mentre è in corso un’esportazione, i comandi Rinomina ed Elimina sono brevemente disattivati: l’esportazione lavora con i nomi di file validi al momento del suo avvio.

Esporta struttura cartelle

Per convertire un’intera cartella con le sue sottocartelle, usa la finestra «Esporta struttura cartelle». La apri con «File → Esporta struttura cartelle…» o con il pulsante omonimo nella barra laterale; lì scegli la cartella di origine e quella di destinazione e avvii l’esportazione con «Esporta tutto». Nella destinazione viene creata la stessa struttura di cartelle; i file SVG vengono copiati senza modifiche e le cartelle senza file supportati non vengono create. Non vengono poste domande: ciò che si trova già nella destinazione viene saltato. Se più file di una cartella hanno lo stesso nome, ciascuno dei successivi riceve la sua estensione originale, ad esempio «geometry (cmx).svg».

Impostazioni

In «sVectorLift → Impostazioni…» (⌘,) imposti la dimensione di rendering per i modelli 3D.

I modelli 3D non hanno una forma vettoriale; per l’esportazione vengono calcolati come immagine. Più alto è il valore, più nitido è il PNG — e più lunga è l’esportazione. Sono ammessi da 256 a 8192 pixel, il valore predefinito è 1024.

Nella stessa finestra trovi anche il pulsante per la scelta della lingua.

Abbreviazioni da tastiera

• ⌘O: scegliere la cartella
• ⌘A: selezionare tutte le clipart
• ← →: scorrere la cartella nella Vista dettagliata
• Doppio clic: passare dalla Panoramica alla Vista dettagliata
• ⌃⌘S: mostrare o nascondere la barra laterale
• ⌘/: mostrare questo aiuto
• ⌘W: chiudere la finestra (chiude l’app dopo conferma)
• ⌘Q: uscire dall’app
• ⌘Z: annullare la rinomina
• ⇧⌘Z: ripristinare la rinomina

Lingua

sVectorLift utilizza la lingua del sistema. Se desideri usare l’app in un’altra lingua, puoi impostarla in Impostazioni di Sistema:

Impostazioni di Sistema → Generali → Lingua e zona → scorri in fondo fino alla sezione «Applicazioni» → «+» → sVectorLift → lingua desiderata

Questa impostazione vale solo per sVectorLift; il resto del sistema rimane invariato.

Se una clipart non appare

• Un punto interrogativo al posto dell’anteprima significa che non è stato possibile leggere il file — ad esempio perché è danneggiato o contiene un formato che sVectorLift non conosce.
• sVectorLift è pensato per le raccolte di clipart: disegni, simboli, illustrazioni. Gli opuscoli su più pagine e i modelli di stampa di CorelDRAW non sono il suo scopo e possono apparire incompleti.

SVG animati

sVectorLift mostra i file SVG animati come immagine fissa – il movimento vero e proprio non viene riprodotto.
