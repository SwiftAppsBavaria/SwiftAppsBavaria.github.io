sVectorLift ヘルプ

概要

sVectorLift は、CorelDRAW 時代の古いベクタークリップアートを開き、SVG に変換します。これにより、今日のアプリケーションでも扱える図形になります。左側でフォルダを選択すると、右側にクリップアートがプレビューとして表示されます。選択したグラフィックは、お好きな書き出し先フォルダに書き出せます。

対応しているフォーマット

• CorelDRAW 書類（.cdr）バージョン 6 〜 9
• Corel Binary Meta File（.cmx）— 古い CDRX 形式にも対応
• Windows Metafile（.wmf）
• Computer Graphics Metafile（.cgm）
• QuickDraw 3D メタファイル（.3dm、.3dmf）— 画像としてレンダリングされます
• Scalable Vector Graphics（.svg） — そのまま表示されます

拡張子が .cdr のファイルの多くは、実際には CorelDRAW 書類ではなく CMX です。一般的なコンバータはまさにこの点で失敗しますが、sVectorLift は両方を読み込めます。

フォルダを選択

1.「フォルダを選択 …」（または ⌘O）をクリックして、クリップアートのコレクションが入ったフォルダを開きます。その下にフォルダのツリーが表示されます。
2. ツリー内のフォルダをクリックすると、そのクリップアートが読み込まれます。サブフォルダは三角形をクリックして展開します。
3. 次回の起動時には、最後に使ったフォルダが再び開きます — 最後に開いたサブフォルダと選択していたファイルも含めて。「ファイル」→「最近使ったフォルダ」から、以前のコレクションへ直接戻ることができます。

Finder からファイルを 1 つだけ開くこともできます（「このアプリケーションで開く」またはダブルクリック）。そのファイルがコレクション内にあれば sVectorLift はそこへ移動し、コレクションの外にあれば単独で表示して、概要に切り替えたときに初めてフォルダへのアクセスを確認します。

「フィルタ（名前またはキーワード）」フィールドを使うと、名前やキーワードでクリップアートを絞り込めます。

サイドバーの幅は、グリッドとの境界線をドラッグして変更できます。サイドバー上部のボタン、または ⌃⌘S でサイドバーを完全に非表示にすると、クリップアートがウインドウの幅いっぱいに表示されます。

どちらのフォルダボタンの隣にも、選んだパスが表示されます。クリックするとパス全体が表示されてコピーでき、右クリックすると直接 Finder が開きます。

クリップアートを表示する

• 右上のスライダで、サムネールの大きさを調整できます。
•「詳細表示」（またはクリップアートをダブルクリック）すると、1 つのグラフィックが大きく表示されます。矢印キー ← → でフォルダ内を移動でき、ダブルクリックで「概要」に戻ります。
• サムネールは、表示されるときに初めて計算されます。そのため、非常に大きなフォルダではまずプレースホルダが表示され、順次埋まっていきます。

選択

選択の操作は「写真」App と同じです:
• クリック: 個々のクリップアートを選択します
• ⌘ + クリック: 個々のクリップアートを選択に追加、または選択から外します
• ⇧ + クリック: 連続した範囲を選択します
• 何もない場所をドラッグ: 選択範囲（ラバーバンド）を作成します
• ⌘A: フォルダ内のすべてのクリップアートを選択します
• 何もない場所をクリック: 選択を解除します

書き出す

1.「2. 書き出し」で「書き出し先フォルダ …」を選択します。パスをクリックすると全体が表示され、必要に応じて Finder が開きます。
2.「選択項目を書き出す」は選択したクリップアートを、「すべて書き出す」はフォルダ全体（フィルタ適用後）を書き出します。

ベクターグラフィックは .svg として保存されます。ラスタ画像のみのファイルと 3D モデルは、内容が失われないように .png として保存されます。SVG ファイルはすでに書き出し先の形式なので、これらについては書き出しが無効になっています。

コンテキストメニュー（クリップアートを右クリック）から、同じ書き出し先フォルダに書き出したり、ファイルを「Finder に表示 …」したり、名前を変更したり、「ゴミ箱に入れる」ことができます。書き出し先フォルダがまだ設定されていない場合は、一度だけ確認されます。

書き出し先のファイルがすでにある場合、sVectorLift は先に確認します。「置き換える」、「両方とも残す」（隣に「名前 2.svg」として書き出します）、「スキップ」、「キャンセル」です。複数のファイルのときは「すべてに適用」で、答えをその実行全体に引き継げます。その後、書き出しはサイドバーの進捗バーとともに進み、いつでも中止できます。

名称変更は ⌘Z で取り消し、⇧⌘Z でやり直せます — そのファイルが、開いているコレクションにある間にかぎります。書き出しの実行中は、名称変更と削除が一時的に使えなくなります。書き出しは、開始した時点のファイル名で処理するためです。

フォルダ構造を書き出す

フォルダ全体をサブフォルダごと変換するには、「フォルダ構造を書き出す」ウインドウを使います。このウインドウは「ファイル → フォルダ構造を書き出す …」またはサイドバーにある同じ名前のボタンで開きます。そこでソースフォルダと書き出し先フォルダを選択し、「すべて書き出す」で開始します。書き出し先には同じフォルダ構造が作成されます。SVG ファイルはそのままコピーされ、対応するファイルがないフォルダは作成されません。確認は求められません。書き出し先にすでにあるものはスキップされます。1つのフォルダ内に同じ名前のファイルが複数ある場合、2つ目以降のファイルには元の拡張子が付きます（例：「geometry (cmx).svg」）。

設定

「sVectorLift → 設定 …」（⌘,）で、3Dモデルのレンダリングサイズを設定します。

3Dモデルにはベクター形式がないため、書き出しでは画像として計算されます。値が大きいほど PNG は鮮明になり、そのぶん書き出しに時間がかかります。指定できるのは 256〜8192 ピクセルで、初期値は 1024 です。

同じウインドウには、言語を選ぶボタンもあります。

キーボードショートカット

• ⌘O: フォルダを選択します
• ⌘A: すべてのクリップアートを選択します
• ← →: 詳細表示でフォルダ内を移動します
• ダブルクリック: 概要と詳細表示を切り替えます
• ⌃⌘S: サイドバーを表示または非表示にします
• ⌘/: このヘルプを表示します
• ⌘W: ウインドウを閉じます（確認のうえ App を終了します）
• ⌘Q: App を終了します
• ⌘Z: 名称変更を取り消します
• ⇧⌘Z: 名称変更をやり直します

言語

sVectorLift はシステムの言語を引き継ぎます。App を別の言語で使用したい場合は、システム設定で指定してください:

システム設定 → 一般 → 言語と地域 → 一番下までスクロールして「アプリケーション」セクション →「+」→ sVectorLift → 使用する言語

この設定は sVectorLift にのみ適用され、システムのほかの部分には影響しません。

クリップアートが表示されない場合

• プレビューの代わりに疑問符が表示される場合、そのファイルは読み込めませんでした。ファイルが壊れているか、sVectorLift が対応していないフォーマットが含まれている可能性があります。
• sVectorLift はクリップアートのコレクション（絵、シンボル、イラスト）のために作られています。CorelDRAW の複数ページのパンフレットや印刷用テンプレートは対象ではなく、不完全に表示されることがあります。

アニメーション SVG

アニメーション SVG ファイルは、sVectorLift では静止画として表示され、動き自体は再生されません。
